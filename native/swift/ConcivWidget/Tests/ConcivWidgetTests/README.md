# ConcivWidgetTests

## Overview

XCTest target for ConcivWidget: bridge message conformance against shared JSON fixtures, discovery, live region, overlay geometry, bridge recovery, capture, launcher defaults and pick selection.

## Interface

- `BridgeConformanceTests` (`BridgeConformanceTests.swift`): valid, unknown-key and invalid fixtures under `Fixtures/bridge/` decode, round-trip or are rejected
- `DiscoveryTests` (`DiscoveryTests.swift`): pairing file parsing, page and health URLs, candidate ports, health body shape
- `LiveRegionTests` (`LiveRegionTests.swift`): open and closed capture regions
- `BridgeRecoveryTests` (`BridgeRecoveryTests.swift`): negotiated version stamping, handshake supersession after rebind and reload
- `CaptureTests` (`CaptureTests.swift`), `OverlayGeometryTests` (`OverlayGeometryTests.swift`), `LauncherDefaultTests` (`LauncherDefaultTests.swift`), `PickSelectionTests` (`PickSelectionTests.swift`)
- `Fixtures/bridge/`: `n2p.*` and `p2n.*` message fixtures plus `encode`, `invalid`, `unknown-key` sets; copied as a test resource
- `transcript-xcode-version.txt`: recorded Xcode and simulator versions; excluded from the target

## Invariants

- `BridgeRecoveryTests.swift`, `CaptureTests.swift`, `LauncherDefaultTests.swift`, `OverlayGeometryTests.swift`, `PickSelectionTests.swift`: wrapped in `#if canImport(UIKit)`, so they run only on the iOS simulator (`xcodebuild test`); `swift test` on macOS runs the rest
- `transcript-xcode-version.txt`: `Fixtures/bridge/` is generated by `pnpm --filter @conciv/extension-ios gen:fixtures`; CI checks `git diff --exit-code` after regenerating

## Side Effects

- None

## Verification

- Run: `cd native/swift/ConcivWidget && swift test` (macOS host; runs the Foundation-only suites)
- Run: `cd native/swift/ConcivWidget && xcodebuild test -scheme ConcivWidget -destination 'platform=iOS Simulator,name=iPhone 17 Pro'` (UIKit suites behind `canImport(UIKit)`)
