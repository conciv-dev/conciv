# swift

## Overview

Swift sources: the ConcivWidget iOS SDK package and the ConcivDemo app that consumes it.

## Subdirectories & Boundaries

- ConcivDemo: [ConcivDemo/README.md](./ConcivDemo/README.md) - iOS simulator demo app built with plain `swiftc` (no Xcode project), compiled together with the real ConcivWidget sources. The TanStack Start example's iOS extension points at this folder.
- ConcivWidget: [ConcivWidget/README.md](./ConcivWidget/README.md) - Swift package `ConcivWidget` (tools 5.9, iOS 17): the iOS SDK library and its XCTest target.
