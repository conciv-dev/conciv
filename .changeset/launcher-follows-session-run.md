The launcher glows again for a run it did not start. With chat on its own transport a foreign run reaches the pane as a run lifecycle rather than a local stream, so the mascot read a signal that only its own turns could raise. The pane now registers the session's activity - its own stream or a live run on the session - so the launcher follows the targeted session from the start of a run to its settle.
