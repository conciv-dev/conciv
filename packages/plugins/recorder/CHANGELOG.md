- [`ccfe318`](https://github.com/conciv-dev/conciv/commit/ccfe318b5134ec42592bcb6d6509b6212c30f29d) Thanks [@omridevk](https://github.com/omridevk)! - A plugin's `./plugin-experimental` entry carries its types: the `experimental()` Vite build writes a `plugin-experimental.d.cts` beside the CommonJS bundle, and the first-party plugins point the entry's `types` condition at it.

- [#1142](https://github.com/conciv-dev/conciv/pull/1142) [`84ea7e3`](https://github.com/conciv-dev/conciv/commit/84ea7e3fe676a4c875535e2f20ca3bc6ffa84c93) Thanks [@omridevk](https://github.com/omridevk)! - A plugin declares its own icons as SVG documents in `Plugin.define({icons})`, and names them through `ctx.icons` in every SDK icon field and in `ctx.ui.Icon`, as opencode's plugins do: `IconName` is now `AppIconName | PluginIconName`. The app draws every icon name through one `Icon` from `@conciv/ui-kit-chat`, and tool cards show an icon in their header (the TanStack cards and the inspector chip show the TanStack logo).

- [#1020](https://github.com/conciv-dev/conciv/pull/1020) [`e806c50`](https://github.com/conciv-dev/conciv/commit/e806c508fc0c380ca8ce7e27a6283a07804b2344) Thanks [@omridevk](https://github.com/omridevk)! - CI now runs the tests of every package under `packages/plugins/` (whiteboard, recorder, tanstack, test-runner); the shard planner had left that folder out.

- [#1191](https://github.com/conciv-dev/conciv/pull/1191) [`d0009c9`](https://github.com/conciv-dev/conciv/commit/d0009c9748360343de7a47802a75b4bd0264b13e) Thanks [@omridevk](https://github.com/omridevk)! - A plugin that is not built into the widget brings its own stylesheet of utilities and adds it through the Style registry.

- [#1176](https://github.com/conciv-dev/conciv/pull/1176) [`7e4d195`](https://github.com/conciv-dev/conciv/commit/7e4d195d46ab43964a08db8143705a54e1e76c31) Thanks [@omridevk](https://github.com/omridevk)! - A plugin reads engine data through its server's `data`: `server.data.meta.models(sessionId)` returns the app's own query for the session's models (same key and cache as the model picker). Plugin rpc reads and writes go through the SDK query and mutation options, never through hand-built queries.

- [#961](https://github.com/conciv-dev/conciv/pull/961) [`b31c334`](https://github.com/conciv-dev/conciv/commit/b31c33489cff0a12d878beac22e5b4680f97ecaa) Thanks [@omridevk](https://github.com/omridevk)! - New package `@conciv/plugin-recorder`: the recorder as a conciv plugin. Its browser part records the page it runs in while a recording is live (a Recorder tab is open, or the agent started one) and the page plugin is active, leaving the widget out through the page plugin's `capture.exclude`; the Recorder tab replays the recording live, starts a New recording and exports it as a video (Export video). The agent drives it from code mode as `external_recording_start()`, `external_recording_stop({captureId, keyframes?})` and `external_recording_pull({secondsBack?, keyframes?})`, guided by the plugin's `recorder` skill. Enable it with `plugins: ['@conciv/plugin-recorder']` (or `['@conciv/plugin-recorder', {masking, windowMinutes, console}]`).

- [#1147](https://github.com/conciv-dev/conciv/pull/1147) [`26a5892`](https://github.com/conciv-dev/conciv/commit/26a58920ba1d6a87eae3f3220fcfa52c8ca86c93) Thanks [@omridevk](https://github.com/omridevk)! - The recorder streams a rendered video to its file instead of holding it in memory.
