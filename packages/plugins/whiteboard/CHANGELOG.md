# @internal/plugin-whiteboard

## 0.0.23

### Patch Changes

- [`ccfe318`](https://github.com/conciv-dev/conciv/commit/ccfe318b5134ec42592bcb6d6509b6212c30f29d) Thanks [@omridevk](https://github.com/omridevk)! - A plugin's `./plugin-experimental` entry carries its types: the `experimental()` Vite build writes a `plugin-experimental.d.cts` beside the CommonJS bundle, and the first-party plugins point the entry's `types` condition at it.

- [#1169](https://github.com/conciv-dev/conciv/pull/1169) [`4022790`](https://github.com/conciv-dev/conciv/commit/4022790e958fa35e5141d88fd1b331e3369d0e61) Thanks [@omridevk](https://github.com/omridevk)! - The Recorder's capture control runs on the shared machine driver, and the whiteboard's collection writes, drawing and export are Effect programs run once at the database boundary instead of promise chains.

- [#1136](https://github.com/conciv-dev/conciv/pull/1136) [`6664a1e`](https://github.com/conciv-dev/conciv/commit/6664a1e59b7e11930cd783b8c77e777a9f56b811) Thanks [@omridevk](https://github.com/omridevk)! - The whiteboard canvas is a region named "Whiteboard canvas", so a screen reader user can find it and land on it.

- [`fbb0b1b`](https://github.com/conciv-dev/conciv/commit/fbb0b1b0da1304733353b00b872e488781a01493) Thanks [@omridevk](https://github.com/omridevk)! - The whiteboard canvas is transparent over the page again, as the old whiteboard was. A new "Canvas background" row in the general settings turns that off for a solid canvas that follows the theme, and the open canvas follows the change at once. PNG exports stay white.

- [`2574b0a`](https://github.com/conciv-dev/conciv/commit/2574b0acb78711cf24be7f3fe2e1061dd0d5cb29) Thanks [@omridevk](https://github.com/omridevk)! - The thread cards for the whiteboard tools (canvas, comment, element and anchor) now ship with the whiteboard plugin and
  draw through `ctx.ui`, so they show only in projects that load the plugin. A failed whiteboard call draws the app's own
  failed-tool card, and the mermaid source of a diagram shows as plain text.

- [#1136](https://github.com/conciv-dev/conciv/pull/1136) [`6664a1e`](https://github.com/conciv-dev/conciv/commit/6664a1e59b7e11930cd783b8c77e777a9f56b811) Thanks [@omridevk](https://github.com/omridevk)! - A comment thread opened again focuses its new reply box on a slow machine too, instead of aiming at the reply box of the thread that was closed.

- [#1136](https://github.com/conciv-dev/conciv/pull/1136) [`6664a1e`](https://github.com/conciv-dev/conciv/commit/6664a1e59b7e11930cd783b8c77e777a9f56b811) Thanks [@omridevk](https://github.com/omridevk)! - Opening a comment thread focuses its reply box even when the reply editor finishes loading after the thread has opened.

- [`d3c8511`](https://github.com/conciv-dev/conciv/commit/d3c8511c2cf5b07c4e3090f7b4b023ea395e96be) Thanks [@omridevk](https://github.com/omridevk)! - Escape from the chat closes the whiteboard again while the transcript shows an expanded tool card; only an open menu, popover or other layer in the chat keeps Escape for itself.

- [#1136](https://github.com/conciv-dev/conciv/pull/1136) [`6664a1e`](https://github.com/conciv-dev/conciv/commit/6664a1e59b7e11930cd783b8c77e777a9f56b811) Thanks [@omridevk](https://github.com/omridevk)! - The whiteboard's wait for its comments to bind is the `commentBindDeadlineMs` option (5000 ms by default) instead of a fixed 5 seconds.

- [#1136](https://github.com/conciv-dev/conciv/pull/1136) [`6664a1e`](https://github.com/conciv-dev/conciv/commit/6664a1e59b7e11930cd783b8c77e777a9f56b811) Thanks [@omridevk](https://github.com/omridevk)! - A human comment keeps the element it was picked on after the engine adds its source details, so it stays placed on that element.

- [#1100](https://github.com/conciv-dev/conciv/pull/1100) [`549f445`](https://github.com/conciv-dev/conciv/commit/549f445f364067d88cbd1f92f36d4569e2cd0145) Thanks [@omridevk](https://github.com/omridevk)! - The whiteboard loads its canvas through the app's query cache, and opening it again after a failed load tries once more. The collections that talk to the engine live in their own model file.

- [#1120](https://github.com/conciv-dev/conciv/pull/1120) [`571d456`](https://github.com/conciv-dev/conciv/commit/571d456cd232387f11dd2e119d1971f409a825c6) Thanks [@omridevk](https://github.com/omridevk)! - A comment being written closes when the session changes instead of landing in the other session's whiteboard. Live cursors are timed by the server's clock, and opening a thread marks it read up to its newest comment, so a skewed browser clock no longer hides cursors or unread replies. A second finger on another pin no longer cancels the pin being dragged, a pin with its drift prompt open no longer snaps back when pressed, and the agent's cursor always ends where the agent last worked.

- [#1169](https://github.com/conciv-dev/conciv/pull/1169) [`4022790`](https://github.com/conciv-dev/conciv/commit/4022790e958fa35e5141d88fd1b331e3369d0e61) Thanks [@omridevk](https://github.com/omridevk)! - The whiteboard's browser half makes its own Effect runtime in setup and disposes it on cleanup; the canvas, its change feed, collections, cursors and comment compose all run on it instead of the global default runtime.

- [#1136](https://github.com/conciv-dev/conciv/pull/1136) [`6664a1e`](https://github.com/conciv-dev/conciv/commit/6664a1e59b7e11930cd783b8c77e777a9f56b811) Thanks [@omridevk](https://github.com/omridevk)! - The whiteboard canvas runs in zen mode as it asks: Excalidraw's direction rules now apply inside the overlay, so the shape panel, library and help buttons stay hidden.
