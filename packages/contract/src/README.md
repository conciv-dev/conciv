# contract/src

## Overview

Defines the oRPC `contract` router between conciv core and its clients (sessions, drafts, markers, navigation, chat, registry, captures, page, server, editor, meta) and the zod row schemas those procedures use. It also provides two client factories: a plain fetch client for node callers and a browser client. The browser client keeps one connection per engine api base in a `globalThis` map: every procedure (one-shot calls and event-iterator streams) rides one partysocket `ReconnectingWebSocket` to `${apiBase}/rpc-ws` through oRPC's websocket `RPCLink`; the socket reconnects on its own, open streams resubscribe after it comes back, and its open/close state is the reachability subscribers hear. `index.ts` re-exports `rows.ts`, `contract.ts`, `client.ts` and `browser-transport.ts`.

## Interface

- `contract` (`contract.ts`): oRPC router with `auth{trust,exchange,requestCode}`, `sessions{list,search,changes,get,preview,create,resolve,open,restore,rename,delete,model,effort,compact,switchHarness}`, `drafts{get,set}`, `markers{list}`, `navigation{get,set}`, `chat{events,hydrate,stop,permissionDecision,uiReply}` (`events` and `sessions.changes` are eventIterators; `sessions.changes` yields `{version}`, the search index version, the current one first), `registry{catalog,call}`, `captures{list}`, `page{symbolicate,changes,clearChanges,queries,reply}` (`queries` is an eventIterator), `server{config,resolve,graph,transform,urls,reload,restart}`, `editor{open,openFromFrames}`, `meta{models,harnesses,commands,tools,engine}`.
- `ChatHydrationSchema` / `ChatHydration`, `ChatPendingApproval` (`contract.ts`): chat hydrate payload (messages, activeRun, lastRun, pendingApprovals, interrupts, and `page` when the input carried a `limit`). `chat.hydrate` input takes an optional `limit` (positive integer) and `before` (the `page.cursor` of the newer window); `ChatHistoryWindow` is that pair.
- `sessions.preview` (`contract.ts`): read-only window of a native transcript. Input `{harness, nativeId, cwd?, before: cursor | null, limit: 1-100}` (`cwd` is an all-projects hit's own project, this project when absent); output `{messages, earlier: cursor | null}`, newest window first, `earlier` is the `before` for the window above it. The cursor is an opaque string the harness minted; a window may hold a few more than `limit` messages, since it starts on a whole turn. A missing, empty or unreadable transcript is `NOT_FOUND`.
- `ToolCommandSignatureSchema` / `ToolCommandSignature` (`contract.ts`): registry catalog entry (name, path, binding `server|client`, icon from `TOOL_ICON_KEYS`, label, mutating/reachable, approval `'ask'`, input/output schema, errors).
- `RegistryCallErrorName` (`contract.ts`): `NO_PAGE_CLIENT`, `PAGE_TIMEOUT`, `UNKNOWN_TOOL`, `INVALID_ARGS`, `HANDLER_ERROR`, `APPROVAL_DENIED`.
- `EditorOpenInputSchema`, `EngineStalenessSchema` / `EngineStaleness` (`contract.ts`).
- `SessionMetaSchema` / `SessionMeta`, `SessionHitSchema` / `SessionHit` (`SessionMeta` plus `excerpt: string | null`, `matched: string[]`, `cwd: string | null` (the other project's cwd for a hit outside this project), `resume: string | null` (the shell command that resumes that hit in its own project) and `preview: NativeSessionRef | null` (the transcript the match came from, which after a harness switch is an earlier transcript, not the session's current `native`), the rows of a `sessions.search` page; `sessions.list` keeps `SessionMeta`), `PersistedAttachmentSchema`, `DraftRowSchema` / `DraftRow`, `MarkerKindSchema` (`'new' | 'compact'`), `MarkerRowSchema` / `MarkerRow`, re-exported `UsageSnapshotSchema` / `UsageSnapshot` (`rows.ts`).
- `makeRpcClient(apiBase, {headers?})` -> `RpcClient` (`client.ts`): oRPC client over `RPCLink` at `${apiBase}/rpc` using `abortableFetch`.
- `abortableFetch(request, init, {signal?})` (`client.ts`): fetch wrapper passing `signal ?? null`.
- `makeBrowserRpcClient(base | () => base | null, {session?})` -> `BrowserRpcClient {rpc, bound, bind, rebind, close}` (`client.ts`); types `RpcClient`, `RpcClientOptions`, `BrowserRpcClientOptions`, `BrowserRpcClient`.
- `browserRpcConnection(apiBase)` -> `{link, trust, release}` (`browser-transport.ts`): holds the shared connection for a normalized api base until `release()`; a trust observer keeps its handle for as long as it listens, so it never sits on a closed connection. `resetBrowserRpcConnection(apiBase)` reconnects an open connection's socket now instead of waiting out the backoff and creates nothing when the base has no connection.
- `heldBrowserRpcLink(currentApiBase, session?)` -> `{link, release}` (`browser-transport.ts`): ClientLink that resolves the api base per call, puts `concivSessionId` in the call context, and holds the connection for the base it last called; `release()` lets it go, and a connection closes when its last holder releases it.
- `subscribeRpcReachability(apiBase, listener)` -> unsubscribe (`browser-transport.ts`).
- `EngineTrust` on every `BrowserRpcConnection.trust` (`browser-transport.ts`): the one trust owner per api base. `isTrusted()`, `status()` (`checking | trusted | untrusted | revoked | unreachable`), `subscribe(listener)` (the listener gets the new and the previous status), `requestTrust(tokenSource?)` (stored token first, the token source only when it is missing or refused), `requestTrustWithToken(token)`, `requestTrustWithCode(code)` -> `{token} | {refused}`, `requestAuthCode({reissue?})`, `ensureTrusted()`.
- `readMagicLinkCode()` / `forgetMagicLinkCode()` (`browser-transport.ts`): read `#conciv_otp=` with `URLSearchParams`, and strip it from the URL only once the engine has answered the exchange (a reload before then keeps the code and retries it).
- `engineHeaders(apiBase)` / `engineWebSocket(apiBase)` (`browser-transport.ts`): the `Authorization: Bearer` header for raw browser fetches (the held token, else the stored one; it creates no connection), and a `WebSocket` constructor whose sockets take the token of the base's open connection (else the stored one), report a revocation to that connection (else forget the stored token), never create a connection, and send `{type: SOCKET_TRUST_FRAME, token}` on open and mark the connection untrusted on a `REVOKED_SOCKET_CLOSE_CODE` (1008) close.
- `LOGIN_CODE_PATTERN`, `ExchangeResultSchema`, `SOCKET_TRUST_FRAME`, `SocketTrustFrameSchema`, `ENGINE_TOKEN_MAX_LENGTH` (`contract.ts`).
- `isRetryableRpcFailure(alive, error)` (`browser-transport.ts`): true only when the connection is alive, the error is not an `ORPCError` and not an `AbortError`.
- `RPC_UNBOUND_MESSAGE` = `'conciv core not connected yet'` (`browser-transport.ts`, re-exported from `client.ts`); types `RpcClientContext`, `SessionAccessor`, `BrowserRpcConnection`, `ReachabilityListener`.

## Invariants

- `sessions.rename` requires `title` of 1-120 characters and declares `NOT_FOUND`; `sessions.model` declares `NOT_FOUND` and `UNKNOWN_MODEL`; `sessions.effort` takes a `ReasoningEffortSchema` value or null and declares `NOT_FOUND` and `UNSUPPORTED_EFFORT`; `sessions.switchHarness` takes a non-empty `harnessId` and an optional non-empty `model` and declares `NOT_FOUND`, `UNKNOWN_HARNESS`, `UNKNOWN_MODEL` and `SESSION_RUNNING`; `meta.models` and `meta.commands` take a `sessionId`; `SessionMetaSchema` carries a nullable `effort` (`contract.ts`, `rows.ts`).
- `chat.stop` requires `runIds` to be non-empty strings; `chat.permissionDecision`, `chat.uiReply` and `page.reply` declare `UNKNOWN_REQUEST` (`contract.ts`).
- Every `server.*` procedure declares `NO_BUNDLER`; `server.reload` and `server.restart` also declare `APPROVAL_DENIED`; `restart.force` defaults to `false` (`contract.ts`).
- `registry.call` requires a non-empty `name` and `input` as `record<string, unknown>`, and declares the `registryCallErrors` set (`contract.ts`).
- `editor.open` requires `line` to be an integer >= 1 when present (`EditorOpenInputSchema`).
- `ToolCommandSignatureSchema` applies `.catch(undefined)` to `icon` and `label` (invalid values become `undefined`); `errors` defaults to `[]` (`contract.ts`).
- `StreamChunkSchema` checks only that a chunk is a non-null object, then casts it to `ChatEvent` (`contract.ts`).
- `DraftRowSchema` requires `selectionStart` / `selectionEnd` to be integers >= 0 and maps null `attachments` to `[]`; `drafts.set` input omits `updatedAt` (`rows.ts`, `contract.ts`). `MarkerRowSchema.afterMessageId` is the id of the message the marker follows, `null` before the first message (`rows.ts`).
- `BrowserRpcClient.bind` throws `conciv rpc client already bound` when a base is set and `conciv rpc cannot bind an empty api base` for `''` (`client.ts`).
- `heldBrowserRpcLink`'s `link.call` throws `RPC_UNBOUND_MESSAGE` when the current api base is null (`browser-transport.ts`).
- Connections are keyed by `normalizeApiBase` (origin + pathname without trailing slash, resolved against `location.href` when present), so equivalent bases share one connection (`browser-transport.ts`).
- Retry policy (`ClientRetryPlugin`): a call retries any failure that is not an `ORPCError` while its connection is open and its own signal is not aborted, so the `AbortError` oRPC raises for a call in flight when the socket closes is retried; a one-shot call retries `CONNECTION_LOSS_RETRIES` = 12 times `CONNECTION_LOSS_RETRY_DELAY_MS` = 250 apart; a contract event-iterator call (`getEventIteratorSchemaDetails` on its output schema) retries without a cap, each retry waiting for the socket to open again and resuming with oRPC's `lastEventId`; a closed connection is not alive and stops retrying. Extension streams (`ext.*`) are not in the contract and keep the one-shot cap (`browser-transport.ts`).
- The socket link is oRPC's `StandardRPCLink` over our own peer client (`socketClient`, `browser-transport.ts`), with the send rules of oRPC's websocket link (wait while connecting, fail a request when the socket is not open) except that an `ABORT_SIGNAL` frame for a socket that is not open is dropped: oRPC's abort listener awaits that send without a catch, so a call cancelled while the socket closes would otherwise end in an unhandled rejection. The `close` event that always follows closes the peer and ends every call still in flight. A request frame that cannot be encoded or sent rejects its call; any other frame that cannot be sent closes its own call with that error. A received frame that cannot be decoded is logged and closes every call in flight with the decode error, since it names no call the client can trust.
- The engine token lives in localStorage; a `SecurityError` (storage blocked) or `QuotaExceededError` leaves the token in memory only, and any other storage error is thrown (`tokenStorage`, `browser-transport.ts`).
- Trust is per socket: the socket sends `{type: SOCKET_TRUST_FRAME, token}` on every open before any queued call, and an `auth.trust` or `auth.exchange` that succeeds on the socket trusts that socket too. A `REVOKED_SOCKET_CLOSE_CODE` close stops the reconnects (`shouldReconnectOnClose`) and forgets the held token; the next call reopens the socket without it (`browser-transport.ts`).
- The token is stored under `conciv:engine-token:<normalized api base>` in localStorage; an `UNAUTHORIZED` reply or a 1008 close for the token currently held forgets it and sets `untrusted` / `revoked`, a refusal for an older token is ignored (`browser-transport.ts`).

## Side Effects

- Holds one connection per normalized api base in `globalThis.__concivBrowserRpcConnectionsV5`, shared across bundle copies (`connectionEntry` in `browser-transport.ts`); connections for different bases live side by side. Each connection counts its holders (`browserRpcConnection` handles, `subscribeRpcReachability` subscriptions, and `heldBrowserRpcLink`, so every `makeBrowserRpcClient` and `makeExtRpcClient`): it closes and leaves the map when the last holder releases it, the way `acquirePushChannel` shares push sockets. Trust status and reachability votes are events on each connection's `EventTarget`; `subscribeRpcReachability` holds the connection for its base until it unsubscribes, and a vote only dispatches while its connection is still open.
- HTTP calls to `${apiBase}/rpc` through the fetch `RPCLink` (`makeRpcClient` in `client.ts`, node callers only); the browser opens one WebSocket to `${apiBase}/rpc-ws` per connection (`socketConnection` in `browser-transport.ts`).
- Adds the `CONCIV_SESSION_HEADER` header (from `@conciv/protocol/chat-types`) to a socket call when the context has `concivSessionId` (`sessionHeaders`, `browser-transport.ts`).
- `makeRpcClient` is the node client and sends `CONCIV_VERSION_HEADER` (`x-conciv-version`, from `@conciv/protocol/rpc-types`) set to the contract package.json version; browser code uses the socket link (`makeBrowserRpcClient` / `heldBrowserRpcLink`).
- Reads `location.href` when defined (`normalizeApiBase`).
- Calls reachability listeners with `true` when the socket opens and `false` when it closes for any reason but a revocation (`socketConnection`, `browser-transport.ts`).
- `rebind` / `close` release the client's hold on its previous base; the shared connection closes only when no other client holds it (`heldBrowserRpcLink`).
