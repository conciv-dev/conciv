# extensions

## Overview

Conciv extension folder for the Next.js example; re-exports the TanStack extension.

## Interface

- `default` (`tanstack.tsx`): re-export of `@conciv/extension-tanstack`

## Invariants

- None

## Side Effects

- None

## Verification

- Run: `cd apps/examples/nextjs-app && pnpm lint && pnpm build` (the package has no `test` or `typecheck` script)
