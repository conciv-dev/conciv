# examples

## Overview

Example host apps that wire conciv into a framework through `@conciv/it` plugins: Next.js and TanStack Start.

## Subdirectories & Boundaries

- nextjs-app: [nextjs-app/README.md](./nextjs-app/README.md) - Next.js example host app wired to conciv through `@conciv/it/plugin/nextjs`.
- tanstack-start: [tanstack-start/README.md](./tanstack-start/README.md) - TanStack Start (React) example host app wired to conciv through `@conciv/it/plugin/vite`, including the iOS extension pointed at `native/swift/ConcivDemo`.
