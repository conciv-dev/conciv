# src

## Overview

Source root of the TanStack Start example: router factory, generated route tree and the components, lib and routes folders.

## Interface

- `getRouter()` (`router.tsx`): creates the TanStack router with `scrollRestoration: true`, `defaultPreload: 'intent'`
- `routeTree` (`routeTree.gen.ts`): generated by TanStack Router (`pnpm generate-routes`); do not edit
- Subdirectories: [components](./components/README.md), [lib](./lib/README.md), [routes](./routes/README.md)

## Invariants

- `routeTree.gen.ts`: generated file, overwritten by `tsr generate`

## Side Effects

- None

## Verification

- Run: `pnpm exec turbo run typecheck lint --filter=tanstack-start-example` from the repo root (turbo builds the package and its dependencies first) (the package has no `test` script)
