title: Next.js
description: Add conciv to a Next.js app.
---

Copy this prompt into your coding agent. It sets conciv up in your Next.js app:

<SetupPrompt framework="nextjs" />

What you get:

- conciv starts with `next dev`, and adds a conciv button to your pages.
- Your next config is wrapped with `withConciv`.
- Two new files: `instrumentation.ts` and `instrumentation-client.ts`.
- `next build` and `next start` leave conciv out.

## Set up by hand

<Accordions>
<Accordion id="by-hand" title="Install and wire conciv yourself">

<Steps>
<Step>

### Install

```package-install
npm install -D @conciv/it
```

</Step>
<Step>

### Wrap your config

Wrap the default export with `withConciv`:

```ts twoslash title="next.config.ts"
import type {NextConfig} from 'next'
import {withConciv} from '@conciv/it/plugin/nextjs' // [!code ++]

const nextConfig: NextConfig = {
  reactStrictMode: true,
}

export default withConciv(nextConfig) // [!code ++]
```

- `withConciv` picks the engine port when Next.js loads your config.
- Options go in its second argument: `withConciv(nextConfig, {harness: 'codex'})`. See
  [Configuration](/docs/reference/configuration).

</Step>
<Step>

### Add the instrumentation files

Create both files next to your `app` or `pages` folder:

```ts twoslash title="instrumentation.ts"
export {register} from '@conciv/it/plugin/nextjs'
```

```ts twoslash title="instrumentation-client.ts"
import '@conciv/it/plugin/nextjs/widget'
```

- `register` starts the engine when the dev server starts.
- The client file adds the conciv button to your pages.

</Step>
<Step>

### Start your dev server

```bash
npm run dev
```

</Step>
<Step>

### Open your app and log in

Click the conciv button in the corner. Type the 6-digit code your dev server prints in its terminal. See
[Logging in](/docs/usage/logging-in).

</Step>
</Steps>

</Accordion>
</Accordions>

## Edge cases

<Accordions>
<Accordion id="src" title="Your routes live in src/">

Next.js reads the instrumentation files from the folder that holds `app` or `pages`. init writes them to the project
root. With `src/app` or `src/pages`, move both into `src/`:

<Files>
  <File name="next.config.ts" />
  <Folder name="src" defaultOpen>
    <File name="instrumentation.ts" />
    <File name="instrumentation-client.ts" />
    <Folder name="app" />
  </Folder>
</Files>

</Accordion>
<Accordion id="existing" title="You already have an instrumentation file">

init does not overwrite an instrumentation file that holds something else. It prints a card instead. Add the line
from the card to your file. In `instrumentation.ts`, call conciv's `register` from your own:

```ts twoslash title="instrumentation.ts"
import {register as registerConciv} from '@conciv/it/plugin/nextjs'

export async function register() {
  await registerConciv()
}
```

</Accordion>
<Accordion id="card" title="init printed a snippet instead of editing the config">

init edits only a config shape it can read. Otherwise it prints the snippet to paste. Add it as in the manual steps
above.

</Accordion>
</Accordions>
