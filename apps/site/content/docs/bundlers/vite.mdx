Copy this prompt into your coding agent. It sets conciv up in your Vite app:

<SetupPrompt framework="vite" />

What you get:

- conciv starts with `vite dev`, and adds a conciv button to every page the dev server serves.
- The agent can read your dev server's config, URLs and module graph.
- `vite build` leaves conciv out.

## Set up by hand

<Accordions>
<Accordion id="by-hand" title="Install and wire conciv yourself">

<Steps>
<Step>

### Install

```package-install
npm install -D @conciv/it
```

</Step>
<Step>

### Add conciv to your config

Add the import and the `conciv()` call:

```ts twoslash title="vite.config.ts"
import {defineConfig} from 'vite'
import react from '@vitejs/plugin-react'
import conciv from '@conciv/it/plugin/vite' // [!code ++]

export default defineConfig({
  plugins: [
    react(),
    conciv(), // [!code ++]
  ],
})
```

- `@conciv/it/plugin/vite` is the Vite plugin.
- `conciv()` takes no options here. Options go in its one argument: see [Configuration](/docs/reference/configuration).
- Your other plugins stay as they are.

</Step>
<Step>

### Start your dev server

```bash
npm run dev
```

</Step>
<Step>

### Open your app and log in

Click the conciv button in the corner. Type the 6-digit code your dev server prints in its terminal. See
[Logging in](/docs/usage/logging-in).

</Step>
</Steps>

</Accordion>
</Accordions>

## Edge cases

<Accordions>
<Accordion id="astro" title="Astro">

Astro takes Vite plugins under its `vite` key:

```js title="astro.config.mjs"
import {defineConfig} from 'astro/config'
import conciv from '@conciv/it/plugin/vite' // [!code ++]

export default defineConfig({
  vite: {
    plugins: [conciv()], // [!code ++]
  },
})
```

</Accordion>
<Accordion id="devtools" title="Vite DevTools">

With Vite DevTools in your plugins, conciv opens in the DevTools dock instead of the corner. It logs in with no code.
See [Logging in](/docs/usage/logging-in#vite-devtools).

</Accordion>
<Accordion id="card" title="init printed a snippet instead of editing the config">

init edits only a config shape it can read. Otherwise it prints the snippet to paste. Add it as in the manual steps
above.

</Accordion>
</Accordions>
