## Add conciv to Vite

Install `@conciv/it` as a dev dependency:

```package-install
npm install -D @conciv/it
```

Add `conciv()` to the plugins of your Vite config:

```ts twoslash title="vite.config.ts"
import {defineConfig} from 'vite'
import react from '@vitejs/plugin-react'
import conciv from '@conciv/it/plugin/vite' // [!code ++]

export default defineConfig({
  plugins: [
    react(),
    conciv(), // [!code ++]
  ],
})
```

Options go in the one argument of `conciv()`. Learn more in the [Configuration
documentation](/docs/reference/configuration).

Start your dev server with `npm run dev`, open your app, and click the conciv button. Type the 6-digit code your dev
server prints. Learn more in the [Logging in documentation](/docs/usage/logging-in).

## What works

Every feature works on Vite:

- The widget on every page the dev server serves, and the engine that starts with `vite dev`.
- The [dev server tools](/docs/usage/dev-server): the agent reads your config, URLs and module graph.
- `vite build` leaves conciv out.

## Astro

Astro takes Vite plugins under its `vite` key:

```js title="astro.config.mjs"
import {defineConfig} from 'astro/config'
import conciv from '@conciv/it/plugin/vite' // [!code ++]

export default defineConfig({
  vite: {
    plugins: [conciv()], // [!code ++]
  },
})
```
