---
title: Whiteboard
description: Sketch on a canvas over your app, and have the agent build it or draw back.
---

Open the whiteboard, sketch a rough layout over your app, and ask the agent to build it:

```text
Build the layout I sketched on the whiteboard, using our Card component.
```

The whiteboard is an [Excalidraw](https://excalidraw.com) canvas that you and the agent share. You both draw on the same
surface.

<Callout type="warn">
  The whiteboard plugin is not on npm yet. Today it runs only in the example apps inside the conciv repo, which load it
  from its folder. See [Examples](/docs/examples).
</Callout>

## Open the canvas

Click **Whiteboard** above the composer. The canvas opens over the page, and the chat stays usable above it. Press
Escape to close it.

The canvas is see-through, so your page shows under your sketch. For a solid canvas, turn off **Canvas background** in
the general settings.

## Have the agent draw

Ask for a diagram of what you are both looking at:

```text
Draw a diagram of how the checkout page loads its data.
```

The agent draws real Excalidraw shapes, not a picture. Move, restyle or delete anything it drew. It can draw shapes,
connect them with arrows, convert an SVG, and turn a mermaid diagram into shapes.

## Comment on an element

Click **Comment** above the composer, then click an element on the page. The comment is tied to the component's
source, not to a spot on the canvas.

The agent can comment too, and reply to yours:

```text
Leave a comment on each component that still uses the old button.
```

Ask it to work through the open comments:

```text
Go through my comments on the whiteboard and fix each one. Resolve the ones you fixed.
```

## Details

<Accordions type="single">
  <Accordion title="What asks you first">
    Deleting an element, clearing the canvas, resolving a comment and deleting a comment each show a [Permission
    card](/docs/usage/approvals) first.
  </Accordion>
  <Accordion title="The agent draws in a draft">
    The agent draws into a draft first, then adds it to the shared canvas. A draft still open when its turn ends is
    added for it.
  </Accordion>
  <Accordion title="Where the board is kept">
    Each chat session has its own board. The engine keeps it in your project's conciv state, on your machine. Every open
    tab shows the same board as it changes.
  </Accordion>
  <Accordion title="Closing keeps the board">
    Closing the canvas only hides it. It stays loaded, so the agent can keep drawing while it is closed.
  </Accordion>
  <Accordion title="The tool names">
    In code mode the tools are called `external_whiteboard_*`, such as `external_whiteboard_canvas_diagram`.
  </Accordion>
</Accordions>
