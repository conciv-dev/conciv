---
title: Whiteboard
description: Sketch on a canvas over your app, and have the agent build it or draw back.
---

The whiteboard is an [Excalidraw](https://excalidraw.com) canvas over your app that you and the agent draw on
together.

## Add the whiteboard

Add the plugin to the `plugins` option of your conciv config:

```ts twoslash title="vite.config.ts" tab="Vite" tab-group="bundler"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [
    conciv({
      plugins: ['@conciv/plugin-whiteboard'], // [!code ++]
    }),
  ],
})
```

```ts twoslash title="next.config.ts" tab="Next.js" tab-group="bundler"
import type {NextConfig} from 'next'
import {withConciv} from '@conciv/it/plugin/nextjs'

const nextConfig: NextConfig = {}

export default withConciv(nextConfig, {
  plugins: ['@conciv/plugin-whiteboard'], // [!code ++]
})
```

```js title="webpack.config.js" tab="webpack" tab-group="bundler"
const conciv = require('@conciv/it/plugin/webpack')

module.exports = {
  mode: 'development',
  plugins: [
    conciv.default({
      plugins: ['@conciv/plugin-whiteboard'], // [!code ++]
    }),
  ],
}
```

```js title="rspack.config.js" tab="Rspack" tab-group="bundler"
const conciv = require('@conciv/it/plugin/rspack')

module.exports = {
  mode: 'development',
  plugins: [
    conciv.default({
      plugins: ['@conciv/plugin-whiteboard'], // [!code ++]
    }),
  ],
}
```

Restart your dev server. The engine installs the plugin from npm into its own cache, so it does not go in your
`package.json`.

## Sketch a layout

Click **Whiteboard** above the composer. The canvas opens over the page. The chat stays usable above it. Sketch a
rough layout, then ask:

```text title="Prompt"
Build the layout I sketched on the whiteboard, using our Card component.
```

Press Escape to close the canvas. It is see-through, so your page shows under your sketch. For a solid canvas, turn
off **Canvas background** in the general settings.

## Have the agent draw

Ask for a diagram of what you are both looking at:

```text title="Prompt"
Draw a diagram of how the checkout page loads its data.
```

The agent draws real Excalidraw shapes, not a picture. You can move, restyle or delete anything it drew. It can also:

- connect shapes with arrows
- convert an SVG into shapes
- turn a mermaid diagram into shapes

## Comment on an element

Click **Comment** above the composer, then click an element on the page. The comment is tied to the component's
source, not to a spot on the canvas. The agent can comment too. It can also work through yours:

```text title="Prompt"
Go through my comments on the whiteboard and fix each one. Resolve the ones you fixed.
```

Deleting an element, clearing the canvas, and resolving or deleting a comment each show a [Permission
card](/docs/usage/approvals) first.

<Accordions type="single">
  <Accordion title="Where the board is kept">
    Each chat session has its own board. The engine keeps it in your project's conciv state, on your machine. Every open
    tab shows the same board as it changes.
  </Accordion>
  <Accordion title="Closing the canvas does not stop the agent drawing">
    Closing only hides the canvas. The agent draws into a draft first, then adds it to the board, even while the canvas
    is closed.
  </Accordion>
</Accordions>
