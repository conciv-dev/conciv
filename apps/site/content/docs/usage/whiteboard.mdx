The whiteboard is an [Excalidraw](https://excalidraw.com) canvas in the widget that you and the agent share. Sketch a
rough layout and ask the agent to build it, or ask it to diagram what you are both looking at.

```text
sketch the auth flow we just discussed as a flowchart
```

## Turn it on

Add `@conciv/plugin-whiteboard` to `plugins` where you add conciv:

```ts title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [conciv({plugins: ['@conciv/plugin-whiteboard']})],
})
```

The engine installs the package itself when it starts. See [Plugins](/docs/plugins).

## The agent draws real elements

The agent writes real, editable Excalidraw elements, not an image: you can move, restyle and delete anything it drew.
It draws with SVG markup, with element skeletons (rectangles, ellipses, diamonds, text, arrows, lines), or from a
Mermaid diagram.

It draws into a hidden draft, which it can preview before it commits it. You see the drawing once the draft is
committed. A draft
it leaves uncommitted is committed when its turn finishes. When you stop the turn, or the turn fails, the draft stays
a draft.

## Comments anchored to source

A comment is pinned to the canvas, or anchored to a component in your source. The agent can find a component by name
in a file to anchor a comment to it, check whether an anchored comment still points at its element after the code
changed, reply in a thread, and resolve or delete comments.

## What asks first

These tools show a **Permission** card before they run. **Always allow** saves the answer for this project. See
[Approvals](/docs/usage/approvals).

## Where the board is kept

Each chat session has its own board. Boards are kept in your project, in `.conciv/whiteboard/whiteboard.db`. The
`stateRoot` option and the `CONCIV_STATE_ROOT` variable do not move it yet: with either set, the board stays in
your project folder.
