Type what you want in the composer and press Enter. Say "this" or "here" and the agent reads the page you are on before
it changes anything:

```text
Why is this list empty when I am logged out?
```

The agent runs in your project, through your own agent CLI (Claude Code by default). See
[Harnesses](/docs/harnesses) for the others.

## Send a message

- **Enter** sends the message.
- **Shift Enter** starts a new line.
- **Escape** stops the agent while it works.

Your draft is saved for each session, so it comes back after a reload.

## Attach a file or an element

Click **Add an attachment** to add a file, or paste one into the composer. Images reach the agent only on Claude.

Click **Select an element from the page**, then click an element in your app. It is pinned to your message, with its
source file when conciv can find it:

```text
Make this button match the primary button style.
```

See [Page control](/docs/usage/page-control) for what the agent does with it.

## Use commands and mentions

Type `/` to open the commands. You get conciv's own, such as `/model`, plus those of your plugins. On Claude you also
get Claude Code's own commands.

Type `@` to mention something by name: a skill, an agent, a tool, another session or a file in your project. Pick it
from the list and it joins your message.

## Send while the agent works

A message you send while the agent works waits in a queue under the composer. Each queued message has two buttons:

- **Steer** sends it now, into the running turn.
- **Remove** drops it.

**Stop generating** stops the turn. The queued messages go back into your draft, unsent.

## Answer the agent's questions [#generative-ui]

When the agent needs a decision, it puts a card in the thread instead of asking in plain text. A card can hold:

- options to pick from, one or several, with an **Other** field for your own answer
- a yes or no question
- a proposed change to apply
- a few fields to fill in

```text
Add a dark mode toggle. Ask me where it should go.
```

<ImageZoom
  src="/screenshots/chat-choices.png"
  alt="A choices card in the thread: Where should the dark mode toggle go?, three options, a field for another answer and Submit"
  width={1920}
  height={1080}
/>

Answer within two minutes and the agent goes on with your answer. Later, it goes on without it, and your answer
arrives as a new message.

## Find a session

Open the session picker to see your sessions under Today, Yesterday and Earlier. Type to search them.

- Turn on **All projects** to search your other projects too.
- Rest on a row, with the pointer or the arrow keys, to preview it.
- A session from another project has **Copy resume command**, to continue it there.

The list also holds sessions you started in your agent CLI, outside the browser, when the harness keeps them. Rename
the current session with **Rename session** in the panel header.

## Switch the model [#model-and-harness]

Open the model menu. It lists the models of every agent CLI conciv found, and the effort levels of the current model.

Picking a model of another CLI switches the session to that CLI. If the chat already has messages, conciv asks first,
with an estimate of how much history it sends along.

## Shorten a long chat

Click **Compress the conversation** when a chat gets long. conciv asks the agent to sum up the decisions, the current
state and the open threads. On Claude it runs Claude Code's own `/compact` instead.

## Use the Terminal tab

On Claude, the panel has a pinned **Terminal** tab. It runs Claude Code itself, in your project, for this session.

The CLI starts the first time you open the tab. Press Escape in the terminal to interrupt it while it works.

## Details

<Accordions type="single">
  <Accordion title="Too many attachments. Remove some and send again.">
    A message holds at most 16 parts, its text and its attachments together. Remove some attachments, or send them in
    two messages.
  </Accordion>
  <Accordion title="Connect agents">
    The **Connect agents** button shows when an agent CLI on your machine can join this tab. See [Connect your
    agents](/docs/agents).
  </Accordion>
  <Accordion title="Buttons from plugins">
    A plugin can add its own buttons beside the composer. The whiteboard plugin adds **Whiteboard** and **Comment**.
  </Accordion>
  <Accordion title="Only some CLIs keep past sessions">
    Sessions you started outside the browser show only when the harness keeps a history conciv can read. See
    [Harnesses](/docs/harnesses).
  </Accordion>
</Accordions>
