The chat is where you ask the agent for what you want, about the page you have open.

## Send a message

Type in the composer and press Enter. Say "this" or "here", and the agent reads the page before it changes anything:

```text title="Prompt"
Why is this list empty when I am logged out?
```

The agent runs in your project through your own agent CLI, Claude Code by default. Learn more in the
[Harnesses documentation](/docs/harnesses).

- **Enter** sends the message.
- **Shift Enter** starts a new line.
- **Escape** stops the agent while it works.

Your draft is saved for each session, so it comes back after a reload.

## Attach a file or an element

Click **Add an attachment** to add a file, or paste one into the composer. Images reach the agent only on Claude.

Click **Select an element from the page**, then click an element in your app. conciv pins it to your message, with its
source file when it can find it:

```text title="Prompt"
Make this button match the primary button style.
```

Learn more in the [Page control documentation](/docs/usage/page-control).

## Use commands and mentions

Type `/` to open the commands. You get conciv's own commands, plus those of your plugins. On Claude you also get
Claude Code's own commands.

Type `@` to mention a skill, an agent, a tool, another session or a file. Pick it from the list. It joins your
message.

## Send while the agent works

A message you send while the agent works waits in a queue under the composer. Each queued message has two buttons:

- **Steer** sends it now, into the running turn.
- **Remove** drops it.

**Stop generating** ends the turn. The queued messages go back into your draft, unsent.

## Answer the agent's questions [#generative-ui]

When the agent needs a decision, it puts a card in the thread instead of asking in plain text. A card can hold
options to pick from, a yes or no question, a proposed change, or a few fields to fill in.

```text title="Prompt"
Add a dark mode toggle. Ask me where it should go.
```

Answer within two minutes and the agent goes on with your answer. Later, it goes on without it, and your answer
arrives as a new message.

## Find a session

Open the session picker to see your sessions under Today, Yesterday and Earlier. Type to search them.

- Turn on **All projects** to search your other projects too.
- Rest on a row, with the pointer or the arrow keys, to preview it.
- A session from another project has **Copy resume command**, to continue it there.

The list also holds sessions you started in your agent CLI, when the harness keeps them. Learn more in the
[Sessions documentation](/docs/sessions).

## Switch the model [#model-and-harness]

Open the model menu. It lists the models of every agent CLI conciv found, and the effort levels of the current model.

Picking a model of another CLI switches the session to that CLI. If the chat has messages, conciv asks first. It shows
how much history it would send along.

## Shorten a long chat

Click **Compress the conversation** when a chat gets long. conciv asks the agent to sum up the decisions, the state
and the open threads. On Claude it runs Claude Code's own compaction instead.

## Use the Terminal tab

On Claude, the panel has a pinned **Terminal** tab. It runs Claude Code itself, in your project, for this session. The
CLI starts the first time you open the tab.
