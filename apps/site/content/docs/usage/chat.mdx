The chat talks to the harness, running in your project. When you say "this" or "here", conciv's instructions tell the
agent to read the rendered page before it edits anything.

    },

/>

The buttons beside it:

- **Add an attachment**: add a file, or paste one. Images attach only on Claude; the other harnesses take no images.
- **Select an element from the page**: click an element on your page to attach it, with its source file when conciv
  can find it. See [Page control](/docs/usage/page-control).
- **Start a new session**.
- **Compress the conversation**: asks the agent to shorten the conversation so far. Claude runs its own `/compact`;
  the other harnesses get a prompt to summarize the key decisions, the current state and the open threads.
- **Connect agents**: shown when an agent CLI on your machine can be connected to this tab.
- **Stop generating**: while a turn runs.

A plugin can add its own buttons here, such as the whiteboard's **Whiteboard** and **Comment**.

A message holds at most 16 parts, its text and its attachments together; past that, conciv says "Too many
attachments. Remove some and send again." Your draft is saved per session on the engine, so it comes back after a
reload.

## While a turn runs

What you send while the agent works waits in a queue under the composer. The first 3 show, with a count for the rest.
Each has **Steer**, which sends it now, and **Remove**. **Stop generating** stops the turn and puts the queued messages
back in your draft, unsent.

## When the agent asks you [#generative-ui]

The agent can put real controls in the thread instead of asking in plain text. It calls its `conciv_ui` tool with one
of four kinds:

The agent waits up to two minutes for your answer. After that it goes on without it, and your answer reaches it as a
later message.

## Sessions

The session picker lists your sessions under Today, Yesterday and Earlier, and searches them on the engine. Turn on
**All projects** to search beyond this project. It lists the harness's own sessions from this project too, such as a
Claude Code session you started in your terminal, when the harness keeps them (see [Harnesses](/docs/harnesses)).
Rest on a row, with the pointer or the arrow keys, for a preview. A match from another project offers **Copy resume
command**, the command that resumes it there. Rename a session with the **Rename session** button beside its title in the panel
header.

## Model and harness

The model menu lists the models of every harness conciv found, and the effort levels of the current model when it has
them. Picking a model of another harness switches the session to that harness. In a chat that already has messages,
conciv asks first: "Switch harness?", with an estimate of how many tokens of history it sends.

## The Terminal tab

On a harness that has a terminal (Claude today), the panel has a pinned **Terminal** tab: the harness CLI itself, running
in your project for this session. The CLI starts the first time you open the tab. Escape with the focus in the
terminal interrupts the CLI when it is busy. The tab comes from the terminal plugin, which conciv ships and always
loads.
