## What comes with conciv, and what you add

The chat, sessions, the quick terminal, logging in, approvals, settings and the dev server tools are part of conciv
itself. The rest comes from plugins. `@conciv/it` ships two of them; you add the others to `plugins` in your conciv
config (see [Plugins](/docs/plugins)).

| Feature                                           | Plugin                        | How you get it                                       |
| ------------------------------------------------- | ----------------------------- | ---------------------------------------------------- |
| [Page control](/docs/usage/page-control) and grab | `@conciv/plugin-page`         | Shipped, always on.                                  |
| The Terminal tab in the panel                     | `@internal/plugin-terminal`   | Shipped, always on.                                  |
| [Live tests](/docs/usage/live-tests)              | `@conciv/plugin-test-runner`  | Install it and add it to `plugins`.                  |
| [Whiteboard](/docs/usage/whiteboard)              | `@internal/plugin-whiteboard` | Not published yet: only loaded by path, in the repo. |
| Recorder tab                                      | `@conciv/plugin-recorder`     | Install it and add it to `plugins`.                  |
| TanStack Router and Start tools                   | `@conciv/plugin-tanstack`     | Install it and add it to `plugins`.                  |
| The iOS simulator                                 | `@conciv/plugin-ios`          | Install it and add it to `plugins`.                  |

See [Built-ins](/docs/plugins/built-ins) for what each plugin adds.
