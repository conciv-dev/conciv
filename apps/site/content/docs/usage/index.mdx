title: Use conciv
description: Everything you do with the widget in your running app, one task per page.
---

The widget is the conciv button and chat panel in the corner of your dev app. You open it and ask for an outcome in
plain words. The agent works on the page you see and in your source. These pages cover one task each.

## First steps

- [Logging in](/docs/usage/logging-in): let a browser in once, with the code your dev server prints.
- [Chat](/docs/usage/chat): send a message, queue the next one, switch sessions and models.

## Work on your app

- [Page control](/docs/usage/page-control): point at an element and have the agent change it.
- [Dev server](/docs/usage/dev-server): ask how an import resolves, what a file pulls in, or restart the server.
- [Live tests](/docs/usage/live-tests): run your tests from the chat and read the result.
- [Quick terminal](/docs/usage/quick-terminal): drop the chat from the top of the page and split it into panes.

## Stay in control

- [Approvals](/docs/usage/approvals): allow or deny a risky action before it runs.
- [Skills](/docs/skills): write the steps once, and the agent follows them.

## Add more

- [Add plugins](/docs/usage/add-plugins): the `plugins` option, and the plugins conciv ships.
- [Whiteboard](/docs/usage/whiteboard): a shared canvas over the app, in the example apps only for now.
