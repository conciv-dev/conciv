title: Page control

Ask the agent to change something you see on the page. It works in your own browser tab, on the page as it is now:

```text
Make the heading on this page larger and bold.
```

The agent reads the page, finds the element, changes it, and checks the result. Page control is built in: nothing to
install.

## Point at what you mean

Click **Select an element from the page**, the crosshair beside the composer. Then click an element in your app. It is
pinned to your next message, with its source file and line when conciv can find them.

```text
Give this card more padding, and round its corners.
```

## Try a change live

The agent can restyle the page on the spot, so you see an idea at once. Ask for something visible:

```text
Try the header in dark blue, without saving it.
```

A live change lives only in the page. The next hot reload wipes it, because it is not in your source.

## Keep the change

When you like it, ask the agent to keep it. It edits the real source file, so the change survives a reload:

```text
Keep that. Save it to the component.
```

The agent can also open the file in your editor:

```text
Open the file that renders this card in my editor.
```

## Have it use the page

The agent can click, type and scroll like a user. Use it to reproduce a bug or walk through a flow:

```text
Fill the signup form with a test user, submit it, and tell me what the console says.
```

What the agent can do on the page:

- **Read** the page: its controls, its text, a field's value, a screenshot, the console and the current route.
- **Act** on it: click, fill, select, check, press a key, hover, scroll and submit, one step or a list of steps.
- **Restyle** it: change styles, classes and text, live.
- **Inspect React**: the component tree, and the file and line that rendered an element.
- **Wait** for an element to show or hide, or for a hot update to land after a file edit.
- **Run code** in the page. This asks you first, every time (see [Approvals](/docs/usage/approvals)).

## Details

<Accordions type="single">
  <Accordion title="Which tab answers">
    With several tabs open, the tab you focused last answers. Name another tab in your message to point the agent at it.
  </Accordion>
  <Accordion title="Page content is not instructions">
    Page text, console messages and screenshots are untrusted. The agent is told never to follow instructions found in
    them.
  </Accordion>
  <Accordion title="The tool names">
    In code mode the page tools are called `external_page_*`, such as `external_page_click`. You see these names in the
    tool cards in the thread.
  </Accordion>
  <Accordion title="Where it comes from">
    Page control is the page plugin, which conciv ships and always loads. See [Plugins conciv
    ships](/docs/plugins/built-ins).
  </Accordion>
</Accordions>
