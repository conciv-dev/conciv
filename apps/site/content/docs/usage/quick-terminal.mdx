title: Quick terminal
description: Drop the chat down from the top of the page on a hotkey, and split it into panes.
---

Press `Mod+backtick` to drop the chat from the top of the page. `Mod` is Cmd on macOS and Ctrl elsewhere. Press it
again, or Escape, to close it.

The quick terminal is a full-width sheet over your app. The app stays visible and usable below it. Use it when you
want the chat wide, or several chats side by side.

## Split it into panes

<Steps>
  <Step>The first pane opens your latest session.</Step>
  <Step>Click **Split pane** in the header, or press `Mod+D`. The new pane starts a new session.</Step>
  <Step>Drag the gutter between two panes to resize them.</Step>
</Steps>

Each pane has its own session picker, usage, refresh and **Close pane** button.

<Callout type="warn">
  Closing a pane deletes its session and its draft. Closing the last pane closes the quick terminal.
</Callout>

## Resize it

Drag the grip on the bottom edge to set the height. conciv remembers it. Drag the grip almost to the top to close the
quick terminal.

## Pop a pane out

Click **Pop out to a window** to open the focused pane's session in its own browser window. If the browser blocks the
window, the session opens in the corner panel instead.

## Change the hotkey

Open **Settings > Shortcuts**, click **Quick terminal** and press the new keys. The same list holds **New quick terminal
pane** and **Open or close conciv**, the corner panel's key (`Mod+.` by default).

To set the hotkey for everyone on the project, add it to your conciv options:

```ts twoslash title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [
    conciv({
      widget: {quickTerminal: {hotkey: 'Alt+k'}}, // [!code ++]
    }),
  ],
})
```

- `hotkey` takes one key, or a list of keys.
- A key set here is locked in **Settings > Shortcuts**. The row says it is set by this project.

## Turn it off

Set `quickTerminal` to `false`. The hotkey then does nothing, and only the corner panel opens:

```ts twoslash title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [
    conciv({
      widget: {quickTerminal: false}, // [!code ++]
    }),
  ],
})
```

## Details

<Accordions type="single">
  <Accordion title="One layout at a time">
    The corner panel and the quick terminal never show together. Opening one closes the other.
  </Accordion>
  <Accordion title="Other bundlers">
    The `widget` option is the same on every bundler. On Next.js, webpack or Rspack, pass it in the conciv options of
    that bundler's setup. See [Quick start](/docs/quick-start).
  </Accordion>
