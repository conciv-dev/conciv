The quick terminal is the chat as a full-width sheet that drops from the top of the page, over your app.

## Open it

Press `Mod+backtick` to open it, where `Mod` is Cmd on macOS and Ctrl elsewhere. Press it again, or Escape, to close
it. The app stays visible and usable below the sheet.

## Split it into panes

The first pane opens your latest session. Click **Split pane** in the header, or press `Mod+D`, for a new pane with a
new session. Drag the gutter between two panes to resize them.

Each pane has its own session picker, usage, refresh and **Close pane** button.

<Callout type="warn" title="Closing a pane deletes its session">
  Closing a pane deletes its session and its draft. Closing the last pane closes the quick terminal.
</Callout>

## Resize it

Drag the grip on the bottom edge to set the height. conciv remembers it. Drag the grip almost to the top to close
the sheet.

## Pop a pane out

Click **Pop out to a window** to open the focused pane's session in its own browser window. If the browser blocks the
window, the session opens in the corner panel instead.

## Change the hotkey

Open **Settings > Shortcuts**, click **Quick terminal** and press the new keys. The same list holds the corner panel's
key, `Mod+.` by default.

To set the hotkey for everyone on the project, add it to your conciv options:

```ts twoslash title="vite.config.ts" tab="Vite" tab-group="bundler"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [
    conciv({
      widget: {quickTerminal: {hotkey: 'Alt+k'}}, // [!code ++]
    }),
  ],
})
```

```ts twoslash title="next.config.ts" tab="Next.js" tab-group="bundler"
import type {NextConfig} from 'next'
import {withConciv} from '@conciv/it/plugin/nextjs'

const nextConfig: NextConfig = {}

export default withConciv(nextConfig, {
  widget: {quickTerminal: {hotkey: 'Alt+k'}}, // [!code ++]
})
```

```js title="webpack.config.js" tab="webpack" tab-group="bundler"
const conciv = require('@conciv/it/plugin/webpack')

module.exports = {
  mode: 'development',
  plugins: [
    conciv.default({
      widget: {quickTerminal: {hotkey: 'Alt+k'}}, // [!code ++]
    }),
  ],
}
```

```js title="rspack.config.js" tab="Rspack" tab-group="bundler"
const conciv = require('@conciv/it/plugin/rspack')

module.exports = {
  mode: 'development',
  plugins: [
    conciv.default({
      widget: {quickTerminal: {hotkey: 'Alt+k'}}, // [!code ++]
    }),
  ],
}
```

`hotkey` takes one key or a list of keys. A key set here is locked in **Settings > Shortcuts**. Its row says the
project set it.

## Turn it off

Set `quickTerminal` to `false` in the same place. The hotkey then does nothing, and only the corner panel opens:

```ts twoslash title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [
    conciv({
      widget: {quickTerminal: false}, // [!code ++]
    }),
  ],
})
```
