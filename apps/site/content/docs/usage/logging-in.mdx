---
title: Logging in
description: Let a browser use conciv by typing the code your dev server prints.
---

A browser logs in to conciv once, with a 6-digit code your dev server prints. The engine can read your project and
run commands, so it answers only browsers you let in.

## Log in with the code

Click the conciv button. A browser that is not logged in shows it with an **Unauthorized** badge. The **Authorize
conciv** dialog opens and asks for the code.

Opening the dialog makes the engine print a box in your dev server's terminal:

```text title="Dev server terminal"
conciv: a browser asks to connect to this engine
From:    Chrome 142 | macOS at http://localhost:5173
Code:    482913
Link:    http://localhost:5173/#conciv_otp=482913
Expires: 10:42:07
```

- **From** is the browser that asks, and the page it asks from. Check it is yours.
- **Code** is what you type.
- **Link** logs the browser in without typing.
- **Expires** is when the code stops working, 5 minutes after it was printed.

Type the six digits. conciv sends them when the last digit is in. The chat opens. The browser stays logged in.

## Log in with a link

Open the **Link** from the box in the browser you want to log in. conciv reads the code from the address and logs the
browser in. Then it removes the code from the address bar.

To get a link without opening the dialog, run this in your project folder with your page's address:

```bash title="Terminal"
npx @conciv/cli auth link http://localhost:5173/
```

It prints the link as JSON:

```json title="Output"
{"ok": true, "data": {"link": "http://localhost:5173/#conciv_otp=482913", "expiresAt": 1795776127000}}
```

`expiresAt` is when the code stops working, in milliseconds since 1970.

## See who is logged in

Run `revoke` with no browser id. It lists the browsers and logs nobody out:

```bash title="Terminal"
npx @conciv/cli auth revoke
```

It lists each logged-in browser under `trusted`. Each entry has:

- its `id`
- the browser
- the page it logged in from
- when it logged in

## Log a browser out

Pass a browser's id to log out that browser. Pass `--all` to log out every browser:

```bash title="Terminal"
npx @conciv/cli auth revoke <id>
npx @conciv/cli auth revoke --all
```

The browser is cut off at once. Its panel says "This browser is no longer authorized to use conciv." and shows a **Log
in** button.

<Accordions type="single">
  <Accordion title="You opened the dialog again and no new box printed">
    While a code is live, opening the dialog again prints nothing new. The code in the earlier box still works. Click
    **Send a new code** to have the engine print a fresh one.
  </Accordion>
  <Accordion title="Where conciv keeps the logins">
    Each logged-in browser is one row in `.conciv/trusted-browsers.json`, in your project. The file holds a hash of each
    browser's token, never the token itself.
  </Accordion>
  <Accordion id="vite-devtools" title="No code inside Vite DevTools">
    With Vite DevTools in your Vite plugins, conciv opens as a panel in the DevTools dock. That page logs itself in,
    with no code. It shows in the list as `via Vite DevTools`.
  </Accordion>
</Accordions>
