---
title: Logging in
description: Let a browser use conciv by typing the code your dev server prints.
---

The first time a browser opens conciv, you log it in with a 6-digit code. Your dev server prints the code in its
terminal. You do this once per browser.

The engine can read your project and run commands, so it answers only browsers you let in.

## Log in with the code

<Steps>
<Step>

### Open the panel

A browser that is not logged in shows the conciv button with an **Unauthorized** badge. Click it. The **Authorize
conciv** dialog opens and asks for the code.

<Step>

### Find the code in your terminal

Opening the dialog makes the engine print a box in the terminal running your dev server:

```text
╭──────────────────────────────────────────────────────╮
│ conciv: a browser asks to connect to this engine     │
│ From:    Chrome 142 | macOS at http://localhost:5173 │
│ Code:    482913                                      │
│ Link:    http://localhost:5173/#conciv_otp=482913    │
│ Expires: 10:42:07                                    │
╰──────────────────────────────────────────────────────╯
```

- **From** is the browser that asks, and the page it asks from. Check it is yours.
- **Code** is what you type.
- **Link** logs the browser in without typing (see the next section).
- **Expires** is when the code stops working, 5 minutes from now.

</Step>
<Step>

### Type the code

Type the six digits. conciv sends them when the last digit is in, and the chat opens. The browser stays logged in, so
next time the chat opens at once.

</Step>
</Steps>

## Log in with a link

Open the **Link** from the box in the browser you want to log in. conciv reads the code from the address, logs the
browser in, and removes the code from the address bar.

To get a link without opening the dialog, run this in your project folder, with your page's address:

```bash
conciv auth link http://localhost:5173/
```

It prints the link as JSON:

```json
{"ok": true, "data": {"link": "http://localhost:5173/#conciv_otp=482913", "expiresAt": 1795776127000}}
```

- `link` is your address with the code added after `#`.
- `expiresAt` is when the code stops working, in milliseconds since 1970.

No global install is needed. The dev server puts the command in your project as `.conciv/bin/conciv`.

## See who is logged in

Run `conciv auth revoke` with nothing after it:

```bash
conciv auth revoke
```

It lists each logged-in browser under `trusted`, with its `id`, the browser, the page it logged in from, and when.

## Log a browser out

Pass the browser's `id` to log out one browser:

```bash
conciv auth revoke <id>
```

Or log out every browser:

```bash
conciv auth revoke --all
```

The browser is cut off at once. Its panel says "This browser is no longer authorized to use conciv." and shows a **Log
in** button.

## What the panel says

<Accordions type="single">
  <Accordion title="Log in to use conciv on this page.">
    This browser is not logged in to this engine. Click **Log in** and type the code from your terminal.
  </Accordion>
  <Accordion title="This browser is no longer authorized to use conciv.">
    Someone logged this browser out with `conciv auth revoke`. Click **Log in** to log in again.
  </Accordion>
  <Accordion title="That code didn't match. Check your terminal and try again.">
    The digits differ from the newest box in your terminal. After 5 wrong tries the code is dropped. Click **Send a new
    code**.
  </Accordion>
  <Accordion title="That code expired. Send a new code and use the one your terminal prints.">
    The code is older than 5 minutes, or it was dropped after 5 wrong tries. Click **Send a new code**.
  </Accordion>
  <Accordion title="Could not ask the dev server for a code. Please try again.">
    The engine did not answer. Check that the dev server is running, then click **Send a new code**.
  </Accordion>
  <Accordion title="conciv lost connection to the engine.">
    The engine stopped answering, usually because the dev server stopped. Start it again and click **Retry**.
  </Accordion>
  <Accordion title="conciv couldn't reach the engine. Check that the dev server is still running.">
    The panel could not load from the engine. Start the dev server again and click **Retry**.
  </Accordion>
</Accordions>

## Details

<Accordions type="single">
  <Accordion title="A code works once">
    A code logs in one browser, once. Opening the dialog again while a code is live shows the same code. **Send a new
    code** makes the engine print a fresh one.
  </Accordion>
  <Accordion title="Where the logins are kept">
    Each logged-in browser is one row in `.conciv/trusted-browsers.json`, in your project. The file holds a hash of each
    browser's token, never the token itself.
  </Accordion>
  <Accordion title="conciv auth says no engine state was found">
    The command reads `.conciv/server.json` to find the engine. The dev server writes it when it starts. Run the command
    in your project folder, after the dev server has started there once.
  </Accordion>
  <Accordion id="vite-devtools" title="Vite DevTools logs in for you">
    With Vite DevTools in your Vite plugins, conciv opens as a panel in the DevTools dock. That page logs itself in,
    with no code. It shows in the `conciv auth revoke` list as `via Vite DevTools`.
  </Accordion>
</Accordions>
