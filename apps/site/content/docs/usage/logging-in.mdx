---
title: Logging in
description: Log a browser in to conciv with the code the dev server prints, and list or revoke logged-in browsers.
---

conciv can read your project, run commands and open your editor, so each browser logs in once before it uses the
widget.

## Log in with the code

<Steps>
<Step>

Open your app. The widget shows **Log in to use conciv on this page.** Click **Log in**.

</Step>
<Step>

The terminal running your dev server prints a code and a link:

```text
conciv: a browser asks to connect to this engine
From:    Chrome 142 | macOS at http://localhost:5173
Code:    123456
Link:    http://localhost:5173/#conciv_otp=123456
Expires: 10:42:00
```

</Step>
<Step>

Type the code in the **Authorize conciv** dialog, or open the link in the same browser.

</Step>
</Steps>

The browser stays logged in. The code expires a few minutes after it is printed, and too many wrong tries discard it.
Click **Send a new code** for a fresh one.

| Message                                                                  | What to do                                            |
| ------------------------------------------------------------------------ | ----------------------------------------------------- |
| That code didn't match. Check your terminal and try again.               | Type the code from the latest banner.                 |
| That code expired. Send a new code and use the one your terminal prints. | Click **Send a new code**.                            |
| Could not ask the dev server for a code. Please try again.               | Check that the dev server is running, then try again. |

## Log in from a terminal

`conciv auth link` prints a one-time login link for a page your dev server serves. Run it in the project:

```bash
conciv auth link http://localhost:5173/
```

```json
{"ok": true, "data": {"link": "http://localhost:5173/#conciv_otp=123456", "expiresAt": 1763460120000}}
```

Opening the link logs that browser in.

## Vite DevTools

When your Vite config also loads Vite DevTools, conciv adds a conciv dock to it. The widget in that dock logs in
through DevTools, with no code. It is listed as `via Vite DevTools`.

## List and revoke browsers

Run `conciv auth revoke` in the project to list the logged-in browsers. Pass an id to revoke one, or `--all` to revoke every one:

```bash
conciv auth revoke
conciv auth revoke 1a2b3c4d
conciv auth revoke --all
```

Each entry has an `id`, the `browser`, the `origin` it logged in from, and `grantedAt`. A revoked browser is
disconnected at once and shows **This browser is no longer authorized to use conciv.** It can log in again with a new
code.

## The engine is not reachable

**conciv couldn't reach the engine. Check that the dev server is still running.** means the widget lost the engine,
usually because the dev server stopped. Start it again and click **Retry**.
