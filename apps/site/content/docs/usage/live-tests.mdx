---
title: Live tests
description: Run your tests from the chat and read the result in the thread.
---

Ask the agent to run your tests. It calls `test_runner_run`, and a test card in the thread shows the
finished result: how many passed and failed, and each failure with its message.

<ImageZoom
  src="/screenshots/test-card.png"
  alt="A test card in the thread with the finished run: passed and failed counts and the failing test"
  width={1920}
  height={1080}
/>

The Tests tab shows the run live. Rows stream in as each test passes or fails.

The agent reads the last result with `test_runner_status`. A vague request like "run the tests"
makes it list your test files first (through code mode), and it may ask which to run. Name a target to skip that step.

On a failure, it summarizes what broke and asks before changing anything. It does not edit your
code unprompted.

<Callout>
  Live tests need the test-runner plugin. Vitest is the default runner. Playwright is also supported. See [Test
  runners](/docs/test-runners).
</Callout>
