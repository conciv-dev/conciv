Ask the agent to run your tests. It runs them in your project and puts the result in the chat:

```text
Run the tests and fix whatever fails.
```

Live tests come from the test runner plugin. Add it once, as below.

## Add the test runner

<Steps>
<Step>

### Install the plugin

```package-install
@conciv/plugin-test-runner -D
```

</Step>
<Step>

### Add it to your conciv options

```ts twoslash title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [
    conciv({
      plugins: ['@conciv/plugin-test-runner'], // [!code ++]
    }),
  ],
})
```

The plugin runs Vitest by default. Restart your dev server to load it.

</Step>
</Steps>

## Run your tests

Ask in plain words. To run only part of the suite, name a file or an area:

```text
Run the tests for the cart.
```

The agent passes "cart" on, and only the test files whose path matches run.

## Read the result

A test card in the thread shows the finished run: how many passed and failed, grouped by file, and each failure with
its message.

## Watch a run live

Open the **Tests** tab in the panel. With Vitest, each test shows as it passes or fails. With Playwright, the rows
appear together when the run ends.

## Ask about the last run

The agent can read the last result without running again:

```text
Which tests failed in the last run?
```

It can also list your test files without running them:

```text
Which test files cover the checkout?
```

## Use Playwright

Set the plugin's `runner` option to `'playwright'`:

```ts twoslash title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [
    conciv({
      plugins: [['@conciv/plugin-test-runner', {runner: 'playwright'}]], // [!code ++]
    }),
  ],
})
```

The entry becomes a pair: the package name, then its options. See [Test runners](/docs/usage/live-tests) for each runner.

## Details

<Accordions type="single">
  <Accordion title="The runner cannot start">
    The run fails with a message that says why: the framework is not installed in your app, or its config fails to load.
    Install it, or fix the config, and ask again.
  </Accordion>
  <Accordion title="The tool names">
    The agent calls `test_runner_run` and `test_runner_status` directly. Listing files is `external_test_runner_list`,
    in code mode.
  </Accordion>
</Accordions>
