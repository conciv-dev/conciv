The test runner plugin runs your project's own tests in a separate process, in your project folder, and gives the
agent the result: what passed, what failed, and why.

```text
run the math tests
```

## Turn it on

Add `@conciv/plugin-test-runner` to `plugins` where you add conciv. Vitest is the default runner:

```ts title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [conciv({plugins: ['@conciv/plugin-test-runner']})],
})
```

For Playwright, pass the `runner` option:

```ts
conciv({plugins: [['@conciv/plugin-test-runner', {runner: 'playwright'}]]})
```

The engine installs the package itself when it starts. The test framework is your project's own: Vitest or
Playwright installed in your project as usual. See [Plugins](/docs/plugins).

## Options

    },

`jest` and `node-test` are accepted names with no runner behind them yet. With either, the plugin fails to load with
`jest runner not implemented` or `node-test runner not implemented`, and the rest of conciv keeps running.

## The tools

The agent calls them from code mode.

| Tool                 | What it does                                                                                 |
| -------------------- | -------------------------------------------------------------------------------------------- |
| `test_runner_list`   | Lists the test files without running them.                                                   |
| `test_runner_run`    | Runs every test, or only the files whose path matches a `pattern`, and waits for the result. |
| `test_runner_status` | The result of the last finished run, without starting one.                                   |

A result has the counts of passed, failed and skipped tests and the run's duration, each failure with its file, test
name, message, stack and line when known, and one row per test.

When the runner cannot start, because the framework is not installed or its config fails to load, the call fails with
a message that says why, such as `vitest unavailable`.

## From your terminal

The same runner answers the RPC `test-runner`:

```bash
conciv plugin call test-runner list --data '{}'
conciv plugin call test-runner run --data '{"patterns":["math"]}'
conciv plugin call test-runner status
conciv plugin call test-runner stop
```

<TypeTable
  type={{
    list: {required: true, type: '{failedOnly?}', description: 'The test files, without running them.'},
    run: {
      required: true,
      type: '{patterns?, testNamePattern?, failedOnly?}',
      description: 'Runs the tests and prints the result.',
    },
    status: {required: true, type: 'no input', description: 'The result of the last finished run.'},
    stop: {required: true, type: 'no input', description: 'Stops the running tests.'},
  }}
/>

When the runner cannot start, `list` and `run` fail with the code `UNAVAILABLE` and the reason.
