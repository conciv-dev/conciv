Live tests come from the test runner plugin, `@conciv/plugin-test-runner`. It runs your project's tests when you ask.

## Add the test runner

Add the plugin to the `plugins` option of your conciv config:

```ts twoslash title="vite.config.ts" tab="Vite" tab-group="bundler"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [
    conciv({
      plugins: ['@conciv/plugin-test-runner'], // [!code ++]
    }),
  ],
})
```

```ts twoslash title="next.config.ts" tab="Next.js" tab-group="bundler"
import type {NextConfig} from 'next'
import {withConciv} from '@conciv/it/plugin/nextjs'

const nextConfig: NextConfig = {}

export default withConciv(nextConfig, {
  plugins: ['@conciv/plugin-test-runner'], // [!code ++]
})
```

```js title="webpack.config.js" tab="webpack" tab-group="bundler"
const conciv = require('@conciv/it/plugin/webpack')

module.exports = {
  mode: 'development',
  plugins: [
    conciv.default({
      plugins: ['@conciv/plugin-test-runner'], // [!code ++]
    }),
  ],
}
```

```js title="rspack.config.js" tab="Rspack" tab-group="bundler"
const conciv = require('@conciv/it/plugin/rspack')

module.exports = {
  mode: 'development',
  plugins: [
    conciv.default({
      plugins: ['@conciv/plugin-test-runner'], // [!code ++]
    }),
  ],
}
```

Restart your dev server. The engine installs the plugin from npm into its own cache, so it does not go in your
`package.json`. Your test framework does. The plugin runs the one installed in your project.

Then ask in plain words:

```text title="Prompt"
Run the tests and fix whatever fails.
```

## Run part of the suite

Name a file or an area, and only the test files whose path matches run:

```text title="Prompt"
Run the tests for the cart.
```

## Read the result

A test card in the thread shows the finished run. It counts the passed and failed tests, groups them by file, and
shows each failure with its message.

Open the **Tests** tab in the panel to watch a run live. With Vitest, each test shows as it finishes. With Playwright,
the rows appear together when the run ends.

## Ask about the last run

The agent can read the last result without a new run. It can also list your test files without running them:

```text title="Prompt"
Which tests failed in the last run? Which test files cover the checkout?
```

## Pick a runner

The `runner` option names your test framework. Write the entry as a pair, the package name and then its options:

```ts twoslash title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [
    conciv({
      plugins: [['@conciv/plugin-test-runner', {runner: 'playwright'}]], // [!code ++]
    }),
  ],
})
```

- **`vitest`** is the default. It drives your project's own `vitest/node`, and each result streams in as it finishes.
- **`playwright`** runs `playwright test` with its JSON reporter. The results arrive when the whole run ends.

<Callout type="warn" title="jest and node-test are not built yet">
  The option accepts `jest` and `node-test`, but neither runner exists yet. Pick one and the plugin fails when it
  starts.
</Callout>
