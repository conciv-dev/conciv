---
title: Live tests
description: Run your tests from the chat and read the result in the thread.
---

Ask the agent to run your tests. It calls `test_runner_run`, and a test card in the thread shows the finished result:
how many passed and failed, grouped by file, and each failure with its message.

<ImageZoom
  src="/screenshots/test-card.png"
  alt="A test card in the thread with the finished run: passed and failed counts and the failing test"
  width={1920}
  height={1080}
/>

The **Tests** tab in the panel shows the run live. With the default `vitest` runner, rows stream in as each test passes
or fails. With the `playwright` runner, the rows appear together when the run ends.

The agent has three tools:

- `test_runner_run` runs every test, or with a `pattern` only the test files whose path matches it, and waits for the
  result. Name a file or an area in your request and the agent can pass it as the pattern.
- `test_runner_status` reads the last finished result without starting a run.
- `external_test_runner_list`, in code mode, lists the test files without running them.

When the runner cannot start (the framework is not installed, or its config fails to load), the call fails with a
message that says why.

<Callout>
  Live tests come from the test-runner plugin, `@conciv/plugin-test-runner`. conciv does not ship it: install it and add
  it to `plugins`. Vitest is the default runner, and Playwright is the other one. See [Test
  runners](/docs/test-runners).
</Callout>
