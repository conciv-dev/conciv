---
title: Approvals
description: What asks before it runs, per harness, and how the Permission card works.
---

Two things can ask you before they run: the harness itself, and some of conciv's tools. Either way the question shows
as a **Permission** card in the chat, and the action runs only once you allow it.

## The card

The card names what asks: the action and what it acts on, such as `page_eval` and the code it would run.

<TypeTable
  type={{
    'Allow once': {required: true, type: '⌘ Enter or Ctrl Enter', description: 'Runs it this once.'},
    Deny: {required: true, type: 'Escape', description: 'Refuses it.'},
    'Allow always': {
      required: true,
      type: 'button',
      description: 'Allows it in this project from now on. Shown only when the ask can be remembered.',
    },
  }}
/>

The keys work while the card has focus. The card waits until you answer. A harness's ask dies with its turn: stop the
turn and its card goes.

## The harness

What the harness asks about is up to the harness. conciv shows its questions as cards.

| Harness    | What asks                                                                                                                                                                                                                                                                                                                                     |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Claude     | Claude Code runs in its `auto` permission mode and decides what to ask. conciv also gives it ask rules, so these Bash commands always ask: `git push` with `--force`, `-f`, `--delete`, `-d` or `:branch`; `git reset --hard`; `git clean`; `git branch -D`; `git gc --prune`; `rm -r`, `-R`, `-fr` or `-fR`; `chmod -R`; `chown -R`; `sudo`. |
| Codex      | Nothing. Codex runs with `approvalPolicy: 'never'` in the `workspace-write` sandbox: the sandbox limits what it can do.                                                                                                                                                                                                                       |
| Gemini CLI | What Gemini CLI asks about.                                                                                                                                                                                                                                                                                                                   |
| OpenCode   | Nothing reaches conciv: OpenCode's own asks are not shown as cards yet.                                                                                                                                                                                                                                                                       |
| Pi         | Pi has no chat yet.                                                                                                                                                                                                                                                                                                                           |

A harness's ask can only be allowed once or denied.

## Outside agents

An agent CLI connected with `conciv mcp connect` can drive your open tabs from your own terminal (see [Connect your
agents](/docs/quick-start/agents)). `hubAccess` decides whether it has to be let in first.

<TypeTable
  type={{
    open: {required: true, type: 'default', description: 'No card. A connected agent can use any open session.'},
    project: {
      required: true,
      type: 'option',
      description:
        'The first call to a session shows a Permission card for the agent. Allow once lets that call in; Allow always lets the agent in for this project from now on.',
    },
  }}
/>

The call waits on the card until you answer it, or until the agent gives up on the call. An outside agent can never
answer a Permission card, and never connect or disconnect agents: you do that in the tab.
