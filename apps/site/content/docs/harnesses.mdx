A harness is the agent CLI that answers in the chat. conciv runs it on your machine, in your project folder, with your
own login. Pick the one a new chat starts with:

```ts twoslash title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [conciv({harness: 'codex'})],
})
```

- `harness` is one of `claude`, `codex`, `opencode`, `gemini-cli` or `pi`.
- Left out, a new chat starts with `claude`.

## Install the CLI and log in

conciv does not install the CLI or log you in. Do both first, in your own terminal. For Claude Code:

```bash
claude
```

Log in when it asks, then quit. conciv finds the CLI on the `PATH` of the process that started your dev server.

## Pick one

Use the harness you already work with. Each one keeps its own login, models and settings, and conciv reuses them.

- **Claude** gives you the most: `/` commands, image attachments, permission cards and a terminal tab.
- **Codex** never asks for permission. Its sandbox limits what it can do instead.
- **OpenCode** and **Gemini CLI** chat in the panel. Gemini CLI shows permission cards.
- **Pi** has no chat in conciv yet. Its past sessions still show in the session list.

The full comparison is at the [end of the page](#what-each-one-can-do).

## Switch harness in a session

The model menu in the panel lists the harness you set, plus every other harness whose CLI is on your `PATH`. Pick one
there to switch during a session. See [Chat](/docs/usage/chat#model-and-harness).

## Set it for one run

Set `CONCIV_HARNESS` to try a harness without editing your config:

```bash
CONCIV_HARNESS=opencode pnpm dev
```

`harness` in the config wins over the variable.

## Claude

conciv runs Claude Code in its `auto` permission mode. It adds ask rules for risky Bash commands. Those asks become
permission cards in the chat. conciv's instructions are added after Claude Code's own system prompt.

## Codex

conciv runs Codex with `approvalPolicy: 'never'` in the `workspace-write` sandbox. It never shows a permission card.

## Gemini CLI

conciv runs Gemini CLI over ACP, as `gemini --acp -m <model>`. The default model is `gemini-3-pro-preview`.
