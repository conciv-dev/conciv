The conciv repo has two example apps with conciv already set up. Run one to try every feature, the plugins included,
on a real app.

## Available examples

| Example        | What it shows                                                                                                                | Source                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| TanStack Start | Vite, with the test runner, TanStack, recorder and whiteboard plugins, a project plugin, and `Alt+k` for the quick terminal. | [View source](https://github.com/conciv-dev/conciv/tree/main/apps/examples/tanstack-start) |
| Next.js        | `withConciv`, with the test runner, TanStack and whiteboard plugins.                                                         | [View source](https://github.com/conciv-dev/conciv/tree/main/apps/examples/nextjs-app)     |

<Callout type="info" title="The whiteboard is only here">
  The whiteboard plugin is not on npm yet, so these examples are the one place to try it.
</Callout>

## Local development

Clone the repo and install:

```bash title="Terminal"
git clone https://github.com/conciv-dev/conciv.git
cd conciv
pnpm install # <- the repo pins its pnpm version, and needs Node 26 or newer
```

Then start one example:

```bash title="Terminal"
pnpm turbo run dev --filter=tanstack-start-example # <- or --filter=nextjs-app
```

The first run builds the conciv packages the example uses, then starts its dev server. It prints the address to open.
Click the conciv button. Type the code the dev server prints in its terminal. Then ask the agent about the page:

```text title="Prompt"
What is on this page, and which file renders it?
```

A few things to notice:

- The TanStack Start example's `conciv/plugins/deploy` folder is a project plugin. conciv loads it with no config
  entry.
- The examples load their plugins from the repo by folder path. Your own app lists published plugins by package name,
  as in [Add plugins](/docs/usage/add-plugins).
- The chat runs a real agent CLI, so it must be installed and logged in.
