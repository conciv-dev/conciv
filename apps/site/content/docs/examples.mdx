## 1. Get the repo

```bash
git clone https://github.com/conciv-dev/conciv.git
cd conciv
pnpm install
```

The repo pins its pnpm version, and needs Node 26 or newer.

## 2. Start an example

Start the TanStack Start example:

```bash
pnpm turbo run dev --filter=tanstack-start-example
```

Or the Next.js example:

```bash
pnpm turbo run dev --filter=nextjs-app
```

The first run builds the conciv packages the example uses, then starts its dev server. It prints the address to open.

## 3. Open it and log in

Open the printed address and click the conciv button. The first time, type the code the dev server prints in its
terminal. See [Logging in](/docs/usage/logging-in).

Then ask the agent something about the page:

```text
What is on this page, and which file renders it?
```

## What each example shows

- **TanStack Start** sets the quick terminal hotkey to `Alt+k`. Its `conciv/plugins/deploy` folder is a project
  plugin, which conciv loads with no config entry.
- **Next.js** wraps its config with `withConciv`, the Next.js setup from [Quick start](/docs/bundlers/nextjs).
