```bash
pnpm install
```

### TanStack Start

```bash
pnpm --filter tanstack-start-example dev
```

Its `vite.config.ts` loads the test-runner, TanStack, recorder and whiteboard plugins by their workspace folders (your own app lists
them by package name, see [Plugins](/docs/plugins#add-a-plugin-in-the-conciv-options)), and sets the
quick terminal hotkey to `Alt+k`. Its `conciv/plugins/deploy` folder is a project plugin, loaded with no config entry
(see [Plugins](/docs/plugins)).

### Next.js

```bash
pnpm --filter nextjs-app dev
```

Its `next.config.ts` adds the test-runner, TanStack and whiteboard plugins (the whiteboard is private and not on
npm). In your own app you list the published ones by package name:

```ts title="next.config.ts"
export default withConciv(nextConfig, {
  plugins: ['@conciv/plugin-test-runner', '@conciv/plugin-tanstack'],
})
```

The example app itself points at its workspace copies with `./node_modules/...` paths, so it runs the plugins built
in this repo instead of the published ones. A plugin of your own is listed the same way, as a `./` path to its folder.

Open the printed URL and click the conciv button. The first time, log in with the code the dev server prints (see
[Logging in](/docs/usage/logging-in)).
