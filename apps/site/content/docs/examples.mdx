```bash
pnpm install
```

### TanStack Start

```bash
pnpm --filter tanstack-start-example dev
```

Its `vite.config.ts` loads the test-runner, TanStack, recorder and whiteboard plugins by their folders, and sets the
quick terminal hotkey to `Alt+k`. Its `conciv/plugins/deploy` folder is a project plugin, loaded with no config entry
(see [Plugins](/docs/plugins)).

### Next.js

```bash
pnpm --filter nextjs-app dev
```

Its `next.config.ts` loads the test-runner, TanStack and whiteboard plugins from `node_modules`:

```ts title="apps/examples/nextjs-app/next.config.ts"
export default withConciv(nextConfig, {
  plugins: [
    './node_modules/@conciv/plugin-test-runner',
    './node_modules/@conciv/plugin-tanstack',
    './node_modules/@internal/plugin-whiteboard',
  ],
})
```

Open the printed URL and click the conciv button. The first time, log in with the code the dev server prints (see
[Logging in](/docs/usage/logging-in)).
