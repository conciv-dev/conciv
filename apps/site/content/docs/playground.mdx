A playground is the real conciv panel, playing a scripted session in your browser. Nothing runs on a server, and no
agent CLI is needed. Each one also sits on the page that explains it.

## Local development

Prefer a real app? The conciv repo has two example apps with conciv already set up. Clone the repo and install:

```bash title="Terminal"
git clone https://github.com/conciv-dev/conciv.git
cd conciv
pnpm install
```

Then start an example:

```bash title="Terminal"
pnpm turbo run dev --filter=tanstack-start-example # <- or --filter=nextjs-app
```

- The repo pins its pnpm version, and needs Node 26 or newer.
- The first run builds the conciv packages the example uses. It then prints the address to open.
- These examples run a real agent CLI, so it must be installed and logged in.

Learn more in the [Examples documentation](/docs/examples).

## Write a playground

A playground is one script file and one line of MDX. The script lists what the reader types and what the agent answers:

```ts title="apps/site/src/playground/scripts/chat/hello.ts"
import type {PlaygroundScript} from '../../script'

export default {
  title: 'Say hello',
  screen: 'panel', // <- or 'quick' for the quick terminal
  plugins: [], // <- browser parts to load, such as 'test-runner'
  turns: [
    {
      prompt: 'Rename the heading to Hello.', // <- typed into the real composer
      replies: [
        {
          kind: 'tool',
          name: 'page_settext',
          input: {selector: 'h1', text: 'Hello'},
          result: {ok: true},
          page: {heading: 'Hello'},
        },
        {kind: 'text', text: 'The heading says **Hello** now.'},
      ],
    },
  ],
} satisfies PlaygroundScript
```

Add it to `playground-scripts.ts`, then put it on a page:

```tsx title="content/docs/usage/chat.mdx"
<Playground page="vite-react" script="chat/hello" caption="Say hello." />
```

A few things to notice:

- A tool reply can ask first (`ask`), change the demo page (`page`), or run from code mode (`mode: 'code'`).
- The script is typed. A change to the widget's contract fails the site's typecheck, not the page.
- Under reduced motion, each step jumps to its end. On a narrow screen, the page shows the transcript only.
