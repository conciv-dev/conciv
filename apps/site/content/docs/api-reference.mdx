Each package name links to its page on npm. The guides beside it show the package in use. Most apps install only
`@conciv/it`. It brings in everything under [Installed for you](#installed-for-you).

<Callout type="success" title="Looking for an option or a command?">
  Every config option is in the [Configuration reference](/docs/reference/configuration), and every command in the [CLI
  reference](/docs/reference/cli). The plugin API has its own [reference](/docs/plugins/reference).
</Callout>

## Set up

| Package                                                        | Purpose                                                                | Related guides                                                                                                                    |
| -------------------------------------------------------------- | ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| [@conciv/it](https://www.npmjs.com/package/@conciv/it)         | The bundler plugin: adds the engine and the widget to your dev server. | [Vite](/docs/bundlers/vite), [Next.js](/docs/bundlers/nextjs), [webpack](/docs/bundlers/webpack), [Rspack](/docs/bundlers/rspack) |
| [@conciv/cli](https://www.npmjs.com/package/@conciv/cli)       | `init`, the tools your agent calls, login and MCP connections.         | [Getting started](/docs/getting-started), [CLI](/docs/reference/cli), [Connect your agents](/docs/agents)                         |
| [@conciv/skills](https://www.npmjs.com/package/@conciv/skills) | Agent skills that teach coding agents to build with conciv.            | [Getting started](/docs/getting-started#installation)                                                                             |
| [@conciv/try](https://www.npmjs.com/package/@conciv/try)       | Try conciv live on conciv.dev, with the agent already on your machine. | [Playground](/docs/playground)                                                                                                    |
