A skill is guidance the agent loads when a task matches its description, through conciv's `skill` tool. It is not
added to every prompt.

Plugins add skills of their own, such as `tanstack` or `test-runner`. See [Engine SDK](/docs/plugins/engine#skills).

## Your own skills

Put a skill in one of these folders. The engine reads them in this order, so a project skill replaces a home skill
with the same id.

A skill is a folder holding a `SKILL.md`, found up to six folders deep, or a `.md` file at the top of the folder. Its
id is the folder name (`release`) or the file name (`style`).

```md title="conciv/skills/release/SKILL.md"
---
name: release
description: Use when the user asks to cut a release of this app.
---

# Release

Run the checks, bump the version, and write the changelog entry.
```

Add, edit or remove a skill and the running engine picks it up: no restart. A file whose frontmatter does not parse is
skipped. Folders whose name starts with `.` are skipped.

Skills in `.claude/skills` and `.agents/skills` are left to the agent CLI, which already loads them.
