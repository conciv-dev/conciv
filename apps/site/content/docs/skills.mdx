title: Skills
description: The built-in skills, and your own skills from a folder in the project.
---

A skill is a Markdown guide the agent loads when a task needs it. The agent sees each skill's id, name and
description, and loads the full text with its `skill` tool.

## Built-in skills

| id       | What it covers                                                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `conciv` | Questions about conciv itself: how it works, installing and configuring it, choosing a harness, the widget, the CLI, plugins, troubleshooting. |
| `report` | Reporting a conciv issue: it collects diagnostics, adds your reproduction steps and publishes the issue with the GitHub CLI.                   |

## Add your own

Put a folder with a `SKILL.md` in `conciv/skills` at the project root:

<Files>
  <Folder name="conciv" defaultOpen>
    <Folder name="skills" defaultOpen>
      <Folder name="greet" defaultOpen>
        <File name="SKILL.md" />
      </Folder>
    </Folder>
  </Folder>
</Files>

```md title="conciv/skills/greet/SKILL.md"
---
name: greet
description: How to greet the user
---

Greet twice.
```

The engine watches the folder: a new or changed skill reaches the agent without a restart.

- The skill's id is its folder name. A `.md` file directly in `conciv/skills` is a skill too, with the file name as
  its id.
- Files beside `SKILL.md` belong to the skill. The agent sees their paths when it loads the skill.
- `conciv/skill` works the same way. So do `skills` and `skill` in the conciv home folder (`CONCIV_HOME`), for skills
  every project gets.

## Frontmatter

<TypeTable
  type={{
    name: {type: 'string', description: 'The name the agent sees. Defaults to the id.'},
    description: {
      type: 'string',
      description: 'When to use the skill. A skill without one is left out of the list the agent sees.',
    },
    'disable-model-invocation': {
      type: 'boolean',
      description: '`true` leaves the skill out of the list the agent sees.',
    },
  }}
/>

The agent can still load a skill left out of the list when you name it.

## Skills from a plugin

A plugin adds skills in code with `ctx.skill.transform`. See [Engine SDK](/docs/plugins/engine#skills).
