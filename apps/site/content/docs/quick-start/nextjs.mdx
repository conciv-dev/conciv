---
title: Next.js
description: Add conciv to a Next.js app.
---

Next.js needs three pieces: `withConciv` around your config, an `instrumentation.ts` that starts the engine, and an
`instrumentation-client.ts` that adds the widget.

<Tabs items={['init', 'By hand']}>

<Tab value="init">

```bash
npx @conciv/cli@latest init
```

init finds Next.js in your `package.json`, installs `@conciv/it`, wraps the default export of your next config with
`withConciv`, and creates `instrumentation.ts` and `instrumentation-client.ts` in the project folder. It does not
overwrite an instrumentation file that already holds something else. If it cannot read the shape of your config, it
prints the snippet to paste instead. See [Quick start](/docs/quick-start) for what it asks.

</Tab>

<Tab value="By hand">

<Steps>
<Step>

### Install

<Tabs items={['pnpm', 'npm', 'yarn']}>

<Tab value="pnpm">

```bash
pnpm add -D @conciv/it
```

</Tab>

<Tab value="npm">

```bash
npm install -D @conciv/it
```

</Tab>

<Tab value="yarn">

```bash
yarn add -D @conciv/it
```

</Tab>

</Tabs>

</Step>
<Step>

### Wrap your config

```ts title="next.config.ts"
import type {NextConfig} from 'next'
import {withConciv} from '@conciv/it/plugin/nextjs'

const nextConfig: NextConfig = {}

export default withConciv(nextConfig)
```

Options go in the second argument of `withConciv`. See [Configuration](/docs/configuration).

</Step>
<Step>

### Add the instrumentation files

```ts title="instrumentation.ts"
export {register} from '@conciv/it/plugin/nextjs'
```

```ts title="instrumentation-client.ts"
import '@conciv/it/plugin/nextjs/widget'
```

Put them in the folder that holds your `app` or `pages` folder: the project root, or `src/`.

</Step>
</Steps>

<Steps>
<Step>

### Start your dev server

```bash
next dev
```

`withConciv` picks the engine port when Next.js loads your config, and `register` starts the engine on it. See
[Configuration](/docs/configuration#port) for how the port is chosen.

</Step>
<Step>

### Open your app and log in

Click the conciv button. The first time, it asks for the 6-digit code your dev server just printed in its terminal.
See [Logging in](/docs/usage/logging-in).

</Step>
</Steps>

`next build` and `next start` do not start the engine, and the widget does not start in a production build.
