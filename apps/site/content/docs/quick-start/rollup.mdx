<Tabs items={['init', 'Manual']}>

<Tab value="init">

```bash
npx @conciv/cli@latest init
```

init detects Rollup and prints a card instead of wiring anything: the `@conciv/it/plugin/rollup`
entry exists but is a build-only no-op today. It does not boot the engine or inject the widget yet.

</Tab>

most Rollup apps can adopt the Vite plugin directly.
