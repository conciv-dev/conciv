---
title: Connect your agents
description: Let the coding agent in your own terminal see and drive your open conciv tabs.
---

The chat in the panel runs its own harness. Your own terminal agent, such as Claude Code or Codex in another window,
is separate. Teach it the conciv CLI and connect it to conciv, and it can find your open conciv tabs and use the same
tools the chat uses.

`conciv init` does this for you. You can also do it by hand.

The section in `AGENTS.md` tells the agent to use `conciv tools page ...` for anything in the running browser, and to
run `conciv tools --help` for every command. If init cannot write it (for example the file has a start marker with no
end marker), it prints the section as a card for you to paste.

The Claude Code plugin's bridge reads the engine's address from `.conciv/mcp-endpoint.json`, which the engine writes
when it starts. If the plugin install fails, init prints the commands to run yourself:

```bash
claude plugin marketplace add .conciv/claude-connect
claude plugin install conciv-connect@conciv --scope local
claude plugin update conciv-connect@conciv --scope local
```

## Connect by hand

`conciv mcp connect` adds `conciv-hub` to that agent's MCP config. It takes `claude`, `codex`, `gemini-cli` or
`opencode`.

```bash
npx @conciv/cli@latest mcp connect claude
```

On success it prints `{"ok":true,"data":{"connected":"claude"}}`.

The connected agent gets three MCP tools: `list_tabs` lists the open conciv tabs of every running dev server on this
machine, and `execute_typescript` and `discover_tools` run on the tab you name with `tab`.

The panel shows the same connections: a **Connected agents** row above the composer, and a **Connect agents** menu in the
composer toolbar.

## Letting an agent in

By default a connected agent can use any open tab with no question. Set `hubAccess: 'project'` to have the tab ask
first. See [Configuration](/docs/configuration) and [Approvals](/docs/usage/approvals).
