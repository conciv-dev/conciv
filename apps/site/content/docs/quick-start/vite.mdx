Vite is the full integration. The plugin boots the engine, bridges the live page, and injects the
widget for you.

<Tabs items={['init', 'Manual']}>

<Tab value="init">

```bash
npx conciv@latest init
```

init detects Vite from your package.json, installs `@conciv/it` with your package manager, and adds
the `@conciv/it/plugin/vite` plugin to your Vite config. If it cannot prove the shape of your
config, it prints the exact snippet to paste instead.

init refuses a dirty git tree; commit first or pass `--force`. `--dry-run` prints the plan without
touching anything.

</Tab>

<Tab value="Manual">

<Steps>
<Step>

### Install

<Tabs items={['pnpm', 'npm', 'yarn']}>

<Tab value="pnpm">

```bash
pnpm add -D @conciv/it
```

</Tab>

<Tab value="npm">

```bash
npm install -D @conciv/it
```

</Tab>

<Tab value="yarn">

```bash
yarn add -D @conciv/it
```

</Tab>

</Tabs>

</Step>
<Step>

### Add the plugin

```ts title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [conciv()],
})
```

</Step>
<Step>

### Run and open

Start your dev server, open the app, and click the conciv button.

```bash
vite dev
```

</Step>
</Steps>

</Tab>

</Tabs>
