---
title: Vite
description: Add conciv to a Vite app, or to a framework built on Vite such as Astro.
---

Add conciv to your Vite config. In `vite dev` it starts the engine, adds the widget to every page the dev server
serves, and gives the agent your dev server's config, URLs and module graph. `vite build` leaves it out.

<Tabs items={['init', 'By hand']}>

<Tab value="init">

```bash
npx @conciv/cli@latest init
```

init finds Vite (or Astro) in your `package.json`, installs `@conciv/it`, and adds `conciv()` to the `plugins` of
your config. If it cannot read the shape of your config, it prints the snippet to paste instead. See
[Quick start](/docs/quick-start) for what it asks.

</Tab>

<Tab value="By hand">

<Steps>
<Step>

### Install

<Tabs items={['pnpm', 'npm', 'yarn']}>

<Tab value="pnpm">

```bash
pnpm add -D @conciv/it
```

</Tab>

<Tab value="npm">

```bash
npm install -D @conciv/it
```

</Tab>

<Tab value="yarn">

```bash
yarn add -D @conciv/it
```

</Tab>

</Tabs>

</Step>
<Step>

### Add conciv to your config

<Tabs items={['vite.config.ts', 'astro.config.mjs']}>

<Tab value="vite.config.ts">

```ts title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [conciv()],
})
```

</Tab>

<Tab value="astro.config.mjs">

```js title="astro.config.mjs"
import {defineConfig} from 'astro/config'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  vite: {
    plugins: [conciv()],
  },
})
```

</Tab>

</Tabs>

</Step>
</Steps>

</Tab>

</Tabs>

<Steps>
<Step>

### Start your dev server

```bash
pnpm dev
```

</Step>
<Step>

### Open your app and log in

Click the conciv button. The first time, it asks for the 6-digit code your dev server just printed in its terminal.
See [Logging in](/docs/usage/logging-in).

</Step>
</Steps>

<Callout>
  With Vite DevTools in your plugins, conciv opens in the DevTools dock instead of the corner, and logs in with no code.
  See [Logging in](/docs/usage/logging-in#vite-devtools).
</Callout>
