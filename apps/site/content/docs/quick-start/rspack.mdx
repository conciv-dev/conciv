title: Rspack
description: Add conciv to an Rspack app.
---

Rspack works like webpack. The entry boots the engine, and you inject the widget yourself with
`widgetUrl`.

<Tabs items={['init', 'Manual']}>

<Tab value="init">

```bash
npx conciv@latest init
```

init detects Rspack from your package.json, installs `@conciv/it` with your package manager, and
adds the `@conciv/it/plugin/rspack` plugin to your Rspack config. Widget injection stays manual:
init prints a card telling you to serve `@conciv/widget/global` and set `widgetUrl`.

init refuses a dirty git tree; commit first or pass `--force`. `--dry-run` prints the plan without
touching anything.

</Tab>

<Tab value="Manual">

<Steps>
<Step>

### Install

```bash
npm install -D @conciv/it
```

</Step>
<Step>

### Add the plugin

```js title="rspack.config.js"
const conciv = require('@conciv/it/plugin/rspack')

module.exports = {
  plugins: [conciv.default()],
}
```

</Step>
<Step>

### Inject the widget

The widget bundle ships as `@conciv/widget/global`. Serve it and set `widgetUrl` so the script is
added to your page. See [Configuration](/docs/configuration#widgeturl).

</Step>
</Steps>

</Tab>

</Tabs>

<Callout>
  Rspack is less complete than [Vite](/docs/quick-start/vite). The live page bridge is Vite only. Chat, tests, and
  approvals work once the engine is booted and the widget is on the page.
</Callout>
