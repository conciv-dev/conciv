</Callout>

Copy this prompt into your coding agent. It sets conciv up for your iOS app:

<SetupPrompt framework="ios" />

What you get:

- A web dev server with conciv in its config. It runs the engine.
- The `ConcivWidget` Swift package in your app.
- The conciv button floating over your own UI in the simulator.

## Set up by hand

<Accordions>
<Accordion id="by-hand" title="Add the Swift package yourself">

<Steps>
<Step>

### Set up the dev server

conciv for iOS loads the widget from an engine. A web dev server with conciv runs it. Set one up with the
[Vite](/docs/quick-start/vite) steps, then start it.

</Step>
<Step>

### Add the package

In Xcode, use File > Add Package Dependencies and paste this URL:

```text
https://github.com/conciv-dev/conciv-swift.git
```

Pick the version that matches your `@conciv/it` version. Add the `ConcivWidget` product to the target that shows
your UI. The package needs iOS 17.

</Step>
<Step>

### Attach the widget

Call `attach()` once at app start:

```swift title="MyApp.swift"
import SwiftUI
import ConcivWidget // [!code ++]

@main
struct MyApp: App {
  init() { // [!code ++]
    ConcivWidget.attach() // [!code ++]
  } // [!code ++]

  var body: some Scene {
    WindowGroup {
      ContentView()
    }
  }
}
```

- `attach()` finds the key window itself, so `App.init` is early enough.
- It finds the engine on its own. See "How the app finds the engine" below.
- In a Release build it does nothing. Run a Debug build to see the widget.

</Step>
<Step>

### Run the app and log in

Build and run a Debug build in the simulator. Tap the conciv button. Type the 6-digit code your dev server prints in
its terminal.

</Step>
</Steps>

</Accordion>
</Accordions>

## Let the agent build and run the app

Add `@conciv/plugin-ios`, and the agent can build, launch, screenshot and read the logs of your app:

```package-install
npm install -D @conciv/plugin-ios
```

Then add it to the plugins in your conciv config:

```ts twoslash title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [
    conciv({
      plugins: [['@conciv/plugin-ios', {projectRoot: './ios', bundleId: 'com.example.MyApp'}]], // [!code ++]
    }),
  ],
})
```

- `projectRoot` is the folder of your Xcode project, relative to the dev server.
- `bundleId` is the bundle id the agent installs and launches.

What the agent gets:

- `ios_build` builds the app. It asks you first.
- `ios_run` installs and launches it in the simulator. It asks you first.
- `ios_screenshot` takes a screenshot of the simulator.
- `ios_logs` reads the app's logs.

A Swift edit reaches the screen only after `ios_build` and `ios_run`. There is no hot reload. See
[Approvals](/docs/usage/approvals) for the ask.

## Edge cases

<Accordions>
<Accordion id="finds-engine" title="How the app finds the engine">

With `CONCIV_URL` set, the app uses that address, for example `http://127.0.0.1:4599`. Leave `/widget` off the end.

Without it, the app:

1. Reads `~/.conciv/dev-endpoint.json`. The engine writes this file when it starts.
2. Otherwise tries `http://127.0.0.1` on ports 4599, 8787 and 3000.

`ios_run` passes the address for you. A fixed `port` in your conciv config keeps it the same across restarts.

</Accordion>
<Accordion id="dev-endpoint-dir" title="Your config sets devEndpointDir">

The app reads only `~/.conciv/dev-endpoint.json`. With `devEndpointDir` set, the engine writes the file elsewhere. The
app falls back to the port probe. Set `CONCIV_URL` to be sure which engine it uses.

</Accordion>
<Accordion id="launcher" title="A native button instead of the mascot">

The button is the animated mascot by default. Pass `.native` for a round native button:

```swift
ConcivWidget.attach(launcher: .native)
```

</Accordion>
<Accordion id="scene-delegate" title="A UIKit app with a scene delegate">

Call `attach()` in `scene(_:willConnectTo:options:)`, before or after `makeKeyAndVisible()`:

```swift title="SceneDelegate.swift"
import UIKit
import ConcivWidget // [!code ++]

class SceneDelegate: UIResponder, UIWindowSceneDelegate {
  var window: UIWindow?

  func scene(_ scene: UIScene, willConnectTo session: UISceneSession, options connectionOptions: UIScene.ConnectionOptions) {
    ConcivWidget.attach() // [!code ++]
  }
}
```

</Accordion>
<Accordion id="options" title="More plugin options">

- `scheme`: the Xcode scheme to build. Unset, it comes from the end of `bundleId`.
- `simulator`: the simulator to boot. Default `iPhone 17 Pro`.
- `buildMode`: `xcodebuild` (the default) or `swiftc`.
- `developerDir`: the Xcode developer folder. Default `/Applications/Xcode.app/Contents/Developer`.
- `extraSourceDirs`: more Swift source folders to compile.
- `concivUrl`: the engine address the app gets. Default: the engine that runs the tool.

</Accordion>
</Accordions>
