## One command

Run it in your app's folder, the one with `package.json`:

```bash
npx @conciv/cli@latest init
```

<Steps>
<Step>

### It looks at your project

init finds your framework from the dependencies in `package.json`, your package manager, and the agent CLIs on your
machine (`claude`, `codex`, `gemini`, `opencode`, `pi`).

</Step>
<Step>

### It asks

- Teach these agent harnesses about conciv? (every one it found, all checked)
- Connect these agents to conciv, so they can find and drive your open conciv tabs? (the ones not connected yet)
- Wire the detected vite config for conciv? (your framework's name in place of vite)
- Add the `@conciv/skills` docs pack (setup, develop, debug and harness guides) and TanStack intent skill-loading
  guidance? (off by default)

</Step>
<Step>

### It shows the plan, then asks "Run this plan?"

The plan lists each step and the files it would edit. A step that is already done shows as `already wired`, and a step
init cannot do for you shows as `manual — prints instructions`.

</Step>
<Step>

### It runs each step

It installs `@conciv/it` as a dev dependency with your package manager, adds conciv to your config and prints the diff,
writes the conciv section of `AGENTS.md` (and `CLAUDE.md`), installs the conciv Claude Code plugin when you picked
claude, and connects each agent you picked. A step it cannot do for you ends as a card with the snippet to paste.
Ctrl-C while it runs puts your config back as it was.

</Step>
</Steps>

<TypeTable
  type={{
    '--yes': {type: 'flag', description: 'Takes every default with no questions. Use it in CI or from an agent.'},
    '--dry-run': {type: 'flag', description: 'Prints the plan and changes nothing.'},
    '--force': {type: 'flag', description: 'Runs even with uncommitted git changes.'},
    '--json': {type: 'flag', description: 'Prints one JSON result and never asks. Pair it with --yes or --dry-run.'},
  }}
/>

init stops before it writes anything when:

- there is no `package.json` in the folder: `no package.json here — run init from your app directory`
- the git tree has uncommitted changes and you did not pass `--force`: `uncommitted changes — commit first or pass --force`
- there is no terminal to ask in and you passed neither `--yes` nor `--dry-run`:
  `Non-interactive terminal — re-run with --yes or --dry-run`

When it is done it prints the next steps: start your app with your package manager's `dev` script, and ask your agent to
run `conciv tools --help`.

## Before you start

<Callout>
  The chat runs an agent CLI on your machine: `claude` by default, on the `PATH` of the shell that starts your dev
  server, and logged in. See [Harnesses](/docs/harnesses) for the others.
</Callout>

conciv runs in your dev server only: `vite build` leaves it out, and a Next.js production server does not start it.

## Then log in

The first time you open the panel, it asks for a 6-digit code that your dev server prints in its terminal. See
[Logging in](/docs/usage/logging-in).

Working with a coding agent in your own terminal? [Connect your agents](/docs/quick-start/agents) covers what init sets
up for it.
