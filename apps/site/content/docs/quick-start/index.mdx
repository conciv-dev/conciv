## One command

```bash
npx conciv@latest init
```

init detects your bundler and package manager, installs `@conciv/it`, wires your config, and
teaches your installed agent harnesses the conciv CLI. It refuses a dirty git tree (commit first or
pass `--force`), and `--dry-run` prints the plan without touching anything.

## Prerequisites

<Callout>
  You need a dev build of your app, Node 22 or newer, and the `claude` CLI on your `PATH`. The chat uses `claude` to
  answer. See [Harnesses](/docs/harnesses) to use a different agent.
</Callout>

conciv mounts in dev only. The conciv button shows once the engine routes are live, so it stays inert on
a plain production preview.
