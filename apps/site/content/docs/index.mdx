---
title: What is conciv
description: Your coding agent, inside the app you are running. It sees the page you are on and changes it for you.
icon: Info
---

An agent in a terminal works on files it cannot see rendered. You describe the page to it, then copy errors and markup
back and forth. conciv adds a panel to your app in development. The agent there reads the page you are on, drives it,
and edits the source that renders it. With the test runner plugin, it runs your tests too. It uses the agent CLI
you already have, on your own machine.

Reach for conciv when:

- You want to point at something on the page and say "change this".
- A bug only shows in the running app, with its real data and state.
- You want the agent to check its own change in the browser before it says it is done.
- You want the agent in your terminal to see and drive the tab you have open.
