---
title: What is conciv
description: The coding agent you already use, in a panel inside your running app. It sees the page you are on and drives it.
---

conciv puts the coding agent you already use, such as Claude Code or Codex, into the app you are building. Add conciv
to your dev server's config, and a conciv button appears in the corner of your app. Open it to chat with an agent that
sees the page you are on, drives and edits it, and reads your dev server, without leaving the app.

It is for developers who build web apps with a coding agent and want it to work on the running page, not only on files.

```ts title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [conciv()],
})
```
