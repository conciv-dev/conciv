The quick terminal is a full-width sheet that drops from the top of the page, over your app, without dimming it. You
can split it into panes, each with its own session.

## Open and close

<TypeTable
  type={{
    'Mod+`': {required: true, type: 'default', description: 'Opens the quick terminal, or closes it.'},
    Escape: {required: true, type: 'key', description: 'Closes it, except while the focus is in a terminal.'},
    'Mod+D': {required: true, type: 'default', description: 'Adds a pane.'},
  }}
/>

`Mod` is Cmd on macOS and Ctrl elsewhere. Change both shortcuts in **Settings > Shortcuts**. The corner panel and the
quick terminal show one at a time: opening one closes the other.

## Set it in your config

It is on by default. Set the hotkey, or turn it off:

```ts title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [conciv({widget: {quickTerminal: {hotkey: 'Alt+k'}}})],
})
```

```ts
conciv({widget: {quickTerminal: {hotkey: ['Mod+`', 'Control+k']}}})
conciv({widget: {quickTerminal: false}})
```

`hotkey` takes one binding or a list. A hotkey set in the config locks the shortcut in **Settings > Shortcuts**.

## Panes

<Steps>
  <Step>The first pane opens your latest session.</Step>
  <Step>
    **Split pane** in the header, or `Mod+D`, adds a pane with a new session. Drag the gutter between panes to resize
    them.
  </Step>
  <Step>Each pane has its own session picker, usage, refresh and close.</Step>
</Steps>

<Callout type="warn">
  Closing a pane deletes its session, with its draft. Closing the last pane closes the quick terminal.
</Callout>

## Resize and pop out

Drag the grip on the bottom edge to set the height; it is remembered. Drag it almost to the top to close the quick
terminal.

**Pop out to a window** opens the focused pane's session in its own browser window. Closing that window brings the session
back in the corner panel. If the browser blocks the window, the session opens in the corner panel instead.
