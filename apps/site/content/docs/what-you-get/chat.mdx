The chat talks to the harness, running in your project. When you say "this" or "here", conciv's prompt tells it to
read the rendered page before it edits anything.

The buttons beside it:

- **Add an attachment**: add a file, or paste one. Images go only to Claude; the other harnesses take no images.
- **Select an element from the page**: click an element on your page to attach it, with its source file when conciv
  can find it.
- **Start a new session**.
- **Compress the conversation**: only on Claude.
- **Stop generating**: while a turn runs.

A message holds at most 16 parts. Your draft is saved per session on the engine, so it comes back after a reload.

## While a turn runs

What you send while the agent works waits in a queue under the composer. The first 3 show, with a count for the rest.
Each has **Steer**, which sends it now, and **Remove**. **Stop generating** stops the turn and puts the queued
messages back in your draft, unsent.

The agent can put real controls in the thread instead of asking in plain text:

The agent waits up to two minutes for your answer. After that it goes on without it, and your answer reaches it as a
later message.

## Sessions

The session picker lists your sessions under Today, Yesterday and Earlier, and searches them on the engine. It lists
the harness's own sessions from this project too, such as a Claude Code session you started in your terminal, when the
harness keeps them (see [Harnesses](/docs/reference/harnesses)). Hover a row for a preview. A match from another project copies
the command that resumes it there. Rename a session by clicking its title in the panel header.

## Model and harness

The model menu lists the models of every harness conciv found, and the effort levels of the current model when it
has them. Picking a model of another harness switches the session to that harness; in a chat that already has
messages, conciv asks first and estimates how much history moves over.
