Pass options where you add conciv. Every option is optional.

<Tabs items={['Vite', 'Next.js']}>

<Tab value="Vite">

```ts title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [conciv({widget: {quickTerminal: {hotkey: 'Alt+k'}}})],
})
```

</Tab>

<Tab value="Next.js">

Options are the second argument of `withConciv`.

```ts title="next.config.ts"
import type {NextConfig} from 'next'
import {withConciv} from '@conciv/it/plugin/nextjs'

const nextConfig: NextConfig = {}

export default withConciv(nextConfig, {plugins: ['@conciv/plugin-tanstack']})
```

</Tab>

</Tabs>

### port

<Tabs items={['Vite', 'Next.js', 'webpack and Rspack']}>
  <Tab value="Vite">
    Without `port`, the engine takes the port it used last time, or a free one. With `port`, the engine tries it and
    takes a free port when it is in use, with a warning in the terminal.
  </Tab>
  <Tab value="Next.js">The engine listens on `port`, `41700` by default. If the port is in use, it does not start.</Tab>
  <Tab value="webpack and Rspack">
    Without `port`, the engine takes the port it used last time, or a free one. With `port`, it listens on exactly that
    port. If the port is in use, the webpack or Rspack process exits with `EADDRINUSE`.
  </Tab>
</Tabs>

### widget

`modal` is the corner panel and its button. `quickTerminal` is the sheet that drops from the top of the page. Both are
on unless you set them to `false`.

```ts
conciv({widget: {modal: {position: 'top-left'}}})
conciv({widget: {quickTerminal: {hotkey: ['Mod+`', 'Control+k']}}})
conciv({widget: {quickTerminal: false}})
conciv({widget: {modal: false}})
```

`modal.position` is one of `top-left`, `top-right`, `middle-left`, `middle-right`, `bottom-left` or `bottom-right`
(the default). The quick terminal hotkey is ``Mod+` `` by default. A `hotkey` set here replaces it and locks the
setting in **Settings > Shortcuts**. See [Quick terminal](/docs/usage/quick-terminal).

`widget: false` keeps the engine and adds nothing to the page. Use it when you render the widget yourself with
`<ConcivWidget />` from `@conciv/react`, `@conciv/preact` or `@conciv/solid`, so the page does not get two:

```ts title="vite.config.ts"
import {defineConfig} from 'vite'
import react from '@vitejs/plugin-react'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [react(), conciv({widget: false})],
})
```

### systemPrompt

<TypeTable
  type={{
    'unset or true': {required: true, type: 'boolean', description: "conciv's built-in prompt."},
    'a string': {required: true, type: 'string', description: "Your string, in place of conciv's built-in prompt."},
    false: {required: true, type: 'boolean', description: 'No conciv prompt.'},
  }}
/>

The engine writes the prompt to `.conciv/chat-system-prompt.txt` when it starts and gives it to the harness. Plugins
add no prompt text: their guidance reaches the agent as [skills](/docs/skills). Claude gets it appended to Claude Code's own system prompt.

```ts
conciv({systemPrompt: 'Prefer Tailwind classes over inline styles.'})
conciv({systemPrompt: false})
```

### plugins

Each entry is a package name, a path (`./`, `../` or `file://`, from the project root), or a `[name, options]` pair
whose options are JSON. An entry `-<id>` turns that plugin off. Plugins in `conciv/plugins/` and `conciv/plugin/` load
without an entry.

```ts title="vite.config.ts"
import {defineConfig} from 'vite'
import react from '@vitejs/plugin-react'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [react(), conciv({plugins: [['@conciv/plugin-test-runner', {runner: 'playwright'}]]})],
})
```

See [Install a plugin](/docs/plugins/install).
