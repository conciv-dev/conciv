Pass options to the plugin. Every field is optional.

```ts title="vite.config.ts"
import conciv from '@conciv/it/plugin/vite'

conciv({
  harness: 'claude',
  enabled: process.env.NODE_ENV !== 'production',
})
```

## Common tasks

### Gate to dev only

```ts
conciv({enabled: process.env.NODE_ENV !== 'production'})
```

### Switch harness

```ts
conciv({harness: 'codex'})
```

See [Harnesses](/docs/harnesses) for the full list.

### Widget layouts

Two layouts ship, both on by default: the corner `modal` and the top drop-down `quickTerminal`.
Configure or disable each under `widget`.

```ts
conciv({widget: {modal: {position: 'top-left'}}}) // move the corner button
conciv({widget: {quickTerminal: {hotkey: ['Mod+`', 'Control+k']}}}) // set the hotkey(s)
conciv({widget: {quickTerminal: false}}) // corner modal only
conciv({widget: {modal: false}}) // quick terminal only
```

`modal.position` is one of `top-left`, `top-right`, `middle-left`, `middle-right`, `bottom-left`,
`bottom-right` (default), and the button is also draggable. See the
[Quick Terminal](/docs/usage/quick-terminal) guide for the drop-down layout.

### Theme

Set `widget.theme` to match the widget's accent color to your host page's palette.

```ts
conciv({widget: {theme: {accent: 'oklch(0.7 0.19 32)', hue: 30}}})
```

`accent` accepts a hex, `rgb()`/`rgba()`, `hsl()`/`hsla()`, `oklch()`, `oklab()`, or `color()` CSS
color value; anything else is ignored and the default magenta accent is kept. `hue` (0-360) shifts
the neutral surface colors — background, text, borders — to match; set it alongside `accent` when
your palette isn't magenta, or the neutrals stay on the default hue.

### Override the binary

```ts
conciv({harnessBin: '/usr/local/bin/claude'})
```

### Custom system prompt

```ts
conciv({systemPrompt: 'Prefer Tailwind classes over inline styles.'})
```

### widgetUrl

On webpack and Rspack the plugin does not inject the widget. Set `widgetUrl` to the served widget
bundle so the script lands on your page.

```ts
conciv({widgetUrl: '/conciv-widget.js'})
```
