A recipe is a short page for one real problem: what goes wrong, why it costs you, and the fix that works today.

## Run conciv

- [Drive the widget from a script](/docs/recipes/drive-the-widget-from-a-script): a scripted model and a script that
  types into the widget.
- [Keep conciv out of production](/docs/recipes/keep-conciv-out-of-production): make sure no deployed build carries
  the widget.

## Plugins

- [Debug a plugin that does not load](/docs/recipes/debug-a-plugin-that-does-not-load): find out why a tool, card or
  panel does not show.
- [Share a plugin across projects](/docs/recipes/share-a-plugin-across-projects): one plugin in several projects, from
  a shared folder or from npm.
