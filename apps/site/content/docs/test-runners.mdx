The test-runner plugin runs your tests in a separate process. Vitest is the default.

## Install

Add it to `plugins`. The engine installs the package on its first load. See [Install a plugin](/docs/plugins/install).

```ts title="vite.config.ts"
conciv({plugins: ['@conciv/plugin-test-runner']})
```

## Select a runner

The runner is the plugin's `runner` option:

```ts title="vite.config.ts"
conciv({plugins: [['@conciv/plugin-test-runner', {runner: 'playwright'}]]})
```

## Available

### Vitest

Default. Full support.

```ts
conciv({plugins: [['@conciv/plugin-test-runner', {runner: 'vitest'}]]})
```

### Playwright

Full support. Runs `playwright test` and reads its JSON report.

```ts
conciv({plugins: [['@conciv/plugin-test-runner', {runner: 'playwright'}]]})
```
