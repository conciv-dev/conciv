The test-runner plugin runs your project's tests in a separate process. It gives the agent the tools behind
[Live tests](/docs/usage/live-tests). conciv does not ship it, so you add it yourself.

Package: `@conciv/plugin-test-runner`

## Install it

```package-install
-D @conciv/plugin-test-runner
```

## Add it to your config

Add it to `plugins`:

```ts twoslash title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [conciv({plugins: ['@conciv/plugin-test-runner']})], // [!code ++]
})
```

Restart your dev server. The plugin runs your tests with Vitest.

## Pick a runner

Pass `runner` to run Playwright instead:

```ts twoslash title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [conciv({plugins: [['@conciv/plugin-test-runner', {runner: 'playwright'}]]})], // [!code ++]
})
```

- `['@conciv/plugin-test-runner', {...}]` is a plugin entry with options.
- `runner` names the framework. Your project must have it installed.

Pick the runner your project's tests are written for:

- **`vitest`** is the default. It drives your project's own `vitest/node`. Each test result streams in as it finishes.
- **`playwright`** runs `playwright test --reporter=json`. The results arrive when the whole run ends.

## What it does

- **List tests**: the agent lists your test files without running them.
- **Run tests**: the agent runs every test, or the files whose path matches a pattern, and waits for the result.
- **Read the last result**: the agent reads the last finished run without starting one.
- **Tests tab**: a run streams live into the Tests tab of the panel.
- **Run card**: a finished run shows as a card in the chat.

See [Live tests](/docs/usage/live-tests) for the prompts to type.
