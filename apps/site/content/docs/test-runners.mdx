The test-runner plugin, `@conciv/plugin-test-runner`, runs your project's tests in a separate process and gives the
agent the tools behind [Live tests](/docs/usage/live-tests). conciv does not ship it: you install it and load it. Vitest
is the default runner.

## Install

```bash
pnpm add -D @conciv/plugin-test-runner
```

## Load it

Add it to `plugins`:

```ts title="vite.config.ts"
plugins: ['@conciv/plugin-test-runner']
```

## Select a runner

The runner is the plugin's `runner` option:

```ts title="vite.config.ts"
plugins: [['@conciv/plugin-test-runner', {runner: 'playwright'}]]
```

| `runner`     | What it does                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------------- |
| `vitest`     | The default. Drives your project's own `vitest/node`, and streams each test result as it finishes. |
| `playwright` | Runs `playwright test --reporter=json` and reads the report when the whole run ends.               |

<Callout type="warn">
  `jest` and `node-test` are accepted by the option but not implemented: choosing one fails the plugin when it starts.
</Callout>

When the runner cannot start, for example because the framework is not installed or its config fails to load, the
agent's call fails with a message that says why.
