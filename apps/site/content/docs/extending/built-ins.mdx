Two built-ins show the public contracts at work: the whiteboard extension and the test-runner
plugin. Neither uses anything private, so they double as reference implementations.

## Whiteboard

[`@conciv/extension-whiteboard`](https://github.com/conciv-dev/conciv/tree/main/packages/extensions/whiteboard)
is the [shared Excalidraw canvas](/docs/usage/whiteboard). It demonstrates the heavyweight end of
the contract:

- **Four tool groups** (`canvas`, `comment`, `anchor`, `element`) composed into one `tools` array,
  each defined with `defineTool` and a typed shared context.
- **A long-lived server process**: its `.server(...)` factory boots a self-hosted CRDT sync
  server, deploys the schema, and returns `dispose` to shut everything down.
- **Custom routes**: `server.app.get('/config', ...)` hands the client its sync endpoint.
- **Composer UI**: its `Component` renders the whiteboard button with
  `useSlot() === 'composer'`.
- **Session scoping**: tools read `request.sessionId` so every chat session gets its own room.

## Test runner

[`@conciv/plugin-test-runner`](https://github.com/conciv-dev/conciv/tree/main/packages/plugins/test-runner)
powers [live tests](/docs/usage/live-tests). It is a plugin, not an extension. Load it with
`plugins: [['@conciv/plugin-test-runner', {runner: 'playwright'}]]`. It shows the plugin patterns:

- **Options**: the `runner` option (vitest, jest, node-test, playwright) is parsed with zod in
  `setup`. Vitest is the default.
- **A runner registry**: adapters (Vitest, Playwright) behind one interface, picked from the option.
- **Tools**: `test_runner_run` and `test_runner_status` are direct tools the agent calls by name.
  `external_test_runner_list` stays in code mode.
- **Plugin RPC**: the Tests tab starts and stops runs over the plugin's RPC, and reads one `event`
  per live run step to stream rows.
- **The card**: the finished result renders in the thread as a test card.
- **A skill**: teaches the agent to list tests before it runs a vague request.

## Reading order

Start with the test runner's `src/index.ts` (about eighty lines end to end), then the whiteboard's
tool groups. Everything the whiteboard imports from `@conciv/extension` is documented in
[Tool contract](/docs/extending/tool-contract) and [Widget UI](/docs/extending/widget-ui).
