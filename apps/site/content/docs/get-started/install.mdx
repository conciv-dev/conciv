---
title: Install
description: One command sets your app up for conciv. Or pick your framework and wire it by hand.
---

Run it in your app's folder, the one with `package.json`:

```bash
npx @conciv/cli@latest init
```

<Steps>
<Step>

### It looks at your project

init finds your framework from the dependencies in `package.json`, your package manager, and the agent CLIs on your
machine.

</Step>
<Step>

### It asks

- Teach these agent harnesses about conciv? (every one it found, all checked)
- Connect these agents to conciv, so they can find and drive your open conciv tabs? (the ones not connected yet)
- Wire the detected vite config for conciv? (your framework's name in place of vite)
- Add the `@conciv/skills` docs pack and TanStack intent skill-loading guidance? (no by default)

A question with nothing to pick from is skipped.

</Step>
<Step>

### It shows the plan, then asks "Run this plan?"

A plan for a Vite app, from `--dry-run`:

```text
◇  Plan ─────────────────────────────────────────────────────────╮
│                                                                │
│  Install @conciv/it                package.json                │
│  Wire the vite config              vite.config.ts              │
│  Teach agents the conciv CLI       AGENTS.md, CLAUDE.md        │
│  Install the conciv claude plugin  .conciv/claude-connect      │
│  Connect Claude to conciv          already wired               │
│  Connect Codex to conciv           already wired               │
│  Connect Gemini CLI to conciv      Gemini CLI MCP config       │
│  Connect OpenCode to conciv        OpenCode MCP config         │
│                                                                │
│  Harnesses: ● claude  ● codex  ● gemini-cli  ● opencode  ● pi  │
│                                                                │
├────────────────────────────────────────────────────────────────╯
```

</Step>
<Step>

### It runs each step

It records the harnesses you picked in `.conciv/harnesses.json`, installs `@conciv/it` as a dev dependency, adds
conciv to your config and prints the diff, writes the conciv section of `AGENTS.md` and `CLAUDE.md`, installs the
Claude Code plugin when you picked claude, and connects each agent you picked. A step it cannot do for you ends as a card with the snippet to
paste. Press Ctrl+C while it runs and it puts back the files it changed.

</Step>
</Steps>

When it is done it prints the next steps: start your app with your package manager's `dev` script, and ask your agent
to run `.conciv/bin/conciv tools --help`.

<TypeTable
  type={{
    '--yes': {type: 'flag', description: 'Takes every default with no questions. Use it in CI or from an agent.'},
    '--dry-run': {type: 'flag', description: 'Prints the plan and changes nothing.'},
    '--force': {type: 'flag', description: 'Runs even with uncommitted git changes.'},
    '--json': {type: 'flag', description: 'Prints one JSON result and never asks. Pair it with --yes or --dry-run.'},
  }}
/>

init stops before it writes anything when there is no `package.json` in the folder, when the git tree has uncommitted
changes and you did not pass `--force`, or when there is no terminal to ask in and you passed neither `--yes` nor
`--dry-run`. See [Troubleshooting](/docs/reference/troubleshooting#from-the-conciv-cli) for the messages.

## Before you start

<Callout>
  The chat runs an agent CLI on your machine: `claude` by default, on the `PATH` of the shell that starts your dev
  server, and logged in. See [Supported agents](/docs/reference/harnesses) for the others.
</Callout>

conciv runs in your dev server only: `vite build` leaves it out, and a Next.js production server does not start it.
