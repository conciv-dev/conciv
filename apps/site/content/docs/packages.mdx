An app installs one package, `@conciv/it`, as a dev dependency. The rest of conciv comes with it.

```bash
pnpm add -D @conciv/it
```

## Add conciv to your app

| Package                                                                            | What it is                                                                                                                                            |
| ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`@conciv/it`](https://github.com/conciv-dev/conciv/tree/main/packages/it)         | The conciv build integration. Import paths: `@conciv/it/plugin/vite`, `/plugin/nextjs`, `/plugin/nextjs/widget`, `/plugin/webpack`, `/plugin/rspack`. |
| [`@conciv/react`](https://github.com/conciv-dev/conciv/tree/main/packages/react)   | `<ConcivWidget />` for a React app that renders the widget itself.                                                                                    |
| [`@conciv/preact`](https://github.com/conciv-dev/conciv/tree/main/packages/preact) | `<ConcivWidget />` for Preact.                                                                                                                        |
| [`@conciv/solid`](https://github.com/conciv-dev/conciv/tree/main/packages/solid)   | `<ConcivWidget />` for Solid.                                                                                                                         |

A `<ConcivWidget />` still needs the engine: keep `@conciv/it` in your config with `widget: false`. See
[Configuration](/docs/configuration#widget).

## Run from your terminal

| Package                                                                      | What it is                                                                                                      |
| ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| [`@conciv/cli`](https://github.com/conciv-dev/conciv/tree/main/packages/cli) | The `conciv` command: `init`, `auth`, `mcp` and `tools`. Run `npx @conciv/cli@latest init` to set a project up. |
| [`@conciv/try`](https://github.com/conciv-dev/conciv/tree/main/packages/try) | Try conciv on conciv.dev with the agent on your machine: `npx @conciv/try --token <token>`.                     |

## Add to `extensions`

Each one is a separate install, and does nothing until you add it to `extensions`.

| Package                                                                                                           | What it adds                                                                                   |
| ----------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| [`@conciv/extension-test-runner`](https://github.com/conciv-dev/conciv/tree/main/packages/extensions/test-runner) | Runs your tests and streams the results into a card. See [Live tests](/docs/usage/live-tests). |
| [`@conciv/extension-whiteboard`](https://github.com/conciv-dev/conciv/tree/main/packages/extensions/whiteboard)   | A canvas you and the agent draw on. See [Whiteboard](/docs/usage/whiteboard).                  |
| [`@conciv/extension-terminal`](https://github.com/conciv-dev/conciv/tree/main/packages/extensions/terminal)       | The harness's own terminal view in the panel.                                                  |
| [`@conciv/extension-recorder`](https://github.com/conciv-dev/conciv/tree/main/packages/extensions/recorder)       | Records the page session for the agent to read back.                                           |
| [`@conciv/extension-tanstack`](https://github.com/conciv-dev/conciv/tree/main/packages/extensions/tanstack)       | TanStack Router and Query state for the agent.                                                 |
| [`@conciv/extension-ios`](https://github.com/conciv-dev/conciv/tree/main/packages/extensions/ios)                 | Build and run a native iOS app in the simulator. See [iOS](/docs/quick-start/ios).             |

## For your agents

| Package                                                                            | What it is                                                                            |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| [`@conciv/skills`](https://github.com/conciv-dev/conciv/tree/main/packages/skills) | Guides for coding agents working on a conciv project. `conciv init` offers to add it. |

The other published `@conciv/*` packages are conciv's internals, or the authoring kit covered in
[Extending](/docs/extending).
