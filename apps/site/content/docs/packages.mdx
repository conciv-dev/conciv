You install one package: [`@conciv/it`](https://github.com/conciv-dev/conciv/tree/main/packages/it).
Everything else is internal wiring or opt-in authoring surface.

## Install

| Package                                                                    | What it is                                                                                                        |
| -------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| [`@conciv/it`](https://github.com/conciv-dev/conciv/tree/main/packages/it) | The umbrella you install. `@conciv/it/plugin/vite`, plus `/webpack`, `/rspack`, `/rollup`, `/esbuild`, `/nextjs`. |

## Author against

| Package                                                                                            | What it is                                                                                                                           |
| -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| [`@conciv/plugin`](https://github.com/conciv-dev/conciv/tree/main/packages/plugin)                 | The plugin SDK: `Plugin.define` for the engine and browser parts, `Rpc.define`, registries and stores. See [Plugins](/docs/plugins). |
| [`@conciv/plugin-testkit`](https://github.com/conciv-dev/conciv/tree/main/packages/plugin-testkit) | Boots the real engine and widget with a fake model, for plugin tests. See [Testing a plugin](/docs/plugins/testing).                 |

## Plugins

| Package                                                                                                     | What it is                                                                                     |
| ----------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| [`@conciv/plugin-test-runner`](https://github.com/conciv-dev/conciv/tree/main/packages/plugins/test-runner) | [Live test execution](/docs/usage/live-tests) and the Tests tab.                               |
| [`@conciv/plugin-tanstack`](https://github.com/conciv-dev/conciv/tree/main/packages/plugins/tanstack)       | Build errors, the route manifest and server-function traces of a TanStack Router or Start app. |
| [`@conciv/plugin-recorder`](https://github.com/conciv-dev/conciv/tree/main/packages/plugins/recorder)       | Records the page and plays it back to the agent as an action log with keyframes.               |
| [`@conciv/plugin-ios`](https://github.com/conciv-dev/conciv/tree/main/packages/plugins/ios)                 | Alpha: build and run a [native iOS app](/docs/quick-start/ios) in the simulator.               |

See [Install a plugin](/docs/plugins/install) for each one's options.

## Under the hood

| Package                                                                                | What it is                                                                               |
| -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| [`@conciv/unplugin`](https://github.com/conciv-dev/conciv/tree/main/packages/unplugin) | The unplugin that boots the engine and injects the widget into your dev build.           |
| [`@conciv/core`](https://github.com/conciv-dev/conciv/tree/main/packages/core)         | The framework-free engine: every `/api/*` route, sessions, harness and test registries.  |
| [`@conciv/embed`](https://github.com/conciv-dev/conciv/tree/main/packages/embed)       | The browser half: mounts the conciv Solid app in an open shadow DOM, cards, page driver. |
| [`@conciv/harness`](https://github.com/conciv-dev/conciv/tree/main/packages/harness)   | Harness adapters: Claude and Codex, plus Gemini CLI, opencode, and Pi stubs.             |
| [`@conciv/cli`](https://github.com/conciv-dev/conciv/tree/main/packages/cli)           | The [`conciv` CLI](/docs/cli) the agent calls from Bash.                                 |
| [`@conciv/protocol`](https://github.com/conciv-dev/conciv/tree/main/packages/protocol) | Shared wire types. Zero runtime.                                                         |
