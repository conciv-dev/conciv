---
title: Vite
description: Add conciv to a Vite app, or to a framework built on Vite such as Astro or SvelteKit.
---

In `vite dev`, conciv starts the engine, adds the widget to every HTML page the dev server serves, and gives the agent
your dev server's module graph. `vite build` leaves it out.

## Install

<Tabs items={['init', 'pnpm', 'npm', 'yarn']}>

<Tab value="init">

```bash
npx @conciv/cli@latest init
```

init finds Vite (or Astro) in your `package.json`, installs `@conciv/it`, and adds `conciv()` to the `plugins` of
your config. If it cannot read the shape of your config, it prints the snippet to paste instead. See
[Install](/docs/get-started/install) for what it asks.

</Tab>

<Tab value="pnpm">

```bash
pnpm add -D @conciv/it
```

</Tab>

<Tab value="npm">

```bash
npm install -D @conciv/it
```

</Tab>

<Tab value="yarn">

```bash
yarn add -D @conciv/it
```

</Tab>

</Tabs>

## Add it

<Tabs items={['vite.config.ts', 'astro.config.mjs']}>

<Tab value="vite.config.ts">

```ts title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [conciv()],
})
```

</Tab>

<Tab value="astro.config.mjs">

```js title="astro.config.mjs"
import {defineConfig} from 'astro/config'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  vite: {
    plugins: [conciv()],
  },
})
```

</Tab>

</Tabs>

## Run it

```bash
pnpm dev
```

Open your app. The conciv button sits in the corner. The first time, it asks for the 6-digit code your dev server
prints in its terminal: see [Your first five minutes](/docs/get-started/first-five-minutes).

## Options

Pass options to `conciv()`. These change how the Vite integration behaves; every other option is on
[Configuration](/docs/reference/configuration).

<TypeTable
  type={{
    enabled: {
      type: 'boolean',
      default: 'true',
      description: 'false starts no engine and adds no widget.',
    },
    port: {
      type: 'number',
      default: 'the last port, or a free one',
      description:
        'The engine port. If it is in use, the engine takes a free port and prints a warning; the widget follows it.',
    },
    widget: {
      type: '{modal?, quickTerminal?} | false',
      default: 'both layouts on',
      description: 'false adds no widget to the page; the engine still starts.',
    },
  }}
/>

## If it does not show up

- **You ran `vite build` or `vite preview`.** conciv is part of `vite dev` only.
- **`enabled: false` or `widget: false` is set.** Remove it.
- **Vite DevTools is in your plugins.** conciv is in the DevTools dock, not the corner.
- **The button shows Unauthorized.** Log in with the code from your terminal. See
  [Troubleshooting](/docs/reference/troubleshooting#in-the-panel).
- **The terminal says the port is in use.** See [Troubleshooting](/docs/reference/troubleshooting#in-the-terminal).
