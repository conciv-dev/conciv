Next.js needs three pieces: `withConciv` around your config, an `instrumentation.ts` that starts the engine, and an
`instrumentation-client.ts` that adds the widget. In a production build, none of them starts the engine or adds the widget.

## Install

<Tabs items={['init', 'pnpm', 'npm', 'yarn']}>

<Tab value="init">

```bash
npx @conciv/cli@latest init
```

init finds Next.js in your `package.json`, installs `@conciv/it`, wraps the default export of your next config with
`withConciv`, and creates `instrumentation.ts` and `instrumentation-client.ts` next to `package.json`. If it cannot
read the shape of your config, or a file already exists with other content, it prints the snippet to paste instead.
See [Install](/docs/get-started/install) for what it asks.

</Tab>

<Tab value="pnpm">

```bash
pnpm add -D @conciv/it
```

</Tab>

<Tab value="npm">

```bash
npm install -D @conciv/it
```

</Tab>

<Tab value="yarn">

```bash
yarn add -D @conciv/it
```

</Tab>

</Tabs>

## Add it

```ts title="next.config.ts"
import type {NextConfig} from 'next'
import {withConciv} from '@conciv/it/plugin/nextjs'

const nextConfig: NextConfig = {}

export default withConciv(nextConfig)
```

```ts title="instrumentation.ts"
export {register} from '@conciv/it/plugin/nextjs'
```

```ts title="instrumentation-client.ts"
import '@conciv/it/plugin/nextjs/widget'
```

Put the two instrumentation files in the folder that holds your `app` or `pages` folder: the project root, or `src/`.

## Run it

```bash
next dev
```

Open your app. The conciv button sits in the corner. The first time, it asks for the 6-digit code your dev server
prints in its terminal: see [Your first five minutes](/docs/get-started/first-five-minutes).

## Options

Options are the second argument of `withConciv`: `withConciv(nextConfig, {port: 41800})`. These change how the
Next.js integration behaves; every other option is on [Configuration](/docs/reference/configuration).

## If it does not show up

- **You ran `next start`.** conciv runs in `next dev` only.
- **`instrumentation-client.ts` is missing or in the wrong folder.** It goes next to your `app` or `pages` folder.
- **Port `41700` is in use.** The engine does not start. Stop what holds the port, or set another `port`.
- **The button shows Unauthorized.** Log in with the code from your terminal. See
  [Troubleshooting](/docs/reference/troubleshooting#in-the-panel).
- **The panel says it couldn't reach the engine.** See [Troubleshooting](/docs/reference/troubleshooting#in-the-panel).
