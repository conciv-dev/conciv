<Callout type="warn">
  With conciv in your webpack config, you get the engine: it listens on `127.0.0.1`, writes `.conciv/server.json`, and
  puts `.conciv/bin/conciv` in place. You do not get the widget, and conciv has no supported way to add it by hand yet.
  For the widget, use [Vite](/docs/frameworks/vite) or [Next.js](/docs/frameworks/nextjs).
</Callout>

## Install

<Tabs items={['init', 'pnpm', 'npm', 'yarn']}>

<Tab value="init">

```bash
npx @conciv/cli@latest init
```

init finds webpack in your `package.json`, installs `@conciv/it`, and adds conciv to the `plugins` of your webpack
config. It then prints an "Inject the widget" card: the `@conciv/widget/global` bundle and the `widgetUrl` option it
names do not add the widget.

</Tab>

<Tab value="pnpm">

```bash
pnpm add -D @conciv/it
```

</Tab>

<Tab value="npm">

```bash
npm install -D @conciv/it
```

</Tab>

<Tab value="yarn">

```bash
yarn add -D @conciv/it
```

</Tab>

</Tabs>

## Add it

Use an ES module config. This is what init writes into one:

```js title="webpack.config.js"
import TerserPlugin from 'terser-webpack-plugin'
import conciv from '@conciv/it/plugin/webpack'

export default {
  entry: './src/index.js',
  plugins: [new TerserPlugin(), conciv()],
}
```

<Callout type="warn">
  A CommonJS config cannot load it: `require('@conciv/it/plugin/webpack')` fails with `ERR_PACKAGE_PATH_NOT_EXPORTED`.
  init still writes that `require` into a CommonJS config. Rename the config to `webpack.config.mjs` and use the
  `import` above.
</Callout>

## Run it

```bash
webpack serve
```

The engine starts. Your page gets no conciv button.

`webpack --mode production` also starts the engine, and the build process keeps running until you stop it.

## If it does not show up

- **There is no button.** That is expected: the webpack integration adds no widget.
- **The config fails with `ERR_PACKAGE_PATH_NOT_EXPORTED`.** It loads conciv with `require`. Use an ES module config.
- **The process stops with `EADDRINUSE`.** The `port` you set is in use. Free it, or remove `port`.
- **The conciv CLI finds no engine.** See [Troubleshooting](/docs/reference/troubleshooting#from-the-conciv-cli).
