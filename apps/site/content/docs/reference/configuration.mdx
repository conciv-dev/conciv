title: Configuration
description: Set conciv's options where you add it to your bundler, one option at a time.
---

Pass options to conciv where you add it to your bundler. Set only the options you need:

```ts twoslash title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [conciv({harness: 'codex', port: 4321})],
})
```

- `conciv(...)` takes one object. Every option in it is optional.
- `harness` picks the agent CLI a new chat starts with.
- `port` asks the engine for a port.

The other bundlers take the same object:

- Next.js: the second argument, `withConciv(nextConfig, options)`.
- webpack and Rspack: the plugin's argument, `conciv.default(options)` in a CommonJS config.

## Options

Each option below has one example. The full list with types and defaults is at the [end of the page](#all-options).

### enabled

Turn conciv off without removing it. No engine starts and no widget is added.

```ts twoslash title="vite.config.ts"
import conciv from '@conciv/it/plugin/vite'
// ---cut---
conciv({enabled: false})
```

### port

Ask the engine for a port.

```ts twoslash title="vite.config.ts"
import conciv from '@conciv/it/plugin/vite'
// ---cut---
conciv({port: 4321})
```

Without `port`, the engine takes the port it used last time in this project, or a free one. When the port you set is
in use, the engine takes a free one and prints a warning. It listens on `127.0.0.1` only.

### widget

Move or turn off the two layouts: `modal`, the corner panel, and `quickTerminal`, the sheet that drops from the top.

```ts twoslash title="vite.config.ts"
import conciv from '@conciv/it/plugin/vite'
// ---cut---
conciv({widget: {modal: {position: 'top-left'}, quickTerminal: {hotkey: 'Alt+k'}}})
```

- `modal.position` is a corner or a middle edge. The default is `bottom-right`.
- `quickTerminal.hotkey` replaces the default ``Mod+` ``. Pass an array for more than one key.
- `false` for a layout turns it off.

Set `widget: false` when you render the widget yourself with `<ConcivWidget />`. The engine still runs, and the page
does not get two widgets. See [Quick terminal](/docs/usage/quick-terminal) for the hotkey.

### plugins

Load plugins by package name or by path. A path starts at the project folder.

```ts twoslash title="vite.config.ts"
import conciv from '@conciv/it/plugin/vite'
// ---cut---
conciv({plugins: ['@conciv/plugin-test-runner', ['./my-plugin', {team: 'core'}]]})
```

- A string loads the plugin with no options.
- `[name, options]` passes options to the plugin. Every option value must be JSON.
- A name with a leading `-` removes that plugin.

See [Plugins](/docs/plugins).

### harness

Pick the agent CLI a new chat starts with. The default is `claude`.

```ts twoslash title="vite.config.ts"
import conciv from '@conciv/it/plugin/vite'
// ---cut---
conciv({harness: 'opencode'})
```

You can still switch harness from the menu in the panel. See [Harnesses](/docs/harnesses).

### systemPrompt

Replace the prompt conciv gives the agent, or give none.

```ts twoslash title="vite.config.ts"
import conciv from '@conciv/it/plugin/vite'
// ---cut---
conciv({systemPrompt: 'Answer in one short paragraph.'})
```

- A string replaces conciv's built-in prompt.
- `false` gives no conciv prompt.
- Left out, the agent gets conciv's built-in prompt.

The engine writes the prompt it used to `.conciv/chat-system-prompt.txt`. Claude gets it after Claude Code's own prompt.

### permission

Answer permission cards ahead of time, for when nobody is at the tab.

```ts twoslash title="vite.config.ts"
import conciv from '@conciv/it/plugin/vite'
// ---cut---
conciv({permission: {page_eval: 'allow'}})
```

`permission` takes three short forms:

- One effect for every action: `'allow'`.
- One effect per action: `{page_eval: 'deny'}`.
- One effect per action and resource: `{page_eval: {'document.title': 'allow'}}`.

The effect is `allow`, `deny` or `ask`. See [Approvals](/docs/usage/approvals).

### permissions

Write permission rules in full, as a list.

```ts twoslash title="vite.config.ts"
import conciv from '@conciv/it/plugin/vite'
// ---cut---
conciv({permissions: [{action: 'page_eval', resource: '*', effect: 'ask'}]})
```

These rules apply after the short forms in `permission`.

### policies

Allow or deny a whole kind of use, such as one plugin.

```ts twoslash title="vite.config.ts"
import conciv from '@conciv/it/plugin/vite'
// ---cut---
conciv({policies: [{action: 'plugin.use', resource: '*/greeter', effect: 'deny'}]})
```

The actions are `provider.use`, `tool.use`, `integration.connect`, `integration.use`, `mcp.use`, `skill.use`,
`plugin.use` and `websearch.use`. The effect is `allow` or `deny`.

### hubAccess

Decide whether an agent outside the tab needs your yes first. An outside agent is one you connected with
`conciv mcp connect`, running in your own terminal.

```ts twoslash title="vite.config.ts"
import conciv from '@conciv/it/plugin/vite'
// ---cut---
conciv({hubAccess: 'project'})
```

- `open`, the default, lets a connected agent into every open tab.
- `project` shows a card in the tab the first time an outside agent calls it. You allow it once, always, or not at all.

See [Connect your agents](/docs/agents).

### stateRoot

Move the `.conciv` state folder out of the project root.

```ts twoslash title="vite.config.ts"
import conciv from '@conciv/it/plugin/vite'
// ---cut---
conciv({stateRoot: '../shared-state'})
```

### homeDir

Move the folder conciv shares across projects, such as the agents you connected.

```ts twoslash title="vite.config.ts"
import conciv from '@conciv/it/plugin/vite'
// ---cut---
conciv({homeDir: '/tmp/conciv-home'})
```

The default is your platform's data folder.

### devEndpointDir

Move `dev-endpoint.json`, the file the iOS SDK reads to find the engine. The default is `~/.conciv`.

```ts twoslash title="vite.config.ts"
import conciv from '@conciv/it/plugin/vite'
// ---cut---
conciv({devEndpointDir: '/tmp/conciv-endpoint'})
```

### sessionId and claudeSessionId

Open the engine on a session you name.

```ts twoslash title="vite.config.ts"
import conciv from '@conciv/it/plugin/vite'
// ---cut---
conciv({claudeSessionId: 'release-notes'})
```

- `sessionId` is a conciv session id (`ses_...`). Any other value stops the engine with an error.
- `claudeSessionId` is a harness session id: up to 128 letters, digits, `_` and `-`.

The engine makes sure the session exists when it starts.

## Set an option from the environment

Some options also read an environment variable. Use one to change an option for a single run:

```bash
CONCIV_HARNESS=codex pnpm dev
```
