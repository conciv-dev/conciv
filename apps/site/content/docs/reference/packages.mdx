---

An app installs one package, `@conciv/it`, as a dev dependency. The rest of conciv comes with it.

```bash
pnpm add -D @conciv/it
```

## Add conciv to your app

| Package                                                                            | What it is                                                                                                                                            |
| ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`@conciv/it`](https://github.com/conciv-dev/conciv/tree/main/packages/it)         | The conciv build integration. Import paths: `@conciv/it/plugin/vite`, `/plugin/nextjs`, `/plugin/nextjs/widget`, `/plugin/webpack`, `/plugin/rspack`. |
| [`@conciv/react`](https://github.com/conciv-dev/conciv/tree/main/packages/react)   | `<ConcivWidget />` for a React app that renders the widget itself.                                                                                    |
| [`@conciv/preact`](https://github.com/conciv-dev/conciv/tree/main/packages/preact) | `<ConcivWidget />` for Preact.                                                                                                                        |
| [`@conciv/solid`](https://github.com/conciv-dev/conciv/tree/main/packages/solid)   | `<ConcivWidget />` for Solid.                                                                                                                         |

A `<ConcivWidget />` still needs the engine: keep `@conciv/it` in your config with `widget: false`. See
[Configuration](/docs/reference/configuration#widget).

## Run from your terminal

| Package                                                                      | What it is                                                                                                       |
| ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| [`@conciv/cli`](https://github.com/conciv-dev/conciv/tree/main/packages/cli) | The `conciv` command: `init`, `auth`, `mcp` and `plugin`. Run `npx @conciv/cli@latest init` to set a project up. |
| [`@conciv/try`](https://github.com/conciv-dev/conciv/tree/main/packages/try) | Try conciv on conciv.dev with the agent on your machine: `npx @conciv/try --token <token>`.                      |

## Add to `plugins`

Each one is a separate install, and does nothing until you add it to `plugins`. See
[Install a plugin](/docs/plugins/install).

| Package                                                                                                     | What it adds                                                                               |
| ----------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| [`@conciv/plugin-tanstack`](https://github.com/conciv-dev/conciv/tree/main/packages/plugins/tanstack)       | TanStack Router and Start: build errors, the route manifest and server-function calls.     |
| [`@conciv/plugin-test-runner`](https://github.com/conciv-dev/conciv/tree/main/packages/plugins/test-runner) | Lists and runs your tests for the agent. See [Live tests](/docs/plugins/live-tests).         |
| [`@conciv/plugin-recorder`](https://github.com/conciv-dev/conciv/tree/main/packages/plugins/recorder)       | A window of the page session, read back as an action log and keyframes.                    |
| [`@conciv/plugin-whiteboard`](https://github.com/conciv-dev/conciv/tree/main/packages/plugins/whiteboard)   | The whiteboard tools: canvas, comments and pins. See [Whiteboard](/docs/plugins/whiteboard). |

## Write a plugin

| Package                                                                            | What it is                                                                                                               |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| [`@conciv/plugin`](https://github.com/conciv-dev/conciv/tree/main/packages/plugin) | The plugin SDK: `Plugin.define` for both halves, `Rpc.define`, stores and the Vite preset. See [Plugins](/docs/plugins). |

## For your agents

| Package                                                                            | What it is                                                                            |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| [`@conciv/skills`](https://github.com/conciv-dev/conciv/tree/main/packages/skills) | Guides for coding agents working on a conciv project. `conciv init` offers to add it. |

The other published `@conciv/*` packages are conciv's internals.
