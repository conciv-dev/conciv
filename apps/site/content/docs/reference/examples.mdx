```bash
pnpm install
```

Run one with turbo, which builds the conciv packages it uses first.

### TanStack Start

```bash
pnpm turbo run dev --filter=tanstack-start-example
```

It serves on port 3000.

### Next.js

```bash
pnpm turbo run dev --filter=nextjs-app
```

Open the printed URL and click the conciv button.
