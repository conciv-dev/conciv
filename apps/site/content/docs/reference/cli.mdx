The conciv CLI sets a project up and drives your running dev server. The agent uses the same commands. Run one from
your project folder:

```bash title="Terminal"
npx @conciv/cli tools page snapshot
```

Every command accepts `--help` for its flags, for example `npx @conciv/cli auth link --help`. The full list of
commands and flags is at the [end of the page](#all-commands).

<Callout type="info" title="Bare conciv is for the agent">
  The agents conciv starts have `conciv` on their `PATH`, from `.conciv/bin`. Your own shell does not, so you type `npx
  @conciv/cli` instead.
</Callout>

`tools`, `plugin`, `auth` and `mcp connect`, `disconnect` and `list` print one JSON document:
`{"ok":true,"data":...}` or `{"ok":false,"error":...}`. Pipe it to `jq` in a script.

## init

Sets a project up: installs `@conciv/it`, wires your bundler config, and connects your agents.

```bash title="Terminal"
npx @conciv/cli@latest init
```

`--yes` accepts every detected default, with no prompts. `--dry-run` prints the plan and touches nothing. `--force`
runs even with uncommitted git changes. `--json` prints one JSON result and never prompts, so pair it with `--yes`:

```bash title="Terminal"
npx @conciv/cli@latest init --yes --json
```

Learn more in the [Getting started documentation](/docs/getting-started).

## tools

Reads and drives the live page through your running dev server. The commands under `tools` come from the engine's own
tool list, so a plugin's tools show up as soon as the engine loads it.

```bash title="Terminal"
npx @conciv/cli tools page click --name SubmitButton
```

`page` is the tool group and `click` is the tool. A tool that targets an element takes `--selector` (CSS), `--ref`
(from the last snapshot) or `--name` (a React component). `--tab` with a session id acts on that one tab, on whichever
dev server holds it.

`tools --help` lists every tool the running engine serves. `tools tabs` lists the open conciv tabs of every running dev
server on this machine:

```bash title="Terminal"
npx @conciv/cli tools tabs
```

Learn more in the [Page control documentation](/docs/usage/page-control).

## plugin call

Calls a method a plugin registered on the running engine, and prints its output.

```bash title="Terminal"
npx @conciv/cli plugin call server open --data '{"file":"src/routes/index.tsx","line":12}'
```

`server` is the plugin's RPC id and `open` is the method. `--data`, or `-d`, sends the method's input as JSON. Learn
more in the [Dev server documentation](/docs/usage/dev-server).

## auth link

Prints a one-time login link for a page served by the conciv dev server.

```bash title="Terminal"
npx @conciv/cli auth link http://localhost:5173/
```

Open the link in the browser you want to log in. Learn more in the [Logging in documentation](/docs/usage/logging-in).

## auth revoke

With no id, lists the browsers that logged in to this project's engine. It logs nobody out:

```bash title="Terminal"
npx @conciv/cli auth revoke
```

With an id from that list, logs that one browser out. `--all` logs every browser out:

```bash title="Terminal"
npx @conciv/cli auth revoke 3f2a9c1d
```

## mcp connect

Adds conciv to an agent CLI, so that agent can find and drive your open conciv tabs.

```bash title="Terminal"
npx @conciv/cli mcp connect claude
```

The agent is one of `claude`, `codex`, `gemini-cli` or `opencode`. Learn more in the [Agents
documentation](/docs/agents).

## mcp disconnect

Removes conciv from an agent CLI.

```bash title="Terminal"
npx @conciv/cli mcp disconnect codex
```

## mcp list

Lists the agents connected to conciv.

```bash title="Terminal"
npx @conciv/cli mcp list
```

## mcp serve

Serves conciv to an outside agent over MCP on stdio, not JSON. `mcp connect` writes this command into the agent's config,
so you rarely run it yourself.

```bash title="Terminal"
npx @conciv/cli mcp serve --agent claude
```

## --version

`--version`, or `-v`, prints the CLI's version as plain text.

```bash title="Terminal"
npx @conciv/cli --version
```
