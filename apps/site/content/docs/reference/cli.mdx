The agent drives your app with the `conciv` CLI. You can run the same commands. Run one against your dev server:

```bash
npx @conciv/cli tools page snapshot
```

- `npx @conciv/cli` runs the CLI anywhere. The agents conciv starts already have `conciv` on their `PATH`.
- `tools page snapshot` reads the open page, as the agent does.

Every command accepts `--help` for its full list of flags, for example `conciv auth link --help`. The full list of
commands and flags is at the [end of the page](#all-commands).

<Callout>
  Every command prints one JSON document: `{"ok":true,"data":...}` or `{"ok":false,"error":...}`. Pipe it to `jq` in a
  script.
</Callout>

## init

Sets a project up: installs `@conciv/it`, wires your bundler config, and connects your agents.

```bash
npx @conciv/cli@latest init
```

Accept every detected default, with no prompts.

```bash
npx @conciv/cli@latest init --yes
```

Print the plan without touching anything.

```bash
npx @conciv/cli@latest init --dry-run
```

Run even with uncommitted git changes.

```bash
npx @conciv/cli@latest init --force
```

Print one JSON result instead of prompting.

```bash
npx @conciv/cli@latest init --yes --json
```

See [Quick start](/docs/getting-started).

## tools

Reads and drives the live page through your running dev server. The commands under `tools` come from the server's own
tool list, so a plugin's tools show up as soon as the server loads it.

```bash
conciv tools page snapshot
conciv tools page click --name SubmitButton
conciv tools page text --selector .price
```

- `page` is the tool group. `snapshot`, `click` and `text` are its tools.
- A tool that targets an element takes `--selector` (CSS), `--ref` (from the last snapshot) or `--name` (a React
  component).

List every tool the running server serves.

```bash
conciv tools --help
```

List the open conciv tabs of every running dev server on this machine.

```bash
conciv tools tabs
```

Act on one tab, on whichever dev server holds it.

```bash
conciv tools page snapshot --tab ses_01JD8X
```

See [Page control](/docs/usage/page-control) for what the `page` tools do.

## plugin call

Calls a method a plugin registered on the running engine and prints its output.

```bash
conciv plugin call server urls
```

- `server` is the plugin's RPC id.
- `urls` is the method.

Send the method's input as JSON.

```bash
conciv plugin call server open --data '{"file":"src/routes/index.tsx","line":12}'
```

`-d` is short for `--data`. See [Dev server](/docs/usage/dev-server) for the `server` plugin's methods.

## auth link

Prints a one-time login link for a page served with the conciv dev server.

```bash
conciv auth link http://localhost:5173/
```

Open the link in the browser you want to log in. See [Logging in](/docs/usage/logging-in).

## auth revoke

Lists the browsers that logged in to this project's engine.

```bash
conciv auth revoke
```

Log one browser out by its id.

```bash
conciv auth revoke 3f2a9c1d
```

Log every browser out.

```bash
conciv auth revoke --all
```

## mcp connect

Adds conciv to an agent CLI, so that agent can find and drive your open conciv tabs.

```bash
conciv mcp connect claude
```

The agent is one of `claude`, `codex`, `gemini-cli` or `opencode`. See
[Connect your agents](/docs/agents).

## mcp disconnect

Removes conciv from an agent CLI.

```bash
conciv mcp disconnect codex
```

## mcp list

Lists the agents connected to conciv.

```bash
conciv mcp list
```

## mcp serve

Serves conciv to an outside agent over MCP stdio. `mcp connect` writes this command into the agent's config for you,
so you rarely run it yourself.

```bash
conciv mcp serve --agent claude
```

  <Accordion title="How conciv tools finds your dev server">
    It reads `CONCIV_PORT` first. Then it looks for `.conciv/server.json` in this folder or a parent. Then it takes the
    most recently started dev server on this machine. With no dev server running, `conciv tools` prints the "No conciv
    dev server" error, and so does its `--help`.
  </Accordion>
  <Accordion title="Live page edits are wiped on the next hot reload">
    The `page` tools that edit the page live (`settext`, `setstyle` and the rest) preview a change. The next hot reload
    wipes them. `conciv tools page changes` lists every live edit made this session, which is how the agent knows what
    to write to source afterwards.
  </Accordion>
  <Accordion title="Print the CLI version">
    `conciv --version`, or `-v`, prints the version instead of a JSON document.
  </Accordion>
