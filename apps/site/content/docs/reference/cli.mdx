`@conciv/cli` is the `conciv` command. Run it with `npx @conciv/cli@latest`, or as `conciv` in a project where conciv
is installed.

<TypeTable

`--help` (or `-h`) prints the usage of any command. `conciv --version` (or `-v`) prints the CLI version.

## `conciv init`

```bash
npx @conciv/cli@latest init
```

init finds your bundler, package manager and agent CLIs, shows the plan, and asks once before it writes anything. See
[Quick start](/docs/get-started).

## `conciv auth`

```bash
conciv auth link http://localhost:5173/
conciv auth revoke
conciv auth revoke <id>
conciv auth revoke --all
```

`auth link` asks the engine of the current folder for a one-time code and prints `{link, expiresAt}`: open the link
and that browser is logged in. `auth revoke` with no id lists the logged-in browsers; with an id, or `--all`, it logs
them out. See [Logging in](/docs/what-you-get/logging-in).

## `conciv mcp`

```bash
conciv mcp connect claude
conciv mcp disconnect claude
conciv mcp list
```

`<agent>` is `claude`, `codex`, `gemini-cli` or `opencode`. A connected agent gets two tools, `execute_typescript` and
`discover_tools`, which reach the same tools the chat uses. Each takes an optional `tab`, a session id, to act on that
tab on whichever engine holds it. See [Connect your agents](/docs/get-started/agents).

## `conciv plugin call`

```bash
conciv plugin call hello greet --data '{"name":"Ada"}'
```

```text title="output"
{"ok":true,"data":{"message":"Hello, Ada!","count":1}}
```

`--data` (or `-d`) is the method's input as JSON. The call runs as the owner: nothing asks first. It takes no `--tab`:
a plugin method learns no session from the caller, so an action on a tab names its session in `--data`. See
[Calling a plugin from the terminal](/docs/build-a-plugin/terminal).

## What every command prints

One JSON document on stdout, except `--help` and `--version`.

```text title="output"
{"ok":true,"data":{"connected":"claude"}}
{"ok":false,"error":{"kind":"user","message":"Unknown RPC method: hello.wave","code":"PLUGIN_RPC","type":"rpc.method_not_found"}}
```

The exit code is 0 for `ok: true` and 1 for an error. A wrong command or flag is an error too, with a hint:

```bash
conciv mcp lisst
```

```text title="output"
{"ok":false,"error":{"kind":"user","message":"Unknown command 'lisst' for conciv mcp. Did you mean 'list'?","hint":"run conciv mcp --help to list its commands"}}
```

```bash
conciv plugin call hello greet --tab conciv_x
```

```text title="output"
{"ok":false,"error":{"kind":"user","message":"Unknown flag --tab for conciv plugin call. Did you mean --data?","hint":"run conciv plugin call --help to see the arguments it accepts"}}
```

A failure that is not yours, such as a crash, has `kind: "unexpected"` and a hint for reporting it.

## Finding the engine

`auth link` uses the engine of the current folder. `plugin call` uses `CONCIV_PORT`, then `.conciv/server.json` in
the current folder or a parent, then the latest running engine on this machine, then port 5173.
