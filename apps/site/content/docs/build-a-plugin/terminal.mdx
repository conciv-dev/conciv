---
title: Call it from the terminal
description: conciv plugin call, what it prints, its errors, and who is asked.
---

Every RPC method a plugin registers can be called from your terminal.

```bash
conciv plugin call <rpcId> <method> --data '<json>'
```

You name the plugin's RPC id and the method; the CLI does not list them. `--data` (or `-d`) is the method's input as
JSON. Leave it out to send no input.

```bash
conciv plugin call hello greet --data '{"name":"Ada"}'
```

```text title="output"
{"ok":true,"data":{"message":"Hello, Ada!","count":1}}
```

```bash
conciv plugin call server resolve --data '{"spec":"app.ts","importer":"/src/main.ts"}'
conciv plugin call server open --data '{"file":"src/thing.ts","line":7,"column":3}'
conciv plugin call experimental.page run --data '{"sessionId":"conciv_...","action":{"type":"text","selector":"h1"}}'
```

Installed plugins have their own: for example `conciv plugin call experimental.tanstack routeManifest`. Each plugin's
README names its methods.

## What it prints

One JSON document on stdout: `{"ok":true,"data":...}` and exit code 0, or `{"ok":false,"error":...}` and exit code 1.


## Which engine it calls

From your project folder, the engine of that project. From any other folder, the latest running conciv engine on
this machine. With no engine running it fails with `No conciv dev server on <host>`.

## Who is asked

Nobody. The CLI reads the engine token your dev server wrote and calls as the owner, so a method runs without a
permission card, `eval` included: `conciv plugin call experimental.page run` with an `eval` action runs the script.
The same action from the agent inside a chat turn still asks you first.

Agents connected from outside through [`conciv mcp`](/docs/cli#conciv-mcp) cannot call plugin methods: the engine
answers them `outside agents can't use plugin routes; use the plugin in the tab`.
