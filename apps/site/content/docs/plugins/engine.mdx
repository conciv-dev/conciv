The engine part runs inside the conciv engine. Write it with [Effect](https://effect.website) from
`@conciv/plugin/effect`. The promise entry, `@conciv/plugin`, does the same without Effect: see
[The promise entry](#the-promise-entry).

```bash
pnpm add effect
pnpm add -D @conciv/plugin
```

## Define the plugin

`Plugin.define({id, effect})` is the default export of the engine part. The engine runs `effect(ctx)` when it loads
the plugin. Each `ctx` domain returns an `Effect`.

```ts title="packages/plugins/recorder/src/index.ts"
import {join} from 'node:path'
import {Plugin, type Rpc} from '@conciv/plugin/effect'
import {Effect, Queue, Stream} from 'effect'
import {createCaptureControl} from './capture-control.js'
import {createRecordingStore} from './recordings.js'
import {createChromiumRenderer} from './render.js'
import {createRendererCache} from './renderer-cache.js'
import {createClientRings} from './rings.js'
import type {RecorderRuntime} from './runtime.js'
import {recorderConfig} from './protocol.js'
import {info} from './skill.js'
import {register} from './tools.js'

function recordingsDirectory(projectDirectory: string): string {
  return join(projectDirectory, '.conciv', 'recorder', 'recordings')
}

export default Plugin.define({
  id: 'recorder',
  effect: (ctx) =>
    Effect.gen(function* () {
      const config = yield* Effect.sync(() => recorderConfig.parse(ctx.options))
      const rings = createClientRings({windowMs: config.windowMinutes * 60_000})
      const control = createCaptureControl(rings)
      const rendererCache = createRendererCache(createChromiumRenderer)
      const recordings = createRecordingStore(recordingsDirectory(ctx.location.directory))
      const runtime: RecorderRuntime = {
        rings,
        control,
        config,
        useRenderer: (work) => rendererCache.use(work),
        recordings,
      }
      yield* register(ctx, runtime)
      yield* ctx.skill.transform((editor) => editor.add(info))
      yield* Effect.addFinalizer(() =>
        Effect.sync(() => {
          control.dispose()
        }).pipe(Effect.andThen(Effect.promise(() => rendererCache.dispose()))),
      )
    }),
})
```

The effect runs in a scope that closes when the plugin stops or reloads. Every tool, skill and RPC handler it
registers is removed then. `Effect.addFinalizer` adds your own cleanup, as above.

## Tools

Add tools inside `ctx.tool.transform`. `editor.namespace` describes a group, and `editor.add` adds one tool. `execute`
returns an `Effect` of the result:

```ts title="packages/plugins/recorder/src/tools.ts"
import type {Context} from '@conciv/plugin/effect/plugin'
import {Tool} from '@conciv/plugin/schema/tool'
import {Effect} from 'effect'
import {z} from 'zod'

const options = {namespace: 'recording', codemode: true}

export const register = Effect.fn('RecorderTools.register')(function* (
  ctx: Pick<Context, 'tool'>,
  runtime: RecorderRuntime,
) {
  yield* ctx.tool.transform((editor) => {
    editor.namespace({
      name: 'recording',
      description:
        "Marked recordings of the user's app page: start one, act, stop it, or pull the last seconds. Each answers a semantic action log plus keyframe screenshots.",
    })
    editor.add({
      name: 'start',
      description:
        "Start a marked recording of the user's app page. Waits for the page to attach and begin streaming, then returns a captureId, so acting right after it returns is safe. Use before performing page actions you want to review, then call recording_stop.",
      input: z.object({}),
      output: z.object({captureId: z.string(), startedAt: z.number()}),
      options,
      execute: () =>
        Effect.gen(function* () {
          const {captureId, startTs, appendCursor} = yield* attempt(() => runtime.control.startCapture())
          const covered = yield* attemptPromise(() => runtime.control.awaitAppendAfter(appendCursor, START_WAIT_MS))
          if (covered) return {output: {captureId, startedAt: startTs}}
          yield* attempt(() => runtime.control.stopCapture(captureId))
          return yield* Effect.fail(
            Tool.makeError({
              message: 'no page client attached within 5s; the app page with the widget must be open to record',
            }),
          )
        }),
    })
  })
})
```

<TypeTable
  type={{
    name: {type: 'string', description: 'Letters, digits and `_`. With a namespace, the tool is `<namespace>_<name>`.'},
    description: {type: 'string', description: 'What the tool does. The agent reads it to decide when to call it.'},
    input: {type: 'schema', description: 'The input schema. The engine checks the input against it.'},
    output: {type: 'schema', description: 'The output schema, optional.'},
    execute: {
      type: '(input, context) => Effect<Result, Tool.Error>',
      description: 'Runs the tool. Succeed with `{output}`, or `{content}` with text, and optional `metadata`.',
    },
    'options.namespace': {type: 'string', description: 'The group the tool belongs to.'},
    'options.codemode': {
      type: 'boolean',
      description:
        'Defaults to code mode: the agent calls the tool from TypeScript as `external_<name>`. `false` makes it a direct tool the agent calls by name.',
    },
  }}
/>

A schema is a zod schema, any Standard Schema (Valibot, ArkType ...), an Effect Schema, or a raw JSON Schema object.

`execute` gets a context with `sessionId`, `agent`, the call `id`, and `progress(update)`.

### Tool.Error

Fail the effect with a `Tool.Error` to fail the call with a message the agent reads. Make one with `Tool.makeError` or
`Tool.toolError`. `metadata` travels with it:

```ts title="packages/plugins/tanstack/src/tools.ts"
function toolFailure(failure: Failure) {
  return Tool.toolError({message: failure.message, error: failure.error, metadata: {code: failure.code}})
}
```

```ts title="packages/plugins/tanstack/src/tools.ts"
execute: () =>
  tanstack.buildErrors().pipe(
    Effect.map((output) => ({output})),
    Effect.mapError(toolFailure),
  ),
```

`Tool.isToolError(error)` tells a `Tool.Error` apart, so a helper can pass one through and wrap anything else:

```ts title="packages/plugins/recorder/src/tools.ts"
function toolFailure(error: unknown): Tool.Error {
  if (error instanceof globalThis.Error && Tool.isToolError(error)) return error
  return Tool.makeError({message: error instanceof globalThis.Error ? error.message : String(error), error})
}

function attempt<Value>(work: () => Value) {
  return Effect.try({try: work, catch: toolFailure})
}
```

## Skills

Add a skill inside `ctx.skill.transform`. The agent sees its `description` and loads its `content` when it needs it.

```ts title="packages/plugins/recorder/src/skill.ts"
import {Skill} from '@conciv/plugin'
import {AbsolutePath} from '@conciv/plugin/schema/schema'

export const info: Skill.Info = {
  id: Skill.Id.make('recorder'),
  name: Skill.Name.make('Recorder'),
  description:
    "Record what happens on the user's app page and read it back as an action log with keyframe screenshots. Load it before your first recording tool call.",
  path: AbsolutePath.make('skill://recorder/SKILL.md'),
  content: [
    '# Recorder',
    '',
    "The recorder keeps a short recording of the user's app page while a recording is live. Nothing is recorded unless a recording was requested. Call its three tools from code mode; `discover_tools` shows their exact signatures.",
  ].join('\n'),
}
```

```ts title="packages/plugins/recorder/src/index.ts"
yield* ctx.skill.transform((editor) => editor.add(info))
```

`@conciv/plugin/effect` exports the same `Skill`. For skills written as files in the project, see
[Skills](/docs/skills).

## RPC

An RPC contract lets the browser part, another plugin or a terminal call the engine part. Put it in its own module,
so both parts import it.

### Rpc.define

`Rpc.define({id, methods, events})` declares the contract. Each method has an `input` and `output` schema, and
optional named `errors`. Each event has a `schema`.

```ts title="packages/plugins/recorder/src/rpc.ts"
import {Rpc} from '@conciv/plugin/rpc'
import {z} from 'zod'

export const Recorder = Rpc.define({
  id: 'recorder',
  methods: {
    config: {input: NoInput, output: recorderConfig},
    state: {input: NoInput, output: z.object({live: z.boolean()})},
    reset: {input: NoInput, output: OkOutput},
    'recordings.exportVideo': {
      input: z.object({clientId: ClientId, id: z.string().min(1).max(256), offset: z.number().int().nonnegative()}),
      output: VideoPieceOutput,
      errors: {expired: z.undefined(), 'render-failed': z.undefined()},
    },
  },
  events: {
    control: {schema: RecorderControlSchema},
    appended: {schema: z.object({clientId: z.string(), cursor: z.number()})},
  },
})
```

An error name that starts with `rpc.` is reserved: `Rpc.define` throws on it.

### Register the handlers

`ctx.rpc.register(contract, handlers)` answers the methods. A handler gets the parsed input and a context with
`error(name, message, data)`, which makes one of the method's declared errors, and returns an `Effect`:

```ts title="packages/plugins/recorder/src/index.ts"
function registerRpc(rpc: Context['rpc'], runtime: RecorderRuntime, announce: Announce) {
  return rpc.register(Recorder, {
    config: () => Effect.sync(() => runtime.config),
    state: () => Effect.sync(() => ({live: runtime.control.isLive()})),
    reset: () =>
      Effect.gen(function* () {
        runtime.rings.clear()
        const appendCursor = runtime.control.emit({snapshot: true, flush: true})
        yield* Effect.promise(() => runtime.control.awaitAppendAfter(appendCursor, RESET_SNAPSHOT_WAIT_MS))
        return OK
      }),
    'recordings.exportVideo': (input, call) =>
      Effect.gen(function* () {
        const file = runtime.recordings.videoFile(input.id)
        const events = yield* Effect.promise(() => runtime.recordings.get(input.id))
        if (!file || !events) return yield* Effect.fail(call.error('expired', `The recording ${input.id} has expired`))
        const rendered = yield* Effect.promise(() => renderedVideo(file, events, runtime.useRenderer))
        if (!rendered)
          return yield* Effect.fail(
            call.error('render-failed', `The recording ${input.id} could not be rendered to video`),
          )
        const piece = yield* Effect.promise(() => readVideoPiece(file, input.offset, MAX_FILE_BYTES))
        return {...piece, ...VIDEO}
      }),
  })
}
```

The registration has `dispose` and `events.emit(name, data)`, which sends an event to every subscriber:

```ts title="packages/plugins/recorder/src/index.ts"
const registration = yield* registerRpc(ctx.rpc, runtime, announce).pipe(Effect.orDie)
yield* Stream.fromQueue(announcements).pipe(
  Stream.runForEach((event) =>
    registration.events
      .emit(...event)
      .pipe(Effect.catch(reportUndelivered), Effect.catchDefect(reportUndelivered)),
  ),
  Effect.forkScoped({startImmediately: true}),
)
```

RPC methods never ask the user. An operation that must ask is a tool.

To call these methods from the widget, see [Call the engine part](/docs/plugins/browser#call-the-engine-part). From
a terminal, see [`conciv plugin call`](/docs/plugins/terminal).

## The promise entry

`@conciv/plugin` is the same engine part without Effect. `Plugin.define` takes `setup(ctx)` instead of `effect`, and
each `ctx` domain returns a `Promise`. `setup` may be async, and may return a cleanup that runs when the plugin stops
or reloads.

```ts title="packages/plugins/test-runner/src/index.ts"
import {Plugin} from '@conciv/plugin'

export default Plugin.define({
  id: 'test-runner',
  async setup(ctx) {
    const config = testRunnerConfig.parse(ctx.options)
    const adapter = getRunner(config.runner) ?? vitest
    const manager = adapter.create(ctx.location.directory)
    await register(ctx.tool, manager)
    await ctx.skill.transform((editor) => editor.add(info))
    const registration = await registerRpc(ctx.rpc, manager)
    const unsubscribe = manager.subscribeRaw((event) => {
      registration.events.emit('event', event).catch((error: unknown) => {
        console.error(`[test-runner] a live test event was not delivered: ${String(error)}`)
      })
    })
    return () => {
      unsubscribe()
      return manager.stop()
    }
  },
})
```

A tool's `execute` and an RPC handler return a `Promise`. A tool fails a call by throwing `Tool.toolError`:

```ts title="packages/plugins/whiteboard/src/tool/refusal.ts"
import {Tool} from '@conciv/plugin'

type Failure = {code?: string; message: string; error?: unknown}

export function fail({code, ...failure}: Failure): never {
  throw Tool.toolError(code === undefined ? failure : {...failure, metadata: {code}})
}
```
