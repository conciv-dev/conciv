A plugin is code you add to conciv. Its engine part gives the agent new tools. Its browser part adds screens to
the widget. A plugin in your project's `conciv/plugins` folder loads with no config entry.

## What a plugin can do

- **Give the agent a tool.** The agent calls it like any built-in tool. The test runner adds `test_runner_run`, so
  you can say "run the tests".
- **Ask the user first.** A tool can stop and show an approval card before it acts.
- **Draw a card in the chat.** A tool's calls show as your own component instead of the generic card.
- **Add a panel.** A tab next to the chat. The test runner's Tests tab follows a run live.
- **Add a slot or a pill.** Content at a fixed place in the widget, or a button above the composer.
- **Answer RPC calls.** Your browser part, a terminal or another plugin calls your engine part by name.

## Pick a plugin or a skill

Start with the smallest thing that does the job:

| You want the agent to                                 | Use                                                                        |
| ----------------------------------------------------- | -------------------------------------------------------------------------- |
| Follow your steps for a kind of task                  | a [skill](/docs/skills), a Markdown file with no code                      |
| Run code you wrote, or read something it cannot reach | a plugin with a [tool](/docs/plugins/guides/tool)                          |
| Show you something in the widget                      | a plugin with a [panel](/docs/plugins/guides/panel) or a card for its tool |

To add a plugin someone else wrote, such as the test runner, see [Add plugins](/docs/usage/add-plugins).
