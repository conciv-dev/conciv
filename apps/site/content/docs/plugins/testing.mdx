title: Testing a plugin
description: Boot the real engine with your plugin, call its tools, and drive its browser part in a headless browser.
---

`@conciv/plugin-testkit` boots the real conciv engine with a fake model, loads your plugin, and opens the real widget
in a browser page. Only the model and the agent CLIs are faked.

```bash
pnpm add -D @conciv/plugin-testkit @conciv/embed vitest playwright
```

## Test the engine part

`bootCoreKit` starts an engine on a free port. `stateRoot` is the project folder: plugins in its `conciv/plugins`
folder load as they would in your app, and `files` writes more files there first. `plugins` is the same list as the
[`plugins` option](/docs/plugins/install).

```ts title="deploy.test.ts"
import {cpSync, mkdtempSync} from 'node:fs'
import {tmpdir} from 'node:os'
import {join} from 'node:path'
import {expect, test} from 'vitest'
import {bootCoreKit} from '@conciv/plugin-testkit/core-kit'

test('the deploy tool answers the preview URL', async () => {
  const project = mkdtempSync(join(tmpdir(), 'deploy-'))
  cpSync('conciv', join(project, 'conciv'), {recursive: true})
  const kit = await bootCoreKit({id: 'deploy-test', stateRoot: project})
  try {
    const {data} = await kit.rpc.plugin.list()
    expect(data.find((plugin) => plugin.id === 'deploy')?.state).toEqual({status: 'active'})
    expect(await kit.callTool('deploy_run', {branch: 'fix-header'})).toEqual({
      url: 'https://fix-header.preview.example.com',
    })
  } finally {
    await kit.cleanup()
  }
})
```

The kit's fields:

<TypeTable
  type={{
    'rpc.plugin.list()': {
      type: 'Promise',
      description: 'Every loaded plugin, with its `id`, `source`, `features` and `state`.',
    },
    'callTool(name, input)': {
      type: 'Promise',
      description: 'Calls a tool by its name without `external_`, from code mode, and answers its output.',
    },
    'writeProjectFile(path, content)': {type: 'void', description: 'Writes a file into the project folder.'},
    stateRoot: {type: 'string', description: 'The project folder.'},
    home: {type: 'string', description: 'The conciv home of this engine.'},
    'base, origin, token': {
      type: 'string',
      description: 'The engine URL, its origin and its token, for `conciv plugin call` or an MCP client.',
    },
    'cleanup()': {type: 'Promise', description: 'Stops the engine.'},
  }}
/>

A plugin that fails to start shows `state: {status: 'failed', error}` in `plugin.list()`.

## Test the browser part

`openPluginWidget` boots the same engine, serves a page with the widget bundle, and opens it in the browser you pass.
Drive the widget by role and visible text, as a user would:

```ts title="deploy.browser.test.ts"
import {cpSync, mkdtempSync} from 'node:fs'
import {createRequire} from 'node:module'
import {tmpdir} from 'node:os'
import {dirname, join} from 'node:path'
import {chromium} from 'playwright'
import {test} from 'vitest'
import {openPluginWidget} from '@conciv/plugin-testkit/widget-suite'

const widgetBundle = join(dirname(createRequire(import.meta.url).resolve('@conciv/embed')), 'conciv-widget.global.js')

test('the Preview pill follows the last deploy', async () => {
  const project = mkdtempSync(join(tmpdir(), 'deploy-'))
  cpSync('conciv', join(project, 'conciv'), {recursive: true})
  const browser = await chromium.launch({headless: true})
  const widget = await openPluginWidget(browser, {id: 'deploy-test', plugins: [], widgetBundle, stateRoot: project})
  try {
    const page = widget.page
    await page.getByRole('button', {name: 'Open conciv chat'}).click()
    await widget.kit.callTool('deploy_run', {branch: 'fix-header'})
    await page.getByRole('button', {name: 'https://fix-header.preview.example.com'}).waitFor()
    await widget.kit.callTool('deploy_run', {branch: 'second'})
    await page.getByRole('button', {name: 'https://second.preview.example.com'}).waitFor()
  } finally {
    await widget.close()
    await browser.close()
  }
})
```

`openPluginWidget` takes `id`, `plugins`,
`widgetBundle`, and optional `files`, `stateRoot` and `body`, the HTML of the page. It returns `page`, `kit` and
`close`.

Never wait for the network to go idle: the widget keeps a socket open. Wait for something the user sees.

## Watch and break the RPC traffic

The widget talks to the engine over one socket. These helpers work on that socket, on a page from `openPluginWidget`:

- `rpcObserverFor(page)` from `@conciv/plugin-testkit/rpc-observer` counts started and completed calls, and waits for
  one with `completed(filter)`.
- `rpcSocketFor(page)` from `@conciv/plugin-testkit/rpc-socket` is the socket itself. Await its `installed` before the
  page loads the widget.
- `@conciv/plugin-testkit/rpc-fault` breaks calls: `failRpcCalls`, `abortRpcCalls`, `garbleRpcReplies`,
  `holdRpcCalls` and `gateRpcCalls`. Each returns an injector you `repair()` or `dispose()`.

The test runner's browser test uses the observer and the socket, in
[`packages/plugins/test-runner/test/test-runner.browser.test.ts`](https://github.com/conciv-dev/conciv/blob/main/packages/plugins/test-runner/test/test-runner.browser.test.ts).
