Add the package, then name it in `plugins` where you add conciv.

```bash
pnpm add -D @conciv/plugin-tanstack
```

import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

A package in the list that is not installed is installed by the engine when it starts. Restart the dev server after
you change the list: the engine reads it once, when it starts.

## Options

Pass options as a `[name, options]` pair. Every option value must be JSON.

```ts
conciv({plugins: [['@conciv/plugin-test-runner', {runner: 'playwright'}]]})
```

## Local paths

An entry that starts with `./`, `../` or `file://` is a folder, resolved from your project root. Files and folders in
`conciv/plugins/` and `conciv/plugin/` need no entry. See [Your first plugin](/docs/plugins/your-first-plugin).

```ts
conciv({plugins: ['./tools/release-plugin']})
```

## Turn a plugin off

An entry that starts with `-` turns off the plugin with that id. Project plugins load before the list, so this turns
off `conciv/plugins/hello`:

```ts
conciv({plugins: ['-hello']})
```

`-*` turns off every plugin loaded before it, built-in ones included, and `-<prefix>.*` every id that starts with the
prefix. A plugin with a
browser half also has a switch in **Settings > Plugins**.
