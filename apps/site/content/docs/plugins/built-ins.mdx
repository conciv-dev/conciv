Two plugins are on in every widget. The rest you add with one line in the `plugins` option. See
[Add a plugin](/docs/plugins#add-a-plugin) for where that option goes.

## On by default

### Page

The agent's view of the page you have open. Its tools read and drive the live page: snapshots, screenshots, the
console, the DOM, forms. Its skill teaches the agent to use them. See [Page control](/docs/usage/page-control).

Nothing to add or configure.

### Terminal

The Terminal tab in the session's pane, for a session whose agent runs in a terminal.

Nothing to add or configure.

## Add one in your config

### Test runner

Package: `@conciv/plugin-test-runner`

- Runs your project's tests when you ask the agent to.
- Streams each run live in a Tests tab.
- Shows the finished run as a card in the chat.

```ts twoslash title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [conciv({plugins: [['@conciv/plugin-test-runner', {runner: 'vitest'}]]})],
})
```

- `runner` picks your test framework: vitest (the default) or playwright.
- jest and node-test are not built yet. The plugin fails to start with either.

See [Live tests](/docs/usage/live-tests).

### Recorder

Package: `@conciv/plugin-recorder`

- Keeps a short recording of the page while recording is on.
- Gives the agent a log of your actions, with screenshots, so it can see what you did.
- Its Recorder tab replays a recording and exports it as a video.

```ts twoslash title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [conciv({plugins: [['@conciv/plugin-recorder', {masking: 'inputs', windowMinutes: 10, console: true}]]})],
})
```

- `masking` hides what you type. It is none (the default), inputs or sensitive.
- `windowMinutes` is how much of the recent page it keeps, up to 60. The default is 10.
- `console` adds the page's console output to the log. It is on by default.

### TanStack

Package: `@conciv/plugin-tanstack`

For an app built with TanStack Router or TanStack Start:

- Gives the agent your dev server's build errors, your route list and recent server function calls.
- Adds a chip to the session's status area and cards for its tools.

```ts twoslash title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [conciv({plugins: ['@conciv/plugin-tanstack']})],
})
```

### iOS

Package: `@conciv/plugin-ios`

- Builds and runs your native iOS app on the simulator.
- Takes screenshots and reads the app's logs.
- Asks you before each build and each run.

```ts twoslash title="vite.config.ts"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [
    conciv({
      plugins: [['@conciv/plugin-ios', {projectRoot: 'ios/PayApp', bundleId: 'dev.conciv.pay', buildMode: 'swiftc'}]],
    }),
  ],
})
```

- `projectRoot` is the folder of your iOS project, from your project root.
- `bundleId` is your app's bundle id.
- `buildMode` is xcodebuild (the default) or swiftc.

Without options every tool answers that the plugin is not configured. See [iOS](/docs/quick-start/ios).
