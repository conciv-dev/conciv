---
title: Add a slot or composer pill
description: Put a small piece of your plugin at a fixed place in the widget, or a pill above the composer.
---

A slot puts your content at a fixed place in the widget, such as a session's status area. A pill sits above the
composer. It runs an action when the user clicks it. You write the browser part with Solid components and plain
async functions.

## Add a slot

Add a slot in your plugin's browser part:

```tsx twoslash title="conciv/plugins/status/plugin-experimental.tsx"
// @jsx: preserve
// @jsxImportSource: solid-js
// ---cut---
import {Plugin, Slot} from '@conciv/frontend-plugin-api'

export default Plugin.define({
  setup(ctx) {
    ctx.add(Slot, {
      at: 'session.status', // <- the place in the widget
      render: (input) => <span>{input.session.run.status() === 'running' ? 'Agent working' : 'Agent idle'}</span>,
    })
  },
})
```

`render` draws the content once. Read `input.session` where you use it, so it follows the session on screen. The
places a slot can go:

- `session.header`: a session's header.
- `session.status`: a session's status area.
- `window.bottom`: the bottom of the widget window.
- `page.overlay`: over your app's page, outside the widget. It keeps keyboard focus inside, unless you set
  `hides: false`.

Build it as in [Build the browser part](/docs/plugins/first-plugin#build-the-browser-part), then reload.

## Add a pill above the composer

A pill can put text in the composer for the user to send:

```tsx twoslash title="conciv/plugins/status/plugin-experimental.tsx"
import {ComposerPill, Plugin} from '@conciv/frontend-plugin-api'

export default Plugin.define({
  setup(ctx) {
    ctx.add(ComposerPill, {
      id: 'review',
      order: 20, // <- sorts it among the other pills
      show: (input) => ({
        label: 'Review',
        icon: 'eye',
        run: () => input.screen.composer.insert('Review my last change and list what could break.'),
      }),
    })
  },
})
```

A few things to notice:

- `show` returns what the pill looks like, or `undefined` to hide it. It runs once per composer on screen.
- `icon` is a name from the widget's icon set, as for `ctx.ui.Icon`.
- `run` is what a click does. Here it puts a prompt in the composer. The user sends it.

Build it as in [Build the browser part](/docs/plugins/first-plugin#build-the-browser-part), then reload.

## Show something only some of the time

Pass a function to `ctx.add`. The widget runs it again when what it reads changes. Returning `undefined` adds nothing:

```tsx twoslash title="conciv/plugins/status/plugin-experimental.tsx"
// @jsx: preserve
// @jsxImportSource: solid-js
// ---cut---
import {Plugin, Slot} from '@conciv/frontend-plugin-api'

export default Plugin.define({
  setup(ctx) {
    const badge: Slot = {at: 'window.bottom', render: () => <span>Dev build</span>}
    ctx.add(Slot, () => (ctx.app.channel === 'dev' ? badge : undefined)) // <- only in a dev build
  },
})
```

`ctx.app.channel` is the widget's release channel. Build it as in
[Build the browser part](/docs/plugins/first-plugin#build-the-browser-part), then reload.
