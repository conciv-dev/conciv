title: Add a panel
description: Add a tab to the session's pane, next to the chat, and draw your plugin's own screen in it.
---

The last section imports `@conciv/client`, which the tutorial did not install. The widget provides it at run time,
and the install gives your editor its types.

```package-install
npm install -D @conciv/client
```

A panel adds a tab next to the chat, for something your plugin shows all the time: a list, a log, a live run. The
browser part is written with Solid components and plain async functions.

## Basic

Add the panel in your plugin's browser part:

```tsx twoslash title="conciv/plugins/plant-shelf/plugin-experimental.tsx"
// @jsx: preserve
// @jsxImportSource: solid-js
// ---cut---
import {Panel, Plugin, type PanelTab} from '@conciv/frontend-plugin-api'

export default Plugin.define({
  setup(ctx) {
    const shelf: PanelTab = {
      id: 'shelf',
      title: 'Shelf', // <- the tab's name, wherever the widget needs text
      pinned: true, // <- always in the strip
      label: () => (
        <>
          <ctx.ui.Icon name="box" size="small" />
          Shelf
        </>
      ), // <- what the strip draws; without it, the title
    }

    ctx.add(Panel, {
      id: 'shelf',
      region: 'pane', // <- required, and the only region today
      list: () => [shelf],
      render: (props) => <p>Plants in {props.session.directory}</p>,
    })
  },
})
```

<Playground page="vite-react" script="plugins/panel-tab" caption="A plugin's tab next to the chat" />

A few things to notice:

- `title` is the tab's name. The strip draws `label` when you give one, and the title when you do not.
- `list` returns the tabs to show. It runs again when what it reads changes, so return a pinned tab every time.
- `render` draws a tab's content once, and your component updates itself from then on.
- `props.session` is the session on screen. Read it where you use it, since it changes without a remount.

Build it as in [Build the browser part](/docs/plugins/first-plugin#build-the-browser-part), then reload.

## Show a tab only some of the time

Return the tab from `list` only when it applies:

```tsx twoslash title="conciv/plugins/plant-shelf/plugin-experimental.tsx"
// @jsx: preserve
// @jsxImportSource: solid-js
// ---cut---
import {Panel, Plugin, type PanelTab} from '@conciv/frontend-plugin-api'

export default Plugin.define({
  setup(ctx) {
    const report: PanelTab = {id: 'report', title: 'Report'}

    ctx.add(Panel, {
      id: 'report',
      region: 'pane',
      list: (input) => (input.open.includes('report') ? [report] : []), // <- open: your tabs the user has open
      render: () => <p>The last report</p>,
    })
  },
})
```

A tab that is not pinned shows only while the user has it open. When they close it, it leaves `input.open`. Build it
as in [Build the browser part](/docs/plugins/first-plugin#build-the-browser-part), then reload.

## Load data into the tab

Read from your engine part inside `render`, with the widget's query hooks. The data then shares the widget's cache:

```tsx twoslash title="conciv/plugins/plant-shelf/plugin-experimental.tsx"
// @jsx: preserve
// @jsxImportSource: solid-js
// @filename: rpc.ts
import * as Rpc from '@conciv/protocol/schema/rpc'
import {z} from 'zod'
const Plant = z.object({plant: z.string()})
const Stock = z.object({plant: z.string(), count: z.number()})
export const Shelf = Rpc.define({
  id: 'plant-shelf',
  methods: {count: {input: Plant, output: Stock}},
  events: {},
})
// @filename: plugin-experimental.tsx
// ---cut---
import {useQuery} from '@conciv/client'
import {Panel, Plugin, type PanelTab} from '@conciv/frontend-plugin-api'
import {Shelf} from './rpc'

export default Plugin.define({
  setup(ctx) {
    const shelf: PanelTab = {id: 'shelf', title: 'Shelf', pinned: true}

    ctx.add(Panel, {
      id: 'shelf',
      region: 'pane',
      list: () => [shelf],
      render: () => {
        const ferns = useQuery(() => ({
          queryKey: ['plant-shelf', 'fern'], // <- start with your plugin's id, so keys never clash
          queryFn: () => ctx.client.rpc(Shelf).count({plant: 'fern'}),
        }))
        return <p>{ferns.data ? `${ferns.data.count} ferns` : 'Counting'}</p>
      },
    })
  },
})
```

`queryFn` calls your engine part through its contract. See [Share an RPC method](/docs/plugins/guides/rpc). Build
it as in [Build the browser part](/docs/plugins/first-plugin#build-the-browser-part), then reload.
