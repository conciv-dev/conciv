---
title: Add a panel
description: Add a tab to the session's pane, next to the chat, and draw your plugin's own screen in it.
---

A panel adds a tab to the session's pane, next to the chat. Use one when your plugin has something to show all the
time: a list, a log, a live run. The test runner's Tests tab is a panel.

The browser part is written with Solid components and plain async functions.

## Add the tab

Add the panel in your plugin's browser part:

```tsx twoslash title="plugin-experimental.tsx"
// @jsx: preserve
// @jsxImportSource: solid-js
// ---cut---
import {Panel, Plugin, type PanelTab} from '@conciv/frontend-plugin-api'

export default Plugin.define({
  setup(ctx) {
    const shelf: PanelTab = {
      id: 'shelf',
      title: 'Shelf',
      pinned: true,
      label: () => (
        <>
          <ctx.ui.Icon name="box" size="small" />
          Shelf
        </>
      ),
    }

    ctx.add(Panel, {
      id: 'shelf',
      region: 'pane',
      list: () => [shelf],
      render: (props) => <p>Plants in {props.session.directory}</p>,
    })
  },
})
```

- `PanelTab` is one tab. Its title names it.
- `label` is what the tab strip draws for it.
- `pinned: true` marks a tab that is always in the strip. Return it from `list` every time.
- `ctx.ui.Icon` draws an icon from the widget's set, so your tab looks like the widget's own.
- `ctx.add(Panel, ...)` adds the panel. The region is always the session's pane.
- `list` returns the tabs to show. It runs again when what it reads changes.
- `render` draws a tab's content once. Your component updates itself from then on.
- `props.session` is the session on screen. Read it where you use it: it changes when the user opens another
  session, and the panel stays mounted.

## Show a tab only some of the time

Return the tab from `list` only when it applies:

```tsx twoslash title="plugin-experimental.tsx"
// @jsx: preserve
// @jsxImportSource: solid-js
// ---cut---
import {Panel, Plugin, type PanelTab} from '@conciv/frontend-plugin-api'

export default Plugin.define({
  setup(ctx) {
    const report: PanelTab = {id: 'report', title: 'Report'}

    ctx.add(Panel, {
      id: 'report',
      region: 'pane',
      list: (input) => (input.open.includes('report') ? [report] : []),
      render: () => <p>The last report</p>,
    })
  },
})
```

- `input.open` holds the ids of your tabs the user has open in this session.
- A tab that is not pinned shows only while the user has it open. When they close it, it leaves `input.open`.

## Load data into the tab

Read from your engine part inside `render`. Use the widget's query hooks, so the data shares the widget's cache:

```tsx twoslash title="plugin-experimental.tsx"
// @jsx: preserve
// @jsxImportSource: solid-js
// @filename: rpc.ts
import * as Rpc from '@conciv/protocol/schema/rpc'
import {z} from 'zod'
const Plant = z.object({plant: z.string()})
const Stock = z.object({plant: z.string(), count: z.number()})
export const Shelf = Rpc.define({
  id: 'plant-shelf',
  methods: {count: {input: Plant, output: Stock}},
  events: {},
})
// @filename: plugin-experimental.tsx
// ---cut---
import {useQuery} from '@conciv/client'
import {Panel, Plugin, type PanelTab} from '@conciv/frontend-plugin-api'
import {Shelf} from './rpc'

export default Plugin.define({
  setup(ctx) {
    const shelf: PanelTab = {id: 'shelf', title: 'Shelf', pinned: true}

    ctx.add(Panel, {
      id: 'shelf',
      region: 'pane',
      list: () => [shelf],
      render: () => {
        const ferns = useQuery(() => ({
          queryKey: ['plant-shelf', 'fern'],
          queryFn: () => ctx.client.rpc(Shelf).count({plant: 'fern'}),
        }))
        return <p>{ferns.data ? `${ferns.data.count} ferns` : 'Counting'}</p>
      },
    })
  },
})
```

- `useQuery` comes from `@conciv/client`, which the widget provides. Your plugin does not bundle its own copy.
- `queryKey` names the data in the cache. Start it with your plugin's id, so it cannot clash with another plugin.
- `queryFn` calls your engine part. See [Share an RPC method](/docs/plugins/guides/rpc).
