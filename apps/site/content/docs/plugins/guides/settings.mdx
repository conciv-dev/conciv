title: Add settings

A plugin has two kinds of settings. **Options** live in the project's conciv config. The team shares them
through the repo. **A setting in the widget** is one the user changes. It stays on their machine.

<AgentPrompt prompt="settings" />

## Pass options from the config

A plugin in `conciv/plugins` loads with no options. To pass some, list its folder in the `plugins` option as
`[path, options]`:

```ts twoslash title="vite.config.ts" tab="Vite" tab-group="bundler"
import {defineConfig} from 'vite'
import conciv from '@conciv/it/plugin/vite'

export default defineConfig({
  plugins: [conciv({plugins: [['./conciv/plugins/tickets', {project: 'OPS', closeAfterDays: 30}]]})],
})
```

```ts twoslash title="next.config.ts" tab="Next.js" tab-group="bundler"
import type {NextConfig} from 'next'
import {withConciv} from '@conciv/it/plugin/nextjs'

const nextConfig: NextConfig = {}

export default withConciv(nextConfig, {plugins: [['./conciv/plugins/tickets', {project: 'OPS', closeAfterDays: 30}]]})
```

```js title="webpack.config.js" tab="webpack" tab-group="bundler"
const conciv = require('@conciv/it/plugin/webpack')

module.exports = {
  mode: 'development',
  plugins: [conciv.default({plugins: [['./conciv/plugins/tickets', {project: 'OPS', closeAfterDays: 30}]]})],
}
```

```js title="rspack.config.js" tab="Rspack" tab-group="bundler"
const conciv = require('@conciv/it/plugin/rspack')

module.exports = {
  mode: 'development',
  plugins: [conciv.default({plugins: [['./conciv/plugins/tickets', {project: 'OPS', closeAfterDays: 30}]]})],
}
```

Your engine part reads them as `ctx.options`. Check them with a schema first, since the user can write anything:

```ts twoslash title="conciv/plugins/tickets/server.ts" tab="Promise" tab-group="plugin-api"
import {z} from 'zod'
import {Plugin} from '@conciv/backend-plugin-api'

const Options = z.object({
  project: z.string(),
  closeAfterDays: z.number().int().positive().default(14), // <- 14 unless the user sets it
})

export default Plugin.define({
  id: 'tickets',
  async setup(ctx) {
    const options = Options.parse(ctx.options)
    await ctx.tool.transform((tools) => {
      tools.add({
        name: 'ticket_policy',
        description: 'Name the tracker project this repo files tickets in, and when stale tickets close.',
        input: z.object({}),
        execute: async () => ({
          content: `Tickets go in ${options.project}. Stale tickets close after ${options.closeAfterDays} days.`,
        }),
      })
    })
  },
})
```

```ts twoslash title="conciv/plugins/tickets/server.ts" tab="Effect" tab-group="plugin-api"
import {Effect} from 'effect'
import {z} from 'zod'
import {Plugin} from '@conciv/backend-plugin-api/effect'

const Options = z.object({
  project: z.string(),
  closeAfterDays: z.number().int().positive().default(14), // <- 14 unless the user sets it
})

export default Plugin.define({
  id: 'tickets',
  effect: (ctx) =>
    Effect.gen(function* () {
      const options = yield* Effect.sync(() => Options.parse(ctx.options))
      yield* ctx.tool.transform((tools) => {
        tools.add({
          name: 'ticket_policy',
          description: 'Name the tracker project this repo files tickets in, and when stale tickets close.',
          input: z.object({}),
          execute: () =>
            Effect.succeed({
              content: `Tickets go in ${options.project}. Stale tickets close after ${options.closeAfterDays} days.`,
            }),
        })
      })
    }),
})
```

A few things to notice:

- `ctx.options` is the object from the config entry. Every value in it is JSON.
- `Options.parse` checks it and fills in the defaults.
- In both tabs a parse that fails stops the plugin from loading, with zod's message in the log. That tells the user
  what to fix.
- The browser part gets the same object as `ctx.options`.

## Add a setting to the widget

Declare a store for the value, then add a row to the widget's settings. You write the browser part in Solid, React,
Preact or plain DOM:

<Tabs groupId="ui-framework" persist items={['Solid', 'React', 'Preact', 'Plain DOM']}>
<Tab value="Solid">

```tsx twoslash title="conciv/plugins/tickets/plugin-experimental.tsx"
// @jsx: preserve
// @jsxImportSource: solid-js
// ---cut---
import {Plugin, SettingsPage, Store, usePlugin} from '@conciv/frontend-plugin-api'
import {z} from 'zod'

const stores = {
  prefs: Store.global(z.object({showClosed: z.boolean()}), {showClosed: false}), // <- one value for every project
}

function ShowClosedRow() {
  const ctx = usePlugin<{stores: typeof stores}>()
  const prefs = ctx.stores.prefs
  return (
    <ctx.ui.SettingsRow title="Show closed tickets">
      <ctx.ui.Switch
        label="Show closed tickets"
        hideLabel
        checked={prefs.value.showClosed}
        onChange={(checked) => prefs.set({showClosed: checked})}
      />
    </ctx.ui.SettingsRow>
  )
}

export default Plugin.define({
  stores, // <- the widget loads these before setup runs
  setup(ctx) {
    ctx.add(SettingsPage, {
      id: 'tickets',
      page: 'general',
      section: 'general', // <- one row in the General section
      title: 'Tickets',
      entries: [{id: 'show-closed', title: 'Show closed tickets', keywords: 'tickets closed'}],
      render: () => <ShowClosedRow />,
    })
  },
})
```

</Tab>
<Tab value="React">

The row lives in your app. Give it to `<ConcivWidget>` as in
[Build your first plugin](/docs/plugins/first-plugin#build-or-wire-the-browser-part).

```tsx twoslash title="src/conciv/tickets.tsx"
// @jsx: react-jsx
// @jsxImportSource: react
// ---cut---
import {useState} from 'react'
import {Plugin, SettingsPage, Store} from '@conciv/frontend-plugin-api'
import {reactRender} from '@conciv/react'
import {z} from 'zod'

export const ticketsDeclarations = Plugin.define({
  stores: {
    prefs: Store.global(z.object({showClosed: z.boolean()}), {showClosed: false}), // <- one value for every project
  },
})

export const tickets: Plugin.Setup<typeof ticketsDeclarations> = (ctx) => {
  const prefs = ctx.stores.prefs

  function ShowClosedRow() {
    const [showClosed, setShowClosed] = useState(prefs.value.showClosed) // <- read once, as the row draws
    return (
      <label>
        <input
          type="checkbox"
          checked={showClosed}
          onChange={(event) => {
            setShowClosed(event.currentTarget.checked)
            prefs.set({showClosed: event.currentTarget.checked})
          }}
        />
        Show closed tickets
      </label>
    )
  }

  ctx.add(SettingsPage, {
    id: 'tickets',
    page: 'general',
    section: 'general', // <- one row in the General section
    title: 'Tickets',
    entries: [{id: 'show-closed', title: 'Show closed tickets', keywords: 'tickets closed'}],
    render: reactRender(ShowClosedRow),
  })
}
```

Spread the declarations into the entry, so the widget loads the store before setup runs:

```ts twoslash title="src/app.tsx"
// @filename: src/conciv/tickets.ts
import {Plugin, Store} from '@conciv/frontend-plugin-api'
import {z} from 'zod'
export const ticketsDeclarations = Plugin.define({
  stores: {prefs: Store.global(z.object({showClosed: z.boolean()}), {showClosed: false})},
})
export const tickets: Plugin.Setup<typeof ticketsDeclarations> = () => {}
// @filename: src/app.ts
// ---cut---
import {tickets, ticketsDeclarations} from './conciv/tickets'

const plugins = [[{id: 'tickets', ...ticketsDeclarations, windowEntry: async () => ({default: tickets})}, {}]] as const
```

```ts twoslash title="conciv/plugins/tickets/plugin-experimental.ts"
import {mountRender, Plugin, SettingsPage, Store} from '@conciv/frontend-plugin-api'
import {z} from 'zod'

const stores = {
  prefs: Store.global(z.object({showClosed: z.boolean()}), {showClosed: false}), // <- one value for every project
}

export default Plugin.define({
  stores, // <- the widget loads these before setup runs
  setup(ctx) {
    const prefs = ctx.stores.prefs
    ctx.add(SettingsPage, {
      id: 'tickets',
      page: 'general',
      section: 'general', // <- one row in the General section
      title: 'Tickets',
      entries: [{id: 'show-closed', title: 'Show closed tickets', keywords: 'tickets closed'}],
      render: mountRender((element) => {
        const label = element.appendChild(document.createElement('label'))
        const box = label.appendChild(document.createElement('input'))
        box.type = 'checkbox'
        box.checked = prefs.value.showClosed // <- read once, as the row draws
        box.addEventListener('change', () => prefs.set({showClosed: box.checked}))
        label.append('Show closed tickets')
        return () => label.remove()
      }),
    })
  },
})
```

</Tab>
</Tabs>

A few things to notice:

- `prefs.value` is the stored value. `prefs.set` replaces it. The widget saves it for you.
- In Solid, `usePlugin` gives a component your plugin's context. `ctx.stores.prefs` is typed from the declaration.
- In Solid, `ctx.ui` holds the widget's own components, so the row looks like the widget's own settings. They are
  Solid components, so the other tabs draw a plain checkbox.
- `prefs.value` is a Solid store. Outside Solid, read it once as the row draws, and keep your own state after.
- `entries` is what the settings search finds.
- With no `page`, the entry is a page of its own. With only `page: 'general'`, it is a section on the General page.

Build or wire it as in [Build or wire the browser part](/docs/plugins/first-plugin#build-or-wire-the-browser-part),
then reload.

<Accordion title="A value per project or per session">

`Store.project` keeps one value for the project the engine runs in. `Store.session` keeps one value per session.
You call it with the session:

<Tabs groupId="ui-framework" persist items={['Solid', 'React', 'Preact', 'Plain DOM']}>
<Tab value="Solid">

```tsx twoslash title="conciv/plugins/tickets/plugin-experimental.tsx"
// @jsx: preserve
// @jsxImportSource: solid-js
// ---cut---
import {Plugin, Slot, Store} from '@conciv/frontend-plugin-api'
import {z} from 'zod'

const stores = {
  view: Store.session(z.object({filter: z.string()}), {filter: 'open'}),
}

export default Plugin.define({
  stores,
  setup(ctx) {
    ctx.add(Slot, {
      at: 'session.status',
      render: (input) => <span>Showing {ctx.stores.view(input.session).value?.filter ?? 'open'} tickets</span>,
    })
  },
})
```

</Tab>
<Tab value="React">

The store's `value` is a Solid signal. Read it in the function you give `ctx.add`, which runs again when it changes:

```tsx twoslash title="src/conciv/tickets.tsx"
// @jsx: react-jsx
// @jsxImportSource: react
// ---cut---
import {Plugin, Slot, Store} from '@conciv/frontend-plugin-api'
import {reactRender} from '@conciv/react'
import {z} from 'zod'

export const ticketsDeclarations = Plugin.define({
  stores: {view: Store.session(z.object({filter: z.string()}), {filter: 'open'})},
})

function Showing(props: {readonly filter: string}) {
  return <span>Showing {props.filter} tickets</span>
}

export const tickets: Plugin.Setup<typeof ticketsDeclarations> = (ctx) => {
  ctx.add(Slot, (): Slot => {
    const session = ctx.sessions.current()
    const filter = (session && ctx.stores.view(session).value?.filter) ?? 'open'
    return {at: 'session.status', render: reactRender(() => <Showing filter={filter} />)}
  })
}
```

</Tab>

```ts twoslash title="conciv/plugins/tickets/plugin-experimental.ts"
import {mountRender, Plugin, Slot, Store} from '@conciv/frontend-plugin-api'

  view: Store.session(z.object({filter: z.string()}), {filter: 'open'}),

  stores,

        at: 'session.status',
```
