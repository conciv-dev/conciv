# src

## Overview

Router factory, TanStack Start instance with request middleware, generated route tree, and the components, lib and routes folders.

## Subdirectories & Boundaries

- [components](./components/README.md), [lib](./lib/README.md), [routes](./routes/README.md)

## Invariants

- `routeTree.gen.ts` is generated by TanStack Router; never edit it.
- `start.ts:csrfMiddleware`: CSRF checks apply to server functions (`handlerType === 'serverFn'`)
- `server.ts`: the paths in `wrangler.jsonc` `assets.run_worker_first` (the HTML pages, never static files) reach the Worker, which serves the prerendered page from `ASSETS` (or the TanStack handler on a 404 or a non-GET) and fills the star count into every HTML response; the build makes no GitHub call
- `start.ts:llmMiddleware`: a `/docs` request that prefers markdown (`isMarkdownPreferred`) and does not end in `.md` is redirected to the `.md` path

## Side Effects

- `start.ts:llmMiddleware`: issues redirects

## Verification

- Run: `pnpm exec turbo run typecheck test --filter=site` and `pnpm lint` from the repo root (turbo builds the package and its dependencies first)
