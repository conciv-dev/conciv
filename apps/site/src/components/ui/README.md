# ui

## Overview

shadcn-style React primitives built on `radix-ui` and `class-variance-authority`, plus animated icons built on `motion/react`, and `video-player.tsx`, a video player skin built from the headless `@videojs/react` parts.

## Invariants

- None

## Side Effects

- None

## Verification

- Run: `pnpm exec turbo run typecheck test --filter=site` and `pnpm lint` from the repo root (turbo builds the package and its dependencies first)
