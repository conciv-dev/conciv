# site

The conciv.dev site: a TanStack Start (React) app with the fumadocs MDX docs in `content/docs`, prerendered at build
time and served from a Cloudflare Worker. The live conciv widget is mounted on the page: the dev server loads it
through the conciv Vite plugin, and the published site composes the try-it plugin (`@conciv/plugin-try-it`), which
connects the widget to an engine the visitor starts on their own machine.

Run the dev server on port 3001:

```bash
pnpm dev
```

## Invariants

- The docs pages describe the product as the code has it today. Every command, option, message and path on a page is
  read from the current source, and every code block is copied from a real file or a command that was run.
- Screenshots in `public/screenshots` show only text that still exists in the widget's code. A shot whose labels no
  longer match is removed, and the page says it in words instead.
- The ONNX runtime `.wasm` files (`assets/ort-*`) are dropped from the server bundle (`vite.config.ts`).
- The prerender skips paths under `/assets/`, and `vite preview` (which the prerender uses) binds `127.0.0.1`.
- Production has `workers_dev: false` and `preview_urls: false` (`wrangler.jsonc`); the `preview` environment turns
  both on.
- `worker-configuration.d.ts` is generated by `pnpm cf-typegen` (`wrangler types`); do not edit it.

## Side effects

- `pnpm build` writes `public/site-source.json` (the source manifest) before `vite build`.
- `pnpm deploy` builds and runs `wrangler deploy`, which publishes the Worker `conciv-site` to `conciv.dev` and
  `www.conciv.dev`.

## Verification

- `pnpm exec turbo run test --filter=site` from the repo root (turbo builds the site and its dependencies first).
- Subfolders: [scripts](./scripts/README.md), [src](./src/README.md).
