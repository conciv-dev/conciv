# site

## Overview

The conciv.dev site: TanStack Start (React) with fumadocs MDX docs, prerendered and served from a Cloudflare Worker, with the conciv widget mounted live on the page.

This is a Tanstack Start application generated with
[Create Fumadocs](https://github.com/fuma-nama/fumadocs).

Run development server:

```bash
npm run dev
# or
pnpm dev
# or
yarn dev
```

Deploys to [conciv.dev](https://conciv.dev) via Cloudflare Workers Builds on push to `main`
(watch paths: `apps/site/**`, `packages/{mascot,it,protocol}/**`).

## Interface

- `vite.config.ts`: plugins `sourceAnnotations`, `dropOnnxRuntimeWasmFromServerBundle`, `cloudflare({viteEnvironment: {name: 'ssr'}})`, `mdx`, `tailwindcss`, `tanstackStart({prerender: {enabled: true}})`, `react`, `conciv({widget: {quickTerminal: {hotkey: ['Alt+k']}}})`; dev port 3001
- `source.config.ts`: `docs = defineDocs({dir: 'content/docs'})` with `remarkMdxMermaid`
- `wrangler.jsonc`: Worker `conciv-site` on `conciv.dev` and `www.conciv.dev`, `ASSETS` binding, `preview` env `conciv-site-preview`
- `brand-assets-alias.ts`: `brandAssetsAlias` maps `@brand-assets` to the `@conciv/brand` package directory
- `worker-configuration.d.ts`: Cloudflare runtime types generated by `pnpm cf-typegen` (`wrangler types`); do not edit
- scripts (`package.json`): `dev`, `build` (copy widget bundle, build source manifest, `vite build`), `deploy` (`wrangler deploy`), `typecheck`, `lint`, `test`, `test:e2e`, `gen:snippets`
- `vitest.config.ts`: node unit tests `test/**/*.test.ts` excluding `*.it.test.ts`; `vitest.e2e.config.ts` for e2e
- Subdirectories: [scripts](./scripts/README.md), [src](./src/README.md)

## Invariants

- `vite.config.ts:dropOnnxRuntimeWasmFromServerBundle`: `assets/ort-*.wasm` files are removed from the SSR bundle
- `vite.config.ts`: prerender skips paths starting with `/assets/`
- `package.json:build`: `packages/embed` must be built first; `copy-widget-bundle.mjs` copies its `dist/conciv-widget.global.js`
- `wrangler.jsonc`: production has `workers_dev: false` and `preview_urls: false`

## Side Effects

- `package.json:deploy`: `wrangler deploy` publishes the Worker to Cloudflare
- `package.json:build`: writes `public/conciv-widget.global.js` and `public/site-source.json`

## Verification

- Run: `pnpm exec turbo run typecheck lint test --filter=site` from the repo root (turbo builds the package and its dependencies first)
