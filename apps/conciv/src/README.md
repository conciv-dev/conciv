# src

## Overview

Router factory, standalone browser entry, generated TanStack route tree and module declarations for `?inline` css/woff2 imports.

## Interface

- `createConcivRouter(config)` (`router.tsx`): builds the Solid router with QueryClient, AppData, extension instances (always prepends the `highlight` extension), engine reachability and router context
- `disposeConcivRouter(router)` (`router.tsx`): calls `router.options.context.disposeInstances()`
- `ConcivRouterContext`, `ConcivRouterConfig`, `ConcivEnvironment` types (`router.tsx`)
- `routeTree` (`routeTree.gen.ts`): generated; full paths `/`, `/panel`, `/quick`, `/panel/$sessionId`, `/panel/connect`, `/panel/latest`, `/pip/$sessionId`, `/panel/$sessionId/`, `/panel/$sessionId/$view`
- `start` (`entry-standalone.tsx`): reads `?settings` and `?core`, builds the router with `makeBrowserRpcClient` and the page extension, renders into `#app`
- `css.d.ts`: `*.css?inline` and `*.woff2?inline` string module declarations
- Subdirectories: [app](./app/README.md), [composer](./composer/README.md), [data](./data/README.md), [extension](./extension/README.md), [extensions](./extensions/README.md), [lib](./lib/README.md), [pane](./pane/README.md), [routes](./routes/README.md), [shell](./shell/README.md)

## Invariants

- `router.tsx:makeGuardedDisposer`: the dispose function runs at most once
- `router.tsx:disposeExtensionInstances`: each `instance.dispose()` is wrapped in try/catch so one failing teardown does not stop the rest
- `router.tsx:wireEngineReachability`: reachability is re-set up only when `apiBase()` changes, and the previous setup is cleaned up first
- `router.tsx:createConcivRouter`: `defaultPendingMs` 300, `defaultPendingMinMs` 500, scroll restoration off; defaults `connected=()=>true`, `apiBase=()=>''`, `connectionGeneration=()=>0`, `connectMode=false`
- `routeTree.gen.ts`: generated by `tsr generate`; do not edit

## Side Effects

- `entry-standalone.tsx:start`: writes `window.__CONCIV_API_BASE__`, reads `window.location.search`, creates browser history, renders into `#app`, opens an rpc client with `makeBrowserRpcClient(apiBase)`
- `router.tsx:wireEngineReachability`: calls `setupEngineReachability(apiBase)` from `@conciv/client`
- `router.tsx:disposeExtensionInstances`: `console.error` on teardown failure
