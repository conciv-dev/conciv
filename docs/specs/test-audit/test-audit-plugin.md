### 5. Odd things / rule breaks

- Ported from opencode (see provenance); keep its names and cases.
- ~40% of the file is type assertions inside runtime `it` blocks. A broken type fails `pnpm typecheck`, not `pnpm test`; a reader of a green `vitest` run can't tell these were checked.
- `vi.useFakeTimers` in Scope (allowed by the 2026-11-16 ruling; the deadline is an option set to 1 s and advanced by fake time, not waited).
- No `vi.fn`/`vi.mock`/`vi.spyOn`. Bundles are evaluated with a hand-written `require` provider (`provider()`), not module mocks.
- Two real `vite build` runs (987, 1018) with 60 s timeouts; slowest tests in the file.
- `published declarations` reads `dist/` (needs a build first; turbo's test-after-build covers it). It reads lazily inside the tests, so a missing dist fails two tests, not the file.
- Test-file budget: the package's node project includes **two** node files (`test/plugin.test.ts` and `test/client/shared-events.test.ts`) plus one browser file, over the "one node + one browser file per package" rule.
