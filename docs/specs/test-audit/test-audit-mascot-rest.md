# Test audit: mascot / mascot-react / brand / brand-react browser + unit files (285 + 319 + 355 + 101 + 75 + 93 = 1,228 lines, origin/main 51708bc06)

Read start to end, all six files, plus `packages/mascot/test/browser/mascot-dom.ts`, the byte-identical `packages/mascot-react/test/browser/mascot-dom.ts`, and `packages/brand/test/browser/lockup-dom.ts` (identical to brand-react's). Cross-checked against test-audit-mascot-it.md (packages/mascot/test/e2e/mascot.it.test.ts, "mascot.it:N"), test-audit-site.md and test-audit-e2e.md (the e2e apps only see the FAB; no lockup test anywhere else).

Budgets: mascot has two browser files (solid-mascot.browser + mascot.it, which is a browser file under an e2e name, see mascot-it report) + one unit: over budget by one. mascot-react, brand, brand-react: within budget.

Packed tests (`{tags: ['packed']}`) are skipped except in `.github/workflows/packed.yml` (vitest-config reporters.ts: `skip: mode !== 'packed'`).

Blanket rule breaks for the two wrapper browser files (not repeated per row): part lookups by `[data-scope="mascot"][data-part=...]`, emitter/rider detection by `span[aria-hidden]` child shape, geometry via `getBoundingClientRect`, GSAP tween reads via `gsap.getProperty`, injected `<style>` rules. Same sanctioned-exception question the mascot.it report raises: there is no user-level observable for these.

### 2. Lines that would go

DUPLICATE + COVERED rows span ~20 lines: 1,228 → ~1,208. Merging the sizing tables, slot tables and emitter tables in both wrappers: ~950.

### 3. Journeys a lean rewrite would use

1. Wrapper contract (one per framework): sizing table (default/class/style/paint-only/shadow), part slots (replace/restore/churn/order/duplicate throws/keyed swap), emitters (default, per child, stand-down, flap drain, curve drain with riders), gaze opt-out on real hover, leak guard; React adds fragment/list children and StrictMode.
2. Publish contract (node): packed install per framework (packed workflow only), entry graph isolation, sideEffects, types, adapter names.
3. Lockup (one per framework): focus-visible wakes, leave/blur settles, unmount stops.

### 4. Cross-file / cross-level duplicates (verified by reading the other test)

- solid:24 vs mascot unit:136: built solid entry renders every part (dist import in Chromium vs packed tarball SSR).
- mascot unit:240/245 vs 125: the packed probe already imports every `effects/*` subpath and lists its functions, including `configureBinaryEffect`.
- solid:231 vs solid:186: arc curve gives 5 riders in both.
- solid and react wrapper files are the same 18 behaviours in two frameworks (different wrapper code, so both stay), with byte-identical `mascot-dom.ts` helpers copied in two packages; brand/brand-react are the same 4 tests with identical `lockup-dom.ts`. A shared suite (like `widgetComponentSuite` in plugin-testkit) fed a mount function per framework would remove one copy of each.
- Wrapper rows vs mascot.it: per the mascot-it report, 176/211/221/231/248/264 are the wrapper layer of core contracts there, not duplicates.

### 5. Odd things / rule breaks

- Lockup tests are named "settles the cursor solid" but assert cursor opacity '0' (hidden): the name or the assert is wrong.
- Lockup tests wait out the product's settle window with `wait(900)` / `wait(150)` fixed sleeps (timing guess, waiting out a product timer); make the window an option or use fake timers.
- react:332/347 monkey-patch `window.addEventListener` to count listeners (spy family).
- `globalThis.IS_REACT_ACT_ENVIRONMENT = true` set at module scope in both React files.
- Real-time `vi.waitFor` drains with a 3s cap (solid 176/186, react 243/252).
- Unit files read `dist/` and spawn `tar`, `node`, `find`; the packed tests only run in the packed workflow, so a normal `pnpm test` never runs 125/136/59.

### 7. Rewrite input

Keep the publish contracts as they are (minus 240/245). Turn each wrapper file into tables (sizing, slots, emitters) and consider one shared wrapper suite fed by both frameworks. Fix the lockup names/asserts and replace the fixed sleeps. Estimated lean size: ~800 lines (from 1,228): wrappers ~250 each (or ~300 once with a shared suite), units ~250, lockups ~50 each.
