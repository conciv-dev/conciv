### 2. Lines that would go

### 3. Journeys a lean rewrite would use

1. Copy: hook writes, copied → idle (fake timers), re-arm, refusal/throw, announcements; button name, tooltip, keyboard focus ring, onCopied (168, 176, 183, 236, 1109, 1122, 1140 + merges).
2. Dialog: Escape / outside click / non-dismissable, starved frames, name from heading, alertdialog, initial focus and return focus across roots, stacked parts in both modes, layout (tall content, transformed parent, other-window shadow, long command) (329-604).
3. Tooltips and truncation: tooltip vs menu trigger, keyboard menu, shadow-root tooltips, truncated reveal / no reveal / no tab stop, group unmount (983, 995, 1039, 1232, 1248).
4. Text area autosize: fit, grow, maxRows with line-height normal, minRows, refit on width, height reports (868-914, 82).
5. Virtual JSON tree: windowing, open big branch, End, keyboard open/close (1303-1346).
6. Keyboard inside a shadow root: 1475 as is; listbox placement 284.
7. Node file: fitHeight table, resize keyboard table + persistence + max/min, skin contrast table (57, 711, 745, 770, 816).

### 5. Odd things / rule breaks

- Hand-rolled stub: 509 replaces `window.requestAnimationFrame` (restored in afterEach). No `vi.*` mocks or spies.
- Timing: 195 fixed sleeps (`pause(280)`, `pause(240)`) to land inside a 400 ms window; 176 waits the real window. Both should use fake timers or a settable reset.
- Geometry asserts (house rule: none): 82, 93, 109, 868-914 (`scrollHeight`/`clientHeight`/`style.height`), 392 (`scrollLeft`), 500/519 (bounding rects to aim a click). For autosize there is no user-level proxy except "the last line is visible and nothing scrolls"; consider `toBeInViewport` on the last line inside a fixed-height host.
- DOM/attribute reads: `data-scope`/`data-part`/`id` (970, 1220), `aria-describedby` and `tabindex` presence (1012, 1226, 1232), `:focus-visible` via `matches` (248, 1039, 1140, 1346), `aria-activedescendant` vs element ids (1475).
- Pixel comparison: 1475 compares element screenshots byte for byte to prove a focus ring appeared.
- Pure tests in a browser file: 57-69, 711-770, 816-841.
- 1303/1323 bound the windowed row count at 40: a tuning constant, fails on an overscan change without a user-visible regression.
