### 5. Odd things / rule breaks

- **Real wall-clock waits**: 322 waits 12 s by design (to prove the old 10 s cap is gone; the cap is not an option, so the test can't shorten it); 333 waits 5 s although `firstOutputTimeoutMs` is an option (344 already uses 300 ms). Both run in every `pnpm test`.
- No `vi.fn`/`vi.mock`/`vi.spyOn`/fake timers.
- Storage sabotage: raw SQL corruption (104, 115, 136) and a trigger that fails the cancel write (197-199). Real failure paths, tied to table/column names.
- Pool internals: 808 and 855 emit synthetic `'error'` events on piscina thread objects; 847 terminates a pool thread directly.
- Polling: the fake CLI polls a gate file every 20 ms (inside the fake, not the test); `untilExists` uses `fs.watch` (fseventsd-sensitive per memory note).
- 575 also asserts `drive` rejects a message without id: unrelated rule riding in a retry test.
- 987, 1053 test @conciv/protocol; 1034 tests the package's own testkit.
- `describe('dist externals')` reads `dist/` at collection: without a build the whole file fails to collect, not two tests (same pattern as core.test.ts 4868).
