## 4. What the e2e level covers today

The e2e suites boot the widget in 12 hosts and check the Terminal tab and persistent pty (nextjs, vite-react), the TanStack chip, a pre-hydration login, the startup library set, harness home writes not reloading the page, the real harness catalog plus one turn (harnesses), `conciv init` on two real clones, and packed installs (one sandbox copy, client graph, prod build, trust policy). They do not drive page tools, approvals, plugins (ios, recorder, test-runner, whiteboard), drafts or the bus. So for almost every user-facing behaviour the owning level is the widget browser suite (conciv), embed.it or core-api.it, not e2e. The overlap cuts above are mostly between browser component files and the conciv/embed.it journeys, and between node files and core-api.it.
