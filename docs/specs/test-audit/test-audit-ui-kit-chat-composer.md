- Not user input: 1761 dispatches synthetic `PointerEvent`s and writes `search.value` directly; 912-943 call the composer context instead of the UI.
- DOM/attribute reads as assertions: `data-copied` (112), `data-scope`/`data-part` walking and `aria-describedby` (507), `aria-expanded` (690), `aria-disabled` (811), replica-iframe DOM queries and `performance` resource entries (1511-1706), `defaultPrevented` (1219).
- Environment-dependent: 241 needs Chromium to refuse the clipboard write.
- A whole family (641, 677, 690, 715, 728, 848) tests width-fit of auto actions, a mode the product switched off with `MAX_INLINE_AUTO_ACTIONS = 0`; and 1826 tests a primitive no surface renders. If these primitives stay public API they need a reason; if not, they and their tests go.
