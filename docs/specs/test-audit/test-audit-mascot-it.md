# Test audit: packages/mascot/test/e2e/mascot.it.test.ts (2,865 lines, origin/main 51708bc06)

Read start to end, plus `packages/mascot/test/e2e/helpers.ts` (harness page, manual GSAP clock, layout/listener counters) and
`test/e2e/README.md`. Cross-checked against `packages/mascot/test/browser/solid-mascot.browser.test.tsx` (Solid wrapper, 285 lines)
and `packages/mascot/test/unit/mascot.test.ts` (publish surface, packed install). No engine, no widget: every test opens a static
harness page in Playwright Chromium, builds a stage by hand and drives the framework-free core service (`createMascot`) through
`page.evaluate`. Level for every row is **browser** (Playwright, no product server). There is no e2e or it test of the mascot
anywhere else; the widget e2e suites only see the FAB.

Blanket rule breaks (apply to every row, not repeated per row):

- **DOM/implementation reads via `page.evaluate`**: every assertion reads GSAP tween state (`gsap.getProperty` through
  `harness.property`), `offsetWidth`, `childElementCount`, style strings, active-writer counts. For animation geometry there is no
  user-visible proxy, so this is the only way to test it; the rewrite must accept it as a sanctioned exception or drop the file.
- **Monkey-patched platform (spy family)**: the harness page wraps `window.addEventListener/removeEventListener` (pointermove
  count), `requestAnimationFrame/cancelAnimationFrame` (frame-loop count) and, under `countLayoutReads`, `getComputedStyle`,
  `getBoundingClientRect` and every `offset*` getter on `HTMLElement.prototype` (helpers.ts:13-80). They count calls, they do not
  stub behaviour, but they are `vi.spyOn` by another name.
- Manual clock (`installManualClock`, GSAP ticker removed) is a fake timer, allowed. Rows marked "wall clock" use real waits.

### 2. Lines that would go

Deleting DUPLICATE (1292, 1306) removes ~14 lines: 2,865 → ~2,851. The 20 MERGE rows span ~640 lines; folding them into their

### 5. Odd things / rule breaks

- The whole file is `page.evaluate` DOM/tween reads against a hand-built stage (see blanket note). Either it is a sanctioned
  exception for motion geometry or it cannot exist under the house rules; there is no user-facing assertion that could replace it.
- Prototype patching of `getComputedStyle`, `getBoundingClientRect`, `offset*` getters, `addEventListener`, `requestAnimationFrame`
  (helpers.ts:13-80): call counting = spy family.
- Wall-clock waits that are timing guesses: gaze describe (`settle(1400)` ~15 times, `settle(250/300/900)`, `wait(60)` loops,
  `wait(900)`), 913 (`wait(1400)` then `wait(400)` and a "<half the ink" threshold), 883 (`sampleFrames(700)`), registration
  (`wait(120/200/600/700)`), reduced motion (`wait(700)`), visibility (`wait(200)` + `waitUntil(3000)`). The README argues the gaze
  waits are "settled saturation" reads; they are still fixed sleeps chosen to outlast an ease.
- Asserts on inline style strings ('-4px', '-12px', `url('…')`) at 1360, 1374, 1616 and on `transform-origin` text at 1943.
- File name says `.it.test.ts` and folder says `e2e/`, but nothing here is integration or end-to-end: no server, no product page.
  It is the package's browser test file; the package also has `test/browser/solid-mascot.browser.test.tsx`, so it carries two
  browser files against the one-browser-file budget.
- Named magic numbers mirrored from the product (1.3 throb, -5 bob, -2 awake, 1.06 eyes, -4 deg lean, 0.936 opacity at 2256) are
