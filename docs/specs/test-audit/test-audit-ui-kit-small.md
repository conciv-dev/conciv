### 3. Journeys a lean rewrite would use

1. Token sheet contract (node): base completeness + scope, per-skin overrides only anchors (ui-kit-system node).
2. Editor external value (browser): caret mapping before/after, restore at end, chip flatten, undo leaves it (tap).
3. Terminal model + primitives (browser, local control socket): paste/inject, control frames (exit/error/busy), reconnect/cap/deliberate disconnect, shadow css, rail once + placement.
4. Streamdown streaming stability (browser): token/word/text node stability, settle drops spans, crash corpus.
5. Streamdown host hooks (browser): local file links, existence after settle, fence view fallback.
6. Preset contract (node): shortcuts resolve, reduced motion, keyframes, tokens, determinism.
7. solid-diffs: externals + paced render sync (fake timers).

### 5. Odd things / rule breaks

- terminal.test.tsx is a browser test without `.browser` in its name.
- terminal 100/125: geometry asserts + data-attribute queries (house rules ban both).
- streamdown: MutationObserver/node-identity and `data-sd-word` reads throughout (68-154); the behaviour (node stability) has no user-level observable, so this is the same kind of sanctioned-exception question as the mascot.
- streamdown 402/421: `setTimeout(0)` yield per character; assertion is only "textContent contains".
- solid-diffs 50: wall-clock throttling bound; flaky by construction on a slow machine.
- solid-diffs 87 tests a dependency.
- No mocks/spies anywhere in the seven files.
