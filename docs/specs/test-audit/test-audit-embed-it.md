### 5. Odd things / rule breaks

- **Waits out a product timeout**: 1174 and 1214 wait for the heartbeat to declare the engine unreachable (`UNREACHABLE_TIMEOUT_MS = 45_000`); house rule says the timer becomes an option the test shortens.
- **Locators on implementation**: `[data-conciv-capture]` (1577), `[data-message-id]` (2951), `:focus-visible` pseudo (1149), `panel.locator('img')` (1415).
- **DOM reads via `page.evaluate`**: `getComposedRanges` (2840/2854), host API calls through `page.evaluate` (1294, 2050, bootConnect beforeAll) — the latter is driving a public API, not reading DOM.
- **Stubs**: `installNativeStub` replaces `window.webkit.messageHandlers` (1401-1445) — a fake native host, the only way to test the bridge without iOS; `captureNativePosts` records posts.
- **Schema sabotage**: 1817 installs a SQLite trigger on `sessions.permissions` (real failure path, tied to table/column names).
