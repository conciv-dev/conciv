### 5. Odd things and rule breaks

- recorder.test 483 waits out the product START_WAIT_MS of 5000 ms in real time: a "waits out a product timeout" break. Fix: make the wait an option the test shortens.
- recorder.it.test.ts is a browser suite named `.it.`; rename to `.browser.test.ts` so the budget rule reads it right (package then has 1 node + 1 browser: within budget).
- 873 reads the process table with `ps` to count chromium children.
- 410 writes document.visibilityState through page.evaluate (simulation); 523 reads aria-valuemax via getAttribute.
- 243 is a 190-line test that proves 14 behaviours; failures will be hard to read.

### 6. Shared state

All state under per-test temp roots. Fake timers are installed and restored per test. No module-level mutable state found.

### 7. Rewrite input (lean)

Browser: one widget journey (tab + live follow + replay), one capture journey (idle, capture, hidden, queued), one failure journey (slow and failed libraries). Engine: store, events+leases, tools+pull, video, lifecycle+errors. Lean estimate: about 1,050 lines (browser 450, engine 600).
