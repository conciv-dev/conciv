# Test audit: packages/plugin-host/test (38 files, 11,053 lines, origin/main 51708bc06)

Every file read start to end at origin/main 51708bc06 (no fetch). `packages/plugin-host/test/core/bus.test.ts` (1,401 lines) is audited separately in test-audit-plugin-host-bus.md and is only cross-checked here.

Level: everything here is node (`vitest` with `environment: 'node'`, `ciTest()`), mostly `it.effect` / `it.live` from test/core/lib/effect.ts. A few tests reach real processes, real git/tar, a local HTTP npm registry, @parcel/watcher and photon wasm; none boots a browser or the engine server, so engine-level coverage lives in packages/core/test (core.test.ts, core-api.it.test.ts).

Provenance: most files are copies of opencode's tests, landed with the plugin host port. #864 (71a6bb923, plan 2) brought bus, bus-unpersisted, bus-session-routing, database*, watcher, keyed-mutex, config-plugin-source; #860 (5e458e22a) brought state*, tool-execute, tool-registry, tool-schema; #885 (bf9bac496) brought most of the rest; #952 brought tool-server. conciv-written: tool-server, global, parts of plugin/supervisor*, rpc-handler-errors. `.oxlintrc.json` exempts config-plugin-source, database-drizzle, plugin.test, effect-flock (lines 395-399) and instructions/index (471) from house lint rules as copied files.

Budget: 38 node test files here plus bus.test.ts = 39 node test files in one package, against the one-node-file budget (`conciv/test-file-budget`). A merge into one file looks like `packages/plugin-host/test/plugin-host.test.ts` with one top-level `describe` per domain, in this order: State (state, state-group, state-replay), Bus (bus, bus-unpersisted, bus-session-routing), Storage (database, kv, keyed-mutex, effect-flock, fs-util, global), Watcher, Npm (npm, npm-config), Config sources and skills (config-plugin-source, config/markdown, config/skill, skill, plugin/skill, tool-skill), Instructions (instruction-state, instructions/index, codemode/instructions), Permission, Tools (tool-registry, tool-schema, tool-execute, tool-server), Code mode (codemode, codemode/catalog), Plugins (plugin, plugin-failure, plugin/module, plugin/supervisor, plugin/supervisor-reload, rpc-handler-errors). The shared layers in test/core/lib and test/core/fixture already make this mechanical; at the lean size (section 7) the one file lands near 5,000 lines, over the 1k-line cap, so a merge also needs either a recorded exception or the rewrite in section 7 first. The copy rule ("keep the source's names") covers file names only for src files; it does not exempt these tests from the budget.
