# Ledger: app, composer, triggers, drafts, queue, steer and model prompt

Feature rows come from `features/app.md` (composer section) and the full per-row composer pass. One row per feature: the flow that covers it and the test, or `blocked: <what it needs>`, `e2e` or `story`. A row a test covers only in part says what is left.

Status words: every status cell starts with exactly one of `tested` (names the landed test file and test title), `written` (written in phase 1, not yet proven green: names the file, describe and test), `planned` (not written, names its file), `verify` (thought covered or writable, unchecked), `blocked` (with the reason), `browser` (goes in an area browser file, not written), `e2e` (goes in an e2e spec, not written), `elsewhere` (owned by a row in another ledger, named), `kept` (opencode's behaviour or a ruling, no test), then a colon and the detail.

## Files, in order

1. `apps/conciv/src/pane/pane-composer.browser.test.tsx`: typing and sending, the placeholder, Escape.
2. `apps/conciv/src/pane/queue-strip.browser.test.tsx`: send while running, the queue strip, Remove, Steer, Stop with a queue.
3. `apps/conciv/src/pane/trigger-sources.browser.test.tsx`: the `/` and `@` lists, picks, `/model`; its fixture project is `apps/conciv/test/fixtures/mention-project`.
4. `apps/conciv/src/composer/session-model-prompt.browser.test.tsx`: the model menu and effort.
5. `apps/conciv/src/pane/draft-storage.browser.test.tsx`: the draft follows the session. Send clears it: file 8.
6. `apps/conciv/src/pane/pane-attachments.browser.test.tsx`: text attachments, the send caps.
7. `apps/conciv/src/composer/note-card.browser.test.tsx`: plugin notes and composer pills from a fixture plugin.
8. `apps/conciv/src/composer.browser.test.tsx`: real focus hand-offs, and the panes opened on a session with saved messages (Send clears the draft). The IME row lives in `pane/pane-composer.browser.test.tsx`.
