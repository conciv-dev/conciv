# Ledger: plugins

Feature rows come from `features/plugins.md`, one table per plugin. One row per feature: the flow that covers it and the test, or `waits: mount history (<file>)`, `blocked: <what it needs>`, `e2e` or `story`. A row a test covers only in part says what is left. The YES and NO marks of the feature list are stale; its rows are the list.

## page

The page plugin is part of the app, so it never mounts: its node tests live beside its sources in `packages/plugins/page/src`, and its on-screen journeys wait for the app's mount with history in `apps/conciv/src/page.dom.test.tsx` (or `apps/conciv/src/page.browser.test.tsx` where layout, real focus, canvas or capture is needed).

`src/tools.test.ts` starts an engine with `createEngine`: it is a draft until the kit's start-up speed fix lands.
