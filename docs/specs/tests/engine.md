Setup, the maintainer's ruling (2026-11-21): one setup in every package, the kit (`@conciv/plugin-testkit` and `@conciv/harness-testkit` as devDependencies, `concivTest()` in the package's one `vite.config.ts`, the kit bin as the `test` script). A test of a single product function calls it directly and does not start an engine. No package gets its setup, and no engine test lands, until the start time is fixed.

The last two columns say how a flow can be proven: by calling one product function with its own inputs, or only through a running engine (`createEngine`, `engine.reply`, `cli()`). A flow is written the cheaper way when both say YES. Kit imports are the root form: `import {createEngine, TestLLM, cli} from '@conciv/plugin-testkit'`.
