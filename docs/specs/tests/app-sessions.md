# Ledger: app, sessions list, search, preview, quick pane

Feature rows come from `features/app.md` (sessions section: the rows marked NO, YES and could-not-judge; the marks there are stale). One row per feature: the flow that covers it and the test, or `blocked: <what it needs>`, `e2e` or `story`. A row a test covers only in part says what is left. A test named here and not yet landed is marked "planned".

The session picker list renders through `VirtualList` (`@tanstack/solid-virtual`). With a scroll box of 0px, virtual-core renders no rows (`calculateRange` returns null when `outerSize === 0`), and happy-dom has no layout. So every flow that reads picker rows runs in browser mode, in `apps/conciv/src/index.browser.test.tsx`.
